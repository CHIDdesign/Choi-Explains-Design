## 2. 원칙

1. **소리는 화면의 재질을 따른다.** 화면이 크림 종이·잉크·테이프이므로 소리도 종이·연필·테이프·도장이다. UI·예고편 소리는 쓰지 않는다.
2. **보이는 사건에만 붙인다.** 박자나 컷에 붙이지 않는다. 화면에서 무언가 놓이거나 넘어가거나 그어질 때만 난다.
3. **자주 나는 소리일수록 작고 짧고 낮게.** 길이는 애니메이션 + 0.3초를 넘지 않는다.
4. **한 영상에 한 세션.** 같은 녹음 세션(`family`)의 변주만 돌린다. 출처가 다른 파일을 섞지 않는다.
5. **말의 자음 대역을 비운다.** 2~6 kHz 에 뾰족한 트랜지언트를 두지 않는다. 말 시작 0.15초 안에는 놓지 않는다.
6. **침묵을 지킨다.** 음악이 빠진 자리, 얼굴 홀드, 결론 문장에는 효과음도 없다.
7. **없으면 내지 않는다.** 맞는 카테고리가 비면 비슷한 다른 소리로 메우지 않는다.

## 3. 카테고리

레벨은 목소리 스템의 통합 라우드니스 `V` 에 대한 상대값이다(효과음의 최대 모멘터리 라우드니스 기준).

| 카테고리 | 소리 | 쓰는 곳 | 레벨 | 최대 길이 |
|---|---|---|---|---|
| `paper_slide` | 종이가 책상 위를 미끄러진다 | 메모·카드·패널·스톡이 들어올 때 | V − 22 LU | 0.45초 |
| `paper_place` | 종이를 내려놓는 낮은 "톡" | 키워드, 콜아웃, 정리 보드 | V − 20 | 0.35초 |
| `page_turn` | 페이지를 한 번 넘긴다 | 챕터 카드, 하이라이트 → 본편 | V − 18 | 0.9초 |
| `tape` | 마스킹 테이프를 뜯거나 붙인다 | 사진·메모가 테이프로 고정될 때 | V − 22 | 0.5초 |
| `pencil_stroke` | 연필·펜이 선을 긋는다 | 밑줄 스윕, 정의·인용, 도식의 선 | V − 24 | 0.6초 |
| `pencil_tick` | 짧은 체크 | 목록·단계 항목 | V − 26 | 0.15초 |
| `stamp` | 고무 도장(부드럽게) | 숫자 착지, 배지, 펀치 구간의 강도 3 | V − 18 | 0.4초 |
| `print_place` | 인화지·카드를 놓는다 | 자료 사진 | V − 20 | 0.4초 |
| `air_soft` | 아주 작은 공기 소리 | 전면 B-roll 진입(선택) | V − 26 | 0.6초 |
| `tonal` | 스코어의 악기로 낸 한 음(곡 조성에 맞춤) | 타이틀, 영상당 1~3회 | V − 14 | 1.5초 |
| `ident` | 채널 인장 | 타이틀·엔드카드(말이 없을 때) | V − 10 | 2~4초 |

- 카테고리마다 같은 `family` 의 변주 3~4개를 둔다. 고르는 규칙은 라운드 로빈이고 직전과 같은 파일은 쓰지 않는다.
- 전처리(FFmpeg, n9.0.2 에서 실행 확인): `aresample=48000,highpass=f=150:p=2,lowpass=f=9000:p=1,afade=t=out:st=<최대 길이−0.15>:d=0.15:curve=qsin`.
- `tonal` 을 곡 조성에 맞출 때는 미리 옮긴 판을 넣어 둔다. 급할 때는 `asetrate=<원래 샘플레이트>*2^(n/12),aresample=48000` 로 n 반음 옮긴다(길이도 같이 바뀐다).
- 없애는 카테고리: `riser`, `sub_drop`, `impact`, `reverse_cymbal`, `glitch`, `notification`, `ding`, `bell_soft`, `camera_shutter`, `typing`, `pop`, `click`, `whoosh_*`, `swoosh_short`, `swipe`.

## 5. 밀도·배치 규칙

| 항목 | 지금 | v2 |
|---|---|---|
| 평균 | 분당 약 2(이번 실행 4.2) | 분당 1.5 이하 |
| 60초 창 상한 | 4, `click`·`riser` 제외 | **3, 모든 효과음 포함**(D5) |
| 최소 간격 | 2초 | 2초. 목록 틱끼리는 0.6초 |
| 같은 파일 | 큐 번호로 순환 | 같은 `family` 안 라운드 로빈, 연속 금지 |
| 말과의 거리 | 없음 | 말 시작 0.15초 안에는 놓지 않는다(앞으로 당긴다) |
| 금지 구간 | 결론·감정 문장 | + 음악 침묵 구간, 얼굴 홀드, 인용 |
| 시퀀스([05](05_편집_문법_v2.md)) | 그래픽마다 | 시퀀스 진입 때 많아야 하나. 안의 샷 전환에는 없음 |

| 음악이 없는 자리 | 같음 | 3 LU 더 작게 |
| 우선순위 | 챕터 > 전환 > 그래픽 | 챕터 `page_turn` > `stamp` > `print_place` > `paper_place` > `paper_slide` > `pencil_*` |

- 겹쳐 쓰기: 한 사건에 한 소리가 기본이다. 타이틀에서만 `ident` 위에 `paper_place` 를 얹는다(두 겹까지).
- 전환 소리와 그래픽 등장 소리가 0.4초 안에 겹치면 전환 쪽만 남긴다(지금의 `near_tx` 규칙 유지).
- 정규화는 피크가 아니라 최대 모멘터리 라우드니스로 한다. 같은 체감 크기가 된다.

## 6. 펀치 구간과 오프닝 하이라이트

- 펀치 구간(`energy_spans`)에서도 riser·impact·whoosh·서브 드롭은 쓰지 않는다. 힘은 `stamp` 한 번과 컷의 리듬에서 낸다.
- 밀도만 푼다: 60초 창 상한 3 → 6, 최소 간격 2초 → 1.2초.
- 강도 3 = `stamp`(V − 16 LU 까지), 강도 2 = `paper_slide` 빠른 판, 강도 1 = `paper_place`.
- 오프닝 하이라이트는 스코어의 `theme` 이 추진력을 맡는다. 조각 사이 숨에는 소리를 넣지 않고, 본편으로 넘어갈 때 `page_turn` 한 번과 `ident` 로 연다.
- 숏폼의 첫 3초도 같다. 훅 문장 위에는 효과음을 얹지 않는다.

## 8. 합성 폴백(`studio/sound/synth.py`)

인터넷이 없어도 팔레트의 재질이 유지되게 한다.

| 카테고리 | 합성법 |
|---|---|
| `paper_slide` | 지금의 `paper`(대역 잡음 800~6000 Hz + 불규칙 엔벨로프)를 0.25~0.45초로. 시드로 변주 3개 |
| `paper_place` | 90~140 Hz 감쇠 사인 40 ms + 2~5 kHz 잡음 15 ms |
| `page_turn` | `paper_slide` 두 번을 0.25초 간격으로, 둘째를 더 낮게 |
| `pencil_stroke` | 3~7 kHz 대역 잡음에 20~40 Hz 불규칙 진폭 변조, 0.3~0.6초 |
| `pencil_tick` | 대역 잡음 12 ms |
| `stamp` | 110 Hz 감쇠 사인 80 ms + 저역 잡음 |
| `tape`·`print_place`·`air_soft`·`tonal`·`ident` | 합성하지 않는다. 없으면 내지 않는다 |

지우는 것: 사인 `ding`, 사각파 `glitch`, 사인 스윕 `pop`, `click`, `riser`, `impact`, `sub_drop`, `reverse`, `typing`, `shutter`, `whoosh_*`.
