# 12. 촬영 체크리스트 — 작은 방에서 혼자, 폰이나 미러리스로

찍을 때 5분이면 되는 일을 편집에서 고치려면 품질을 잃는다. 아래 항목마다 **이 파이프라인에서 무엇이 틀어지는지**를 적었다.
"이번 테스트"는 `projects/20261001_2028_…`(iPhone 14 Pro, 1080p, 원본 2개)에서 잰 값이다. 근거: [`07_영상_룩_v2.md`](07_영상_룩_v2.md) 1절, [`00_테스트영상_진단.md`](00_테스트영상_진단.md).
기획·대본 쪽은 [`11_기획_대본_촬영_가이드.md`](11_기획_대본_촬영_가이드.md)가 맡는다. 이 문서는 카메라 앞 한 쪽짜리다.

## 카메라

| ☐ | 할 일 | 안 하면 생기는 것 |
|---|---|---|
| ☐ | **4K · 30fps · SDR**(HDR 비디오 끔)로 찍는다 | 1080p 원본은 편집본도 1080p 라 확대 여유가 0 이다. 106% 푸시인·크롭이 전부 업스케일이 된다(이번 테스트). 60fps 는 30 으로 내려 쓰니 용량만 든다 |
| ☐ | **노출·초점 잠금**(화면을 길게 눌러 AE/AF 고정), 미러리스는 수동 노출 | 말하는 동안 밝기가 천천히 변한다. 색보정은 영상 전체에 값 하나라 따라가지 못하고, 컷마다 얼굴 밝기가 튄다(게이트 F5) |
| ☐ | **화이트밸런스 잠금**(가능한 앱·기종에서), 미러리스는 켈빈 고정 | 고개를 돌리거나 손이 들어올 때 색이 흔들린다. 같은 이유로 자동 보정이 못 고친다 |
| ☐ | 후면 메인 카메라(1×), 삼각대, 렌즈는 **눈높이** | 전면 카메라·광각은 잡음과 왜곡이 크다. 아래에서 올려 찍으면 천장과 턱이 화면을 차지한다 |
| ☐ | 카메라는 팔 길이의 1.5배 이상 떨어뜨린다 | 가까운 광각은 얼굴을 넓히고, 배경(침대·문)이 더 많이 들어온다 |

## 빛

| ☐ | 할 일 | 안 하면 생기는 것 |
|---|---|---|
| ☐ | **얼굴을 비추는 빛 하나**를 정한다: 창이나 스탠드를 얼굴 앞 45°, 눈높이보다 조금 위. 흰 종이·천으로 가려 부드럽게 | 이번 테스트 2번 원본: 옆의 전등이 한쪽 뺨만 비춰 얼굴 채도 35.7(자연 범위 상한 30), 밝기 L 63. 교정이 채도를 깎아야 했다 |
| ☐ | **전등을 화면에 넣지 않는다.** 넣는다면 얼굴 반대편 뒤쪽 구석에, 갓이 하얗게 날아가지 않을 만큼 어둡게 | 전등이 "가장 밝은 점"이 돼 노출 기준을 흔든다. 이번 테스트: 날아간 화소 0.2% → 4.4%, 전등갓이 흰 덩어리 |
| ☐ | **빛의 색을 섞지 않는다.** 모니터·형광등·전구 가운데 하나만 켠다 | 한쪽은 주황, 한쪽은 파랑인 얼굴은 화이트밸런스 하나로 못 맞춘다 |
| ☐ | 찍기 전 10초를 찍어 폰에서 본다: 이마가 번들거리지 않는가, 전등·창이 하얗게 날아가지 않는가 | 날아간 부분은 되살릴 수 없다 |

## 배경

| ☐ | 할 일 | 안 하면 생기는 것 |
|---|---|---|
| ☐ | **침대·가방·빨래를 화면 밖으로.** 화면 네 귀퉁이를 한 번씩 본다 | 이번 테스트 1번 원본: 왼쪽 기타 가방, 오른쪽 침대. 본편·썸네일·숏폼에 전부 나온다. 자동으로 지우는 기능은 기본 경로에 없다([07](07_영상_룩_v2.md) 5절) |
| ☐ | **벽에서 1.5m 이상** 떨어져 앉는다 | 벽에 그림자가 지고 배경이 얼굴과 붙어 평평해진다. 떨어지면 배경이 자연스럽게 어둡고 흐려진다 |
| ☐ | 피부색과 비슷한 누런·베이지 벽 바로 앞은 피한다. 어쩔 수 없으면 벽에 빛이 덜 가게 한다 | 색보정의 피부 판정이 벽을 건드릴 여지가 생긴다. 이번 테스트의 벽 얼룩·분홍 벽은 (버그였지만) 이 조건에서 났다 |
| ☐ | 배경에 둘 것은 하나만(책장 한 칸, 화분, 포스터) | 물건이 많으면 메모·사진 그래픽과 시선을 다툰다 |

## 구도 — 가로 무대(36/64)와 세로(9:16)를 한 번에

| ☐ | 할 일 | 안 하면 생기는 것 |
|---|---|---|
| ☐ | **화면 한가운데**에 앉는다. 좌우로 각각 화면의 1/4 은 비운다 | 롱폼은 화자를 왼쪽 36% 판으로 잘라 넣고, 숏폼은 가운데 세로 띠(가로의 약 32%)만 쓴다. 한쪽으로 치우쳐 앉으면 둘 다에서 어깨가 잘린다 |
| ☐ | **눈이 화면 위 1/3 선**에, 머리 위에 주먹 하나만큼 여백 | 머리 위가 비어 있어야 소제목 바가 뜬다(약 230px). 너무 많이 비면 얼굴이 작아지고 천장이 들어온다 |
| ☐ | 얼굴 높이가 화면 높이의 **1/4~1/3** 이 되게(가슴 위까지 보이게) | 이번 테스트는 약 0.38 로 조금 크다. 크면 세로 크롭에서 턱·어깨가 잘리고, 얼굴 옆에 메모를 놓을 자리가 없다 |
| ☐ | 손짓은 **몸통 폭 안에서** | 세로 크롭 밖으로 나간 손은 숏폼에서 잘린다 |
| ☐ | 같은 내용을 다시 찍을 때는 **같은 자리 · 같은 빛 · 같은 설정** | 이번 테스트: 두 원본의 얼굴색 차이 ΔE 11.2. 색을 맞춰도 방 모양이 달라 한 영상에서 화면이 둘로 갈린다. 배경 차이가 크면 교차 편집을 못 쓴다([02](02_전체테이크_중복_처리_설계.md) 3-3) |

## 소리

| ☐ | 할 일 | 안 하면 생기는 것 |
|---|---|---|
| ☐ | **마이크를 입에서 한 뼘(15~25cm)**, 입김을 피해 약간 옆에. 폰 내장 마이크면 카메라를 1m 안으로 | 이번 테스트 SNR 34.9 · 33.4 dB — 잡음 제거가 켜지는 기준(38 dB)보다 낮다. 잡음 제거는 목소리 결도 조금 깎는다 |
| ☐ | 냉장고·환기·PC 팬·알림을 끈다. 이불·커튼은 **화면 밖**에 그대로 둔다 | 일정한 웅 소리는 지워도 흔적이 남는다. 부드러운 물건은 방의 울림을 줄여 준다 |
| ☐ | 시작 전에 **아무 말 없이 10초** 녹음한다(룸톤) | 컷 사이를 메울 방 소리가 없으면 편집점마다 배경 소리가 끊긴다 |
| ☐ | 카메라가 두 대면 시작할 때 **손뼉 한 번** | 소리로 싱크를 맞춘다. 또렷한 한 점이 있으면 실패하지 않는다 |

## 말하기

| ☐ | 할 일 | 안 하면 생기는 것 |
|---|---|---|
| ☐ | 틀리면 **그 문장 처음부터** 다시 말한다. 대본 전체를 두 번 찍지 않는다 | 이번 테스트의 가장 큰 사고: 전체를 두 번 찍은 원본이 둘 다 들어가 영상이 두 배가 됐다([02](02_전체테이크_중복_처리_설계.md)) |
| ☐ | 문장 사이에 **1초** 쉰다. 다시 말하기 전에도 1초 | 쉼 안에서 잘라야 말 꼬리가 새지 않는다 |
| ☐ | 끝나고 5초 가만히 있다가 끈다 | 마지막 문장 끝이 잘린다 |
