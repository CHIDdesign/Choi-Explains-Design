## 1. 왜 필요한가 (이번 테스트에서 실제로 있었던 일)

- 숏폼용으로 고른 Openverse 사진이 **CC BY-NC-ND 2.0**(비영리·변경 금지)이었다. 크레딧은 "atelier-ying / Openverse" 뿐이었다.
  우연히 타이밍에서 빠져 화면에는 안 나갔지만, 내려받아 계획에 들어간 상태였다. 그 작업의 Openverse 후보 17건 중 8건이 NC 또는 ND 였다.
- 위키백과 사진 두 장(CC BY-SA 4.0, CC BY 2.0)은 화면에 `작가 · 라이선스 · Wikipedia (문서명)` 으로 표기됐다 — 형식은 맞다.
- 지금 코드는 "자유 라이선스만"이라는 한 가지 규칙뿐이라, 디자인 채널에 꼭 필요한 저작권 있는 작품(포스터·제품 광고·책 표지·화면)은 아예 못 쓰고,
  반대로 스톡 쪽에는 라이선스 검사가 없다. 등급을 나눠 **쓸 수 있는 것은 조건을 지켜 쓰고, 쓰면 안 되는 것은 기계가 막는다.**

| 미국 17 U.S.C. §107 | 목적과 성격 · 저작물의 성질 · 이용된 양과 실질 · 시장 영향. 변형적 이용인지가 중요하고 판단은 사안별 |
| 상표(지칭적 공정사용) | 그 상표 없이는 대상을 가리키기 어렵고, 필요한 만큼만 쓰고, 후원·보증을 암시하지 않을 것 |
| YouTube | 출처 표기·"침해 의도 없음" 문구만으로는 공정이용이 되지 않는다. 해설 없는 이미지 슬라이드쇼·대량 생산형 콘텐츠는 수익 창출 불가. 사실적인 합성 콘텐츠는 공개 의무 |

## 3. 등급

| 등급 | 대상 | 자동화 | 화면 제약 |
|---|---|---|---|
| **own** | 화자 본인의 작업물·촬영물·화면 녹화(④ 자료 폴더) | 완전 자동 | 없음. 단, 폴더 안에 남의 작업물이 섞여 있으면 화자가 책임진다 — GUI 에 한 줄 안내 |
| **A** | CC0 · 퍼블릭 도메인 · PDM · 공공누리 0·1유형 · CC BY | 완전 자동 | 없음(크롭·누끼·주석 가능). CC BY 는 크레딧 필수 |
| **A-sa** | CC BY-SA | 자동 + 자료 대장에 표시 | 원본을 크게 바꾸지 않는 처리(액자·푸시인·주석 레이어). 누끼·합성 콜라주는 설정 `allow_sa_derivatives` 가 켜졌을 때만. 영상 전체에 동일 조건이 미치는지는 사안별이라 단정하지 않는다 |
| **stock** | Pixabay·Pexels·Unsplash·Coverr 라이선스 | 자동 | 각 제공처 약관. 식별 가능한 인물·상표가 주 피사체인 컷은 피한다. Unsplash API 의 핫링크 요구 조항은 운영자 확인 필요(미확인) |
| **B** | 제조사·기관의 보도용·홍보용 이미지(프레스 킷·뉴스룸) | **허용 목록에 있는 출처만** 자동. 나머지는 검토 시트에 "확인 필요" | 약관이 편집 목적·변형 금지면 크롭·재색·누끼 금지. 광고처럼 보이는 배치 금지 |
| **C** | 저작권이 살아 있는 작품의 인용: 포스터·광고·책 표지·논문 첫 쪽과 그림·영화 스틸·웹/앱 화면 캡처·비자유 로고 | 설정 `allow_quote` 가 켜졌을 때 자동 조달, **전부 자료 대장과 검토 시트에 목록화** | 아래 4절 |
| **D** | 금지 | 기계가 막는다 | — |

**D(금지) 목록**
- NC(비영리)·ND(변경 금지) 조건: CC BY-NC*, CC BY-ND*, 공공누리 2·4유형(상업 금지). 공공누리 3유형(변경 금지)은 원본 그대로만 — 크롭·주석이 필요하면 쓰지 않는다.
- 비상업 약관의 기관 이미지(예: V&A, Harvard Art Museums) — 메타데이터 조회용으로만.
- 스톡 에이전시 유료 이미지·워터마크가 있는 이미지.
- 출처를 알 수 없는 이미지(검색 결과·핀터레스트 핀·SNS 재게시물).
- 일반인의 얼굴·사적 사진.
- **실존 인물·실존 작품·역사적 장면을 그린 AI 생성 이미지.** 추상 질감·배경·가상의 예시(화면에 "예시" 표기)만 허용하고 `synthetic: true` 로 기록한다.

## 4. C 등급(인용) 운용 규칙

아래 수치는 법이 정한 선이 아니라, "분량·방법·대체성"을 보수적으로 관리하기 위한 **운영 규칙**이다.

1. **그 작품을 말하고 있는 문장에서만** 쓴다. 분위기용·배경용으로 쓰지 않는다. 요청의 `claim` 이 비어 있으면 C 등급을 쓸 수 없다.
2. **한 번에 6초 이내, 작품 하나당 영상 전체에서 15초 이내.**
3. **풀블리드 금지.** 종이 위 `hero`·`board`·`doc_highlight`·`browser_frame` 으로만 — 원작을 감상하게 하는 배치가 아니라 설명하는 배치.
4. **변형적 요소를 붙인다**: 주석·밑줄·비교·디테일 줌·화자의 해설 자막 중 하나 이상.
5. **해상도 제한**: 긴 변 1600px 이하로 내려 저장한다(원작 대체 방지). 논문·책은 **한 쪽 이내**, 강조하는 문장 주변만 읽히면 된다.
6. **썸네일의 주인공으로 쓰지 않는다.**
7. **출처 표기 필수**(화면 + 설명란): 작품명·작가·연도·권리자.
8. 논문 속 그림·사진 작품 전체·영화 스틸은 기본 꺼짐(`allow_figure_quote`). 켜도 검토 시트에서 사람이 한 번 본다.
9. 자산 메타에 `quote.justification`(어느 문장의 무엇을 설명하려고 몇 초 썼는지)을 남긴다.

화면 캡처(웹·앱)도 C 등급이다. 로그인 뒤 화면·개인 정보가 보이는 화면·유료 콘텐츠 본문은 캡처하지 않는다.

## 5. 저작권 밖의 제약

- **상표·로고**: 지칭 목적으로, 변형 없이, 필요한 크기로. 로고를 재색칠하거나 채널 로고처럼 배치하지 않는다. Commons 의 단순 글자 로고는 저작물성이 없더라도 상표권은 남는다.
- **초상**: 공인의 공개 활동 사진(A 등급)만. 주제와 무관한 인물 사진을 대상의 대용으로 쓰지 않는다(예: 서비스 이야기에 CEO 무대 사진).
- **서체**: 글자체 도안 자체는 보호 대상이 아니지만 폰트 **파일**은 프로그램 저작물이다. 렌더에는 번들 서체와 오픈 라이선스 서체만 쓴다.
- **소장 기관의 요구**: 미술관이 정한 표기 문구가 있으면 그대로 쓴다.

## 6. 크레딧 표기 형식

화면(`credit_short` — 16:9 는 22px 이상, 9:16 은 26px 이상, 자리는 06 문서의 출처 규칙)과 설명란(`credit_full`, `업로드정보.txt`) 두 벌을 만든다.

| 등급·소스 | 화면 | 설명란 |
|---|---|---|
| CC BY / BY-SA (Commons) | `사진: {작가} · CC BY-SA 4.0 · Wikimedia Commons` | `"{파일 제목}" by {작가} — CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/) — {파일 페이지 URL}` + 변경했으면 "잘라 씀" |
| CC0 · 퍼블릭 도메인(미술관) | `{작품명}, {작가}, {연도} · {기관} · 퍼블릭 도메인` | `{작품명}, {작가}, {연도}. {기관}, {소장 번호}. CC0 — {URL}` |
| Openverse 경유 | `사진: {작가} · {라이선스} · {원 출처}` | Openverse 응답의 `attribution` 문장 그대로 + `foreign_landing_url` |
| 공공누리 | `{기관} · 공공누리 제1유형` | `'{기관}'에서 '{연도}' 작성하여 공공누리 제1유형으로 개방한 '{저작물명}' — {URL}` |
| 스톡 | `{작가} / Pixabay` · `Photo by {작가} on Unsplash` · `{작가} / Pexels` | 같은 문구 + 소재 페이지 URL |
| B(프레스) | `이미지: {회사} 제공` | `이미지 제공: {회사} — {약관 URL}` |
| C(작품 인용) | `{작품명}, {작가}, {연도} · © {권리자}` | `{작품명}({연도}), {작가}. © {권리자}. 비평·교육 목적의 인용(저작권법 제28조).` |
| C(논문) | `{저자} ({연도}), {저널}` | `{저자} ({연도}). {제목}. {저널} {권}({호}), {쪽}. https://doi.org/{DOI} — 비평·교육 목적의 인용` |
| C(화면 캡처) | `화면: {도메인} ({캡처 연월})` | `{서비스명} 화면 캡처, {캡처일}. © {운영사}. 비평·교육 목적의 인용` |
| own | 표기 없음(원하면 `자료: 본인`) | — |
| 여러 장 그리드 | `사진: Wikimedia Commons 기여자 {n}명 — 설명란 참조` | 장마다 한 줄 |
| AI 생성(추상) | 표기 없음 | `AI 생성 이미지 {n}장(추상 일러스트·질감)` |

- 화면 크레딧에 **검색어·내부 식별자·라이선스 약칭만 덩그러니** 두지 않는다. 작가 미상은 `작가 미상`.
- `업로드정보.txt` 끝에 등급별 묶음으로 출력한다: A/A-sa → 스톡 → B(약관 URL) → C(인용 목록) → 합성.

## 7. 기계가 지키는 것 (`assets/license.py` + 게이트)

| 검사 | 동작 |
|---|---|
| 라이선스 문자열에 `nc`·`nd`·`all rights reserved`·빈 값 | 후보에서 제거(D). Openverse 는 요청에 `license_type=commercial,modification` 을 붙이고 응답도 다시 검사 |
| 요청의 `tier_max` 초과 | 후보에서 제거 |
| C 등급인데 `allow_quote` 꺼짐 | 사다리의 다음 칸(코드 재현·자료 카드)으로 |
| C 등급의 시간·크기·트리트먼트 위반 | 6초로 자르고 `hero` 로 바꾸고 1600px 로 줄인다 |
| A-sa 에 `cutout`·합성 | `hero` 로 바꾼다(설정이 켜져 있지 않으면) |
| B 인데 허용 목록에 없음 | 쓰지 않고 검토 시트에 "확인 필요" |
| 크레딧 누락(`attribution_required` 인데 `credit_short` 빈 값) | 렌더 전 block |
| 자료 대장 | `부가자료/자료_대장.csv` — 자산·등급·시각·초·크기·출처·인용 사유 |

## 8. 운영자가 정할 것 (설정)

| 설정 | 기본 | 뜻 |
|---|---|---|
| `allow_quote` | 켬 | C 등급(인용) 사용. 끄면 A·own·stock 만 |
| `allow_figure_quote` | 끔 | 논문 그림·사진 작품 전체·영화 스틸 |
| `allow_sa_derivatives` | 끔 | CC BY-SA 자산의 누끼·합성 |
| `press_allowlist` | 빈 목록 | B 등급으로 자동 사용할 출처와 약관 URL |
| `allow_synthetic` | 끔 | AI 생성(추상 질감·배경만) |

## 9. 확인하지 못한 것

- CC BY-SA 사진을 영상에 넣는 것이 "개작"에 해당하는지에 대한 Creative Commons 의 해당 문단(직접 인용하지 못했다).
- Unsplash API 가이드라인의 핫링크 요구와 영상 제작용 다운로드의 관계.
- 브랜드별 프레스 이미지 약관 원문(허용 목록에 넣을 때 하나씩 확인한다).
- Rijksmuseum·Getty·NGA·e뮤지엄 이미지의 권리 조건.
- 한국저작권위원회의 1인 미디어용 안내서는 찾지 못했다.
