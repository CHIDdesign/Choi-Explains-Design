# 스킬 출처 추가분 — `docs/스킬_출처.md` 에 덧붙일 것

모션 검수·레시피(`docs/upgrade/06c` · `06d`)와 스킬 두 개(`choi-motion-scene` · `choi-motion-review`)를 만들면서 참고한 저장소다.
조사 기록은 `docs/research/애니메이션_스킬_저장소_리서치.md`. 커밋과 라이선스는 2026-10-01 에 `git clone --depth 1` 로 받아 확인했다.
**이번에는 어떤 저장소의 코드나 문장도 저장소에 넣지 않았다.** 원칙과 수치만 옮겼고, 스케치와 린트는 새로 썼다.

## 1절에 덧붙일 것 없음

`.claude/skills/` 에 새로 넣는 외부 스킬은 없다. `choi-motion-scene`(교체) · `choi-motion-review`(신규)는 이 저장소에서 쓴 것이다.

## 4절 "저작권 주의"에 덧붙일 문장

- **LICENSE 파일이 없는 저장소**가 이번에 넷 더 있다: animate-skill, animation-forge(README 의 MIT 표기만으로는 부족하다), PDoomVideo, remotion-dev 의 스킬·템플릿 저장소(Remotion License 가 적용된다). 코드와 문장을 복사하지 않는다.
- 이번 조사에서 NC(비상업)·GPL 계열 저장소는 새로 쓰지 않았다. 기존 4절의 목록(video-talkcraft, MotionTalk, jc-remotion-skills, OpenChatCut)은 그대로다.
- 수치(이징 좌표, 프레임 수, 임계값)는 사실 정보로 보고 옮겼다. 채택한 값은 `docs/upgrade/06` 6장에 있고, 출처별 원래 값은 리서치 노트에 있다.
- 설치돼 있지만 아직 쓰지 않는 패키지를 쓰게 되면 라이선스를 다시 확인한다: `@remotion/paths` · `@remotion/layout-utils`(Remotion 문서는 MIT 라고 적는다 — 패키지의 LICENSE 파일은 읽지 않았다, 미확인), `gsap` 의 플러그인.
