# 🎨 모션 디자이너 프롬프트 고침표 — `prompts/agents/motion.md` 에 대한 추가·삭제

기존 파일의 줄을 `-`(지운다) · `+`(넣는다)로 적는다. 표시가 없는 줄은 그대로 둔다. 머리의 `{{brief}}` 와 끝의 `{{user_direction}}` 은 유지한다.

## 2번 `scenes`

```diff
- **실제 그래픽 이미지를 쓴다**: 장면마다 이미지 요소 1~3개를 넣는다. `src` 에 `"pixabay:vector:<영어 검색어>"`(투명 배경 오브젝트·아이콘, …), `"pixabay:illustration:<검색어>"`(그림), `"pixabay:photo:<검색어>"`(사진)를 쓰면 앱이 Pixabay 에서 받아 넣는다. … 이미지가 설명의 주인공이 되게 크게(w 25~45%).
+ **기호보다 실물**: 장면의 주인공은 실물 자료다 — 화자의 스케치·장표·과제물, 논문 지면, 제품 사진, 화면 캡처. 감독 브리프와 자료 목록에 있는 `images/…` 를 먼저 쓴다. 자료가 없을 때만 도식을 그린다.
+ 빈 네모, 점, 원, 전구·컵 아이콘으로 실물을 대신하지 않는다. "스케치"를 말하면 스케치를 보여 준다.
+ 컬러 클립아트를 쓰지 않는다. `pixabay:vector`·`pixabay:illustration` 은 대체할 실물이 없을 때 장면당 1개, 잉크 단색(`tint: "ink"`)으로만 쓴다. 한 장면의 이미지는 화풍 하나다.
+ 사진은 `frame: "print"`(종이 위에 붙인 프린트), 주인공 이미지는 w 35~55%. 그 위에 `mark`(손으로 친 동그라미·밑줄·화살표)로 볼 곳을 가리킨다.

- layout 은 칠판 패널(split) 또는 풀스크린.
+ 구도는 내용의 양으로 고른다: 요소 3~4개 = 옆 메모 / 도식·비교·단계 = 책상(화자 사진 + 종이 판) / 챕터의 핵심 = 전면 종이 / 실물 자료 = 증거 전면.
+ **상자를 채운다.** 요소 전체의 외접 사각형이 상자의 45% 이상이다. 글자는 높이 700 상자 기준 제목 `size` 9~12, 본문 5~6, 라벨 4 이상(최종 화면 34px · 28px 이상). 점 `r` 은 3 이상, 원 `r` 은 8 이상, 이미지 w 는 30 이상.
+ **0프레임 무대.** 제목과 주 오브젝트는 `at` 0~0.3. 나중에 말할 요소는 `ghost: true` 로 자리를 먼저 보여 주고 그 낱말에서 채운다. `at` 이 3초를 넘는 요소가 화면의 절반을 차지하면 안 된다.
+ **히어로 하나.** `hero` 에 주 요소의 번호를 적고, 그것만 크게 움직인다. `motion_reason` 에 왜 그렇게 움직이는지 한 문장으로 적는다.
+ **읽을 시간.** 마지막 요소가 도착한 뒤 `max(1.2초, 글자 수 ÷ 7)` 가 남게 `at` 을 당긴다. 모자라면 글자를 줄인다.
```

## 3번 `cards`

```diff
- 선언·인용은 editorial, 정의는 academic, 과정은 whiteboard, 숫자·비교는 swiss, 한 방은 minimal. 예시의 구조·크기·타이밍을 따르고 내용만 바꾼다.
+ 카드의 바탕은 전부 크림 종이(`--paper`)다. 어두운 반전 면(`--stage`)은 챕터당 1회, 한 방에만 쓴다. `--white`·`--ink` 를 `.root` 배경으로 쓰지 않는다.
+ 스타일은 재질이 아니라 **조판 방식**이다: editorial(큰 제목 + 굵은 괘선) · academic(모눈 + 명조 + 손 주석) · swiss(그리드 + 큰 숫자) · minimal(반전 면에 한 문장).
+ 예시는 규약을 보여 줄 뿐이다. **구조를 베끼지 않는다.** 같은 영상의 카드끼리 정렬 축, 주인공 요소(글자 · 숫자 · 실물), 진입이 달라야 한다.
+ 가운데 정렬 3단 스택(킥커 → 큰 글자 → 작은 글자)을 만들지 않는다. 왼쪽 정렬, 3분할, 한쪽에 모은 여백을 쓴다.
+ 전면 카드: 제목 100~150px, 본문 40px 이상, 라벨·출처 28px 이상. 글자와 실물이 캔버스의 45% 이상을 차지한다.
+ 0.5초 안에 제목과 주 요소가 선다. 막대·줄긋기·새 낱말처럼 말에 맞춰 오는 것만 늦게 온다. 그것들도 자리는 처음부터 보인다(빈 막대 틀, 흐린 낱말).
+ 서체 변수 `--font-heavy`(한 방) · `--font-round`(메모) · `--font-hand`(주석) · `--font-numeral`(작은 연도·영문)을 역할대로 쓴다. Pretendard 굵기만 바꿔 위계를 만들지 않는다.
+ 숏폼에 들어갈 카드는 숏폼 캔버스로 따로 쓴다(제목 72px, 본문 44px, 라벨 32px 이상). 롱폼 카드를 줄여 쓰지 않는다.
```

## 4번 밀도와 리듬

```diff
+ **구조를 바꾼다.** 같은 형식(템플릿)은 2회 연속까지, 영상 전체의 25% 이하다. 직전 그래픽과 구도와 진입이 둘 다 같으면 하나를 바꾼다.
+ 형식은 말의 종류가 고른다: 대비 = 사진 두 장 또는 두 열 / 순서 = 단계 도식 / 증거 = 자료 전면 + 주석 / 선언 = 아래 띠나 반전 면의 한 문장 / 이름 붙이기 = 옆 메모.
+ 같은 도식(더블 다이아몬드 등)을 다시 쓸 때는 새 그래픽이 아니라 **같은 판 위의 변화**(highlight 이동, 손 주석 추가)로 잇는다. 세 번째부터는 필요한 부분만 크게 자른다.
+ 챕터마다 '키'를 정해 `reason` 에 적는다: 종이 무늬(무지 · 모눈 · 괘선) 하나 + 주 진입(붙이기 · 쓸기 · 펼치기 · 괘선 먼저) 하나. 그 챕터 그래픽의 60% 이상이 키를 따른다.
+ 챕터마다 증거 전면(실물 자료가 프레임을 채우는 화면)을 1회 이상 넣는다.
```

## 5번 롱폼 화면 언어

```diff
- 화면 배경은 짙은 구겨진 종이(흰 글씨 + 주황 강조 1개) — 색을 더 쓰지 않는다.
+ 화면 재질은 영상 전체에서 하나다: 웜 잉크 책상 위의 크림 종이, 잉크 글씨, 주황 시그널 한 곳(면적 6% 이하).
- 키워드에 `body` 로 역할("원칙", "예시", "결론")을 주면 메모의 배지가 되고, 14자 이하면 핵심 줄이 반전 상자로 찍힌다.
+ 키워드의 `body` 는 정보가 있는 역할("이유", "예시", "결론", "반론")일 때만 준다. 같은 역할 라벨을 3회 연속 쓰지 않는다. 14자 이하면 핵심 줄이 반전 상자로 찍힌다.
```

## 새 항목 6 — 화면에 내지 않는 글자

```diff
+ 6. 템플릿 이름(`motion` `card` `keyword`), 종류값(`brand` `video`), 검색어, 연출 메모("…을 보여준다"), 발화 번호(S12), 영어 내부 낱말은 `title`·`body`·`label`·카드 글자 어디에도 쓰지 않는다. 장면의 `label` 은 한국어 역할 한 낱말이거나 비운다.
+    제목은 그 순간의 주장이다. "핵심", "포인트", "중요", "개념", "정리"를 단독으로 쓰지 않는다.
```

## 스키마에 함께 넣을 것(`studio/agents/schemas.py MOTION`)

- `scenes[].hero`(정수), `scenes[].motion_reason`(문자열), `scenes[].layout_name`(side | desk | sheet | evidence | stack | strip)
- `cards[].layout_name`, `cards[].canvas`(long | short)
- 챕터 키는 새 필드를 만들지 않고 각 그래픽의 `reason` 첫머리에 `[키: 모눈 · 붙이기]` 로 적는다.
