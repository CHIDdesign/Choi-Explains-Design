# 사용한 디자인 스킬과 오픈소스 출처

AI 스튜디오의 "디자인 감각"은 GitHub 에 공개된 Claude 에이전트 스킬과 영상 자동화 저장소에서 가져왔습니다. **라이선스가 허락하는 것만 저장소에 포함**했고, 라이선스가 없거나 비상업 조건인 것은 원칙만 요약하고 설치 방법을 적었습니다.

## 1. 저장소에 포함한 스킬(`.claude/skills/`)

이 폴더에서 Claude Code 를 실행하면 자동으로 인식됩니다. 앱은 이 스킬의 원칙을 `prompts/skills/*.md` 로 정리해 모든 에이전트의 시스템 프롬프트에 넣습니다.

| 스킬 | 출처(커밋) | 라이선스 | 앱에 반영된 것 |
|---|---|---|---|
| `motion-framer` | [freshtechbro/claudedesignskills](https://github.com/freshtechbro/claudedesignskills/blob/main/.claude/skills/motion-framer/SKILL.md) (`1da73fe`) | MIT | variants 로 상태 정의, stagger, spring 물리값, exit 애니메이션 → `design/motion.ts` 의 `STAGGER`·`SPRING`, 모션 DSL 의 `enter`/`keys` |
| `modern-web-design` | 같은 저장소 | MIT | 2024~ 디자인 트렌드(대담한 타이포, 여백, 마이크로 인터랙션), 접근성·대비 체크 → 스타일 가이드와 아트 디렉터 체크리스트 |
| `video-editing-skill` | [6missedcalls/video-editing-skill](https://github.com/6missedcalls/video-editing-skill) (`7dc6e1d`) | MIT | 무음 기반 점프컷, 트림, 자막 번인, 텍스트 오버레이 순서 → 편집 원칙(`prompts/skills/editing_craft.md` 로 대체) |

각 폴더에 원본 `LICENSE` 가 함께 있습니다.

## 2. 포함하지 않고 원칙만 쓴 스킬

| 스킬 | 이유 | 반영 | 직접 설치(선택) |
|---|---|---|---|
| [delphi-ai/animate-skill](https://github.com/delphi-ai/animate-skill) (`71bc617`) | 저장소에 라이선스 파일이 없음 → 복사하지 않음 | 이징 선택(ease-out 등장·ease-in 퇴장), 퇴장은 등장의 약 75% 길이, 200~300ms 규칙, `prefers-reduced-motion` 정신 → `design/motion.ts` 토큰과 `prompts/skills/motion_principles.md` | `npx skills add https://github.com/delphi-ai/animate-skill --skill animate` |
| [remotion-dev/skills](https://github.com/remotion-dev/skills) | Remotion License(개인·3인 이하 회사 무료) | `interpolate`+`Easing.bezier`, CSS 애니메이션 금지, 폰트 로딩, `OffthreadVideo` 등 렌더러 구현 전반 | `npx skills add remotion-dev/skills` |
| [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes) | Apache-2.0(엔진이 달라 코드는 쓰지 않음) | 자막은 조용한 레일 + 드문 강조, 1080p 약 46px, 퇴장은 말하는 중에 하지 않음, 강조는 한 구절에 하나 | — |
