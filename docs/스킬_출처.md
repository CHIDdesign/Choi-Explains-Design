# 사용한 디자인 스킬과 오픈소스 출처

AI 스튜디오의 "디자인 감각"은 GitHub 에 공개된 Claude 에이전트 스킬과 영상 자동화 저장소에서 가져왔습니다. **라이선스가 허락하는 것만 저장소에 포함**했고, 라이선스가 없거나 비상업 조건인 것은 원칙만 요약하고 설치 방법을 적었습니다.

## 1. 저장소에 포함한 스킬(`.claude/skills/`)

이 폴더에서 Claude Code 를 실행하면 자동으로 인식됩니다. 앱은 이 스킬의 원칙을 `prompts/skills/*.md`(편집·기획 역할의 시스템 프롬프트)와 `prompts/skills/agents/<이름>.md`(그 에이전트의 지시 끝)로 정리해 넣습니다. 디자인 역할과 가벼운 역할(`LEAN_AGENTS`)은 공통 노트를 받지 않습니다.

| 스킬 | 출처(커밋) | 라이선스 | 앱에 반영된 것 |
|---|---|---|---|
| `motion-framer` | [freshtechbro/claudedesignskills](https://github.com/freshtechbro/claudedesignskills/blob/main/.claude/skills/motion-framer/SKILL.md) (`1da73fe`) | MIT | variants 로 상태 정의, stagger, spring 물리값, exit 애니메이션 → `design/motion.ts` 의 `STAGGER`·`SPRING`, 모션 DSL 의 `enter`/`keys` |
| `modern-web-design` | 같은 저장소 | MIT | 2024~ 디자인 트렌드(대담한 타이포, 여백, 마이크로 인터랙션), 접근성·대비 체크 → 스타일 가이드와 아트 디렉터 체크리스트 |
| `video-editing-skill` | [6missedcalls/video-editing-skill](https://github.com/6missedcalls/video-editing-skill) (`7dc6e1d`) | MIT | 무음 기반 점프컷, 트림, 자막 번인, 텍스트 오버레이 순서 → 편집 원칙(`prompts/skills/editing_craft.md` 로 대체) |

각 폴더에 원본 `LICENSE` 가 함께 있습니다.

## 6. 색·음향 수식을 다시 구현한 곳: FilmCraft

[storytold/filmcraft](https://github.com/storytold/filmcraft) (`29e6937`, MIT OR Apache-2.0, Copyright (c) 2026 ArtCraft Team and the FilmCraft contributors). 독립 오픈소스 NLE 이고, 코드를 옮기지 않고 공개된 수식만 우리 구조에 맞게 다시 썼습니다. 프로그램 연동은 하지 않습니다.

| 우리 코드 | FilmCraft 위치 | 가져온 수식 | 우리가 바꾼 것 |
|---|---|---|---|
| `studio/grade/auto.py apply_tone` | `crates/render/src/effects.rs:691-699` | 휘도 3제곱 가중 + 채널 비율 스케일(색상 보존) | 누르는 쪽만, 세기는 룩 `rolloff` × `HL_PER_ROLLOFF` |
| `studio/grade/auto.py apply_wheels` | `crates/render/src/effects.rs:1388-1397` | 3구간 휠(lift·중간·gain) | 기준 프레임 맞춤 안에서만 사용 |
| `studio/grade/auto.py solve_match` | `crates/render/src/color_match.rs:204-290` | 3톤 Oklab 통계를 맞추는 LM 역산 | 감마 프레임을 선형화해 입력, `user/reference_frames` 옵트인, 색 잡음·얼룩 검사 통과 때만 |
| `studio/edit/assemble.py _cut_wav` | `crates/render/src/transitions.rs:75-81` | equal-power 이득 공식 | 앞 keep 을 끝까지 두고 원본 핸들을 다음 머리에 섞는 단방향 구조(출력 표본 수 불변) |
| `studio/media/mix.py voice_activity` | `crates/engine/src/essential_sound.rs:336-378`, `crates/audio-dsp/src/ducking.rs` | 5홉 평활 → 틈 메움 → 짧은 활성 제거 순서 | 기존 hang·덕킹 곡선은 그대로 |
