# 롱폼 무대(Stage) — 롱폼만의 디자인 로직과 편집법

숏폼(릴스식)은 **세로로 쌓는다**: 위 카드 한 장 · 아래 얼굴 · 이음새 굵은 자막, 순간마다 카드를 갈아 끼운다.
롱폼(16:9 강의)은 그 반대다. 시청자는 앉아서 10분 넘게 보고, 화면은 가로로 넓고, 무엇보다 **지금 어디쯤 왔고 무슨 주장을
쌓는 중인지**를 알아야 이해가 된다. 그래서 롱폼은 숏폼 카드를 옮겨 오지 않고 자기 로직으로 짠다.

## 1. 원칙 다섯 가지

| | 숏폼(릴스) | 롱폼(무대) |
|---|---|---|
| 화면 나누기 | 세로 스택(카드 ↑ 얼굴 ↓) | **가로 무대**: 화자 열(36%) + 작업대 열(64%) |
| 요소의 수명 | 카드 한 장이 3~5초, 계속 교체 | 요소가 **머물고 쌓인다**(보드·정리) |
| 첫 임무 | 훅 — 1초 안에 붙잡기 | **오리엔테이션** — 지금 어디, 무슨 주장 |
| 강조 언어 | 형광펜 · 드롭인 · 팝 | **밑줄 스윕 · 괘선 그리기 · 마스크 슬라이드** |
| 재질 | 흰·크림·짙은 종이 카드 | 잉크 위 **두 장의 판**(화자 판 · 보드 판) + 유리 플레이트 |

1. **그리드가 먼저** — 모든 요소는 같은 자리에 놓인다. 플레이트·액자는 상단 84px 기준선, 화자 판·보드 판은 y 84~930(자막 띠 위),
   좌우 여백 40/72. 요소가 화면을 떠돌지 않고, 얼굴을 절대 가리지 않는다(`face_safe_layouts`).
2. **오리엔테이션 장치 셋** — ① 상단 컨텍스트 스트립(챕터 번호·제목 + 챕터 진행 눈금) ② 챕터 카드의 **목차**(전체 챕터,
   지금 챕터 강조) + 주장 한 줄 ③ 챕터 끝 **정리 보드**(그 챕터의 핵심 개념을 모아 7초).
3. **위계 한 가지** — 라벨 칩 → 헤드라인(디스플레이 800, ≤2줄) → 본문 → 각주. 강조는 화면당 한 곳: 헤드라인의 한 낱말
   (강조색 + 밑줄 스윕 10f).
4. **모션 시그니처 한 가지** — 바깥 가장자리에서 안쪽으로 **쓸어 들어오기**(clip-path, 14~18f outQuint) + 괘선 그리기 + 줄
   마스크 슬라이드(3f 스태거). 퇴장은 진입의 75%(페이드 + 8px). 형광펜·드롭인·팝은 숏폼 언어라 쓰지 않는다.
5. **화자는 사람** — 판에 담길 때도 둥근 모서리 22px·얇은 선·부드러운 그림자로 '사람이 있는 창'이지 장식이 아니다.

## 2. 부품(렌더러 `components/longform/`)

| 부품 | 자리 | 내용 | 모션 |
|---|---|---|---|
| **ContextStrip** | 좌상단 (72, 30) | `02` Anton 강조색 + 챕터 제목 20px + 챕터 눈금(지난 챕터 흰 50% · 지금 챕터 강조색이 진행률만큼 · 다음 18%) | 챕터 시작 3.2초 뒤 14f 페이드. 전체화면·보드·타이틀·챕터 카드 동안은 숨김 |
| **ChapterCard**(classic) | 전면 잉크 | 왼쪽 거대 번호, 오른쪽 `( chapter 02 )` → 괘선 → 제목 → **주장**(명조 기울임) → **목차**(전체 챕터, 지금 챕터 강조색 점) | 와이프 전환으로 진입, 줄 마스크 슬라이드 |
| **SpeakerCard** | 화자 열 | 화자를 둥근 판(40/96 여백, 반경 22, 얇은 선, 그림자)에 — 보드가 열릴 때만 | 화자 열로 16f 이동, 반경·선이 같이 자란다 |
| **BoardPanel** | 작업대 열 | 잉크 판 + 희미한 점 격자 + 머리줄(챕터 칩 · 템플릿 라벨) + 괘선 + 내용 + 바닥줄(브랜드 · 출처) | 바깥 가장자리에서 안으로 쓸어 들어옴 18f |
| **ConceptPlate** | 얼굴 반대편 상단 기준선 | 유리 플레이트(어두운 스크림 + 블러, 얇은 선, 왼쪽 강조 바) 안에 칩 → 괘선 → 헤드라인(강조 낱말 밑줄 스윕) → 본문 → 각주. 숫자는 Anton 카운트업(24f outExpo), 인용은 명조 + 큰 따옴표, 정의는 용어 + 영문(명조 기울임) + 괘선 + 풀이 | 바깥에서 쓸어 들어옴 14f, 줄 스태거 3f, 퇴장 10f |
| **MediaPlate** | 같은 자리 | 둥근 사진·스톡(아주 느린 푸시 1.00→1.05) + 아래 캡션 줄(이름 · 설명 · ▣ 출처) | 같은 시그니처 |
| **RecapBoard** | 보드 판 | 챕터 주장(헤드라인) → 번호 붙은 핵심 개념 2~4줄(Anton 번호 강조색) | 줄마다 5f 스태거, 한꺼번에 보이는 정리(하나씩 등장하는 목록과 다르다) |
| **Callout**(classic) | 화자 반대편 y 28% | 강조색 칩 라벨 + 굵은 2줄 흰 글씨, 핵심어는 강조색 + 밑줄 스윕 | 줄 마스크 슬라이드 10f, 3f 스태거 |

종이 챕터(사용자 템플릿)는 그대로다 — 찢어진 액자·검정 라벨 + 큰 흰 글씨(레퍼런스 3)·구겨진 종이. 하이브리드가 챕터마다
고른다(`studio/edit/style.py`). 숏폼 카드 세 변형(`components/cards/ConceptVariants.tsx`)은 이제 **숏폼에서만** 쓴다.

## 3. 편집법(파이프라인)

- **챕터 = 카드 → 본문 → 정리** : 챕터 카드(목차·주장) → 본문(플레이트 · 보드 · 전면 그래픽, 8~15초에 하나, 얼굴만 최대
  12초) → 챕터 끝 7초 **정리 보드**(`studio/render/props.py chapter_recaps`: 그 챕터의 키워드·정의·숫자·목록·비교·도식
  제목을 시간순으로 모아 2~4개, 45초 넘는 챕터만, 다른 그래픽과 겹치지 않는 가장 늦은 빈 창에, 5초까지 줄여서라도).
  AI 는 정리 목록을 따로 만들지 않는다(앱이 넣는다).
- **챕터 카드에 목차** : `chapter_maps` 가 챕터 카드 데이터에 전체 챕터 제목(items)과 지금 챕터(highlight)를 넣는다.
- **콜아웃은 주석** : 자막과 별도 레이어, 형광펜 대신 밑줄 스윕. 얼굴 옆 빈 공간에만(자리가 없으면 띄우지 않는다).
- 그 밖(프레이밍 100↔106, 글라이드 강조, 블러·푸시·와이프·빛샘 전환, 효과음)은 `studio/edit/grammar.py` 그대로.

## 4. 수치(1920×1080, 30fps)

```
STAGE.margin 72 · STAGE.top 84(플레이트 기준선) · 화자 열 36%
화자 판  x 40 / y 84 / w 611 / h 846 / r 22          (panelSide=right 기준, left 면 좌우 반전)
보드 판  x 699 / y 84 / w 1181 / h 846 / r 22 · 안쪽 여백 56 · 점 격자 28px · 아래 150 은 자막 띠
플레이트 w 420~700(얼굴 여유에 맞춤) · h = w×0.58(개념) / w×0.74(사진) · 안쪽 여백 36×s(s = w/700)
글자     칩 19×s · 헤드라인 ≤60×s(보드 96) · 본문 26×s(보드 34) · 각주 19×s(보드 22) · 숫자 Anton 132×s(보드 220)
모션     쓸어 들어오기 14f(플레이트)/18f(보드) outQuint · 괘선 12f · 줄 스태거 3f · 밑줄 스윕 10f · 퇴장 10f
```
