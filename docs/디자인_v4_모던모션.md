# 디자인 v4 — 모던 모션 (2026-10-02)

채널 주인의 레퍼런스(테크 설명 영상·쇼릴 8장): 흰/연한 색 밝은 무대 또는 검정 어두운 무대, 자간을 좁힌 굵은 산세리프 키네틱 타이포(한
단어만 이탤릭 세리프), 둥근 흰 UI 목업 카드·칩·말풍선, 3D 아이소메트릭 도시·건물, 모니터/노트북 목업, 모서리의 작은 기술 라벨, 물·액체
질감. 요청: "모션 그래픽과 스톡 이미지·영상을 최대한 많이, 엄청 풍부하게. 내 얼굴이 항상 안 나와도 된다. 색은 이 오렌지."

v3(종이 콜라주·명조)는 `collage` 표면·`PRESS_FONT`·`components/press/` 로 남아 있지만 기본 룩에서는 쓰지 않는다.

## 1. 측정값(이미지는 저장소 밖)

- 채널 오렌지 `#FC5400`(RGB 252·84·0) — 흰 바탕 글자용 짙은 톤 `#D94600`, 칩·행·형광용 옅은 톤 `#FFD7C4`. `props.PALETTES["ember"]`, 설정 기본.
- 어두운 무대 `#121214`(레퍼런스의 구겨진 차콜 `#2A2A2F` 와 쇼릴의 검정 사이). 밝은 무대 `#F7F8F6` + 아래쪽 옅은 디자인 색 번짐.
- 잉크 `#121315`, 흐린 잉크 64%, 선 10%. 그림자 `softShadow(1~3)`: 위에서 하나(dx:dy = 3:8), 넓게 번짐.

## 2. 서체(`tokens.ts FONT` — 역할 이름은 그대로, 글꼴만 바뀜)

거의 모든 역할 = Pretendard(헤드라인 800 자간 −0.035em 행간 1.06 · 본문 500 · 라벨 600 대문자 자간 0.14em · 큰 숫자 900 자간 −0.05em).
`italic`·`numeral`·`hand` = Instrument Serif 이탤릭(영문·숫자·연도). 헤드라인의 `*강조 어절*` 하나는 이탤릭 세리프 — 한글은 Instrument
Serif 에 글리프가 없어 번들 고운바탕 700 + `skewX(-8deg)` 합성(`Modern.tsx accentFont`). 명조 본문·손글씨·블랙한산스는 쓰지 않는다.

## 3. 부품(`renderer/src/components/modern/`)

- `Modern.tsx` — `ModernStage`(밝은/어두운 무대) · `CornerLabels`(모서리 라벨 + 꺾쇠) · `CornerMarks`(제목 둘레 네모 넷) · `Headline`
  (어절마다 마스크 등장 3f 간격, `*강조*`) · `Echo`(짧은 문장의 흐린 메아리) · `Pill`(✓ 칩, card/tint/accent) · `Bubble`(말풍선 + 꼬리) ·
  `UIPanel`(흰 둥근 카드 + 제목 줄 + 둥근 행, 3D 틸트) · `DeviceFrame`(monitor·laptop·phone) · `IsoBlocks`(아이소메트릭 블록 도시 + 길) ·
  `BigNumeral`(구두점만 색) · `FootageText`(가는 머리말 + 굵은 본문, 어둠) · `CutoutScene`(오린 사물 + 바닥 그림자 + 칩 + 헤드라인) ·
  `SpeakerFrame`(화자 둥근 흰 카드).
- `Titles.tsx` — `ModernTitle` · `ModernChapter` · `ModernEndCard`. `Panels.tsx` — `ModernPlate`(pip/overlay 흰 카드) · `ModernPanel`(split).
- 표면 `surfaces.ts`: 기본 `modern`, 모션 `bg: ink` → `dark`. 카드 변수 `--paper`=밝은 무대 · `--white`=흰 카드 · `--ink`.
- 템플릿 분기: 키워드(헤드라인 + 코너 마크 + 칩 + 메아리) · 숫자(`BigNumeral`) · 목록(둥근 행, 지금 행은 흰 카드) · 사진/스톡 전면
  (`FootageText`·`Pill`, 필름 룩 없음, 오린 사진은 `CutoutScene`) · 자막(흰 둥근 상자 + 부드러운 그림자).

## 4. 배분 정책(스타일 가이드 2·3·4절, 플레이북 01)

얼굴만 ≤20%(10–30) · 실물 자료 ≥45% · 모션·카드·도식 ≥30% · 풀스크린 합계 ≤90% · 얼굴 없는 구간 최대 90초 · 맨얼굴 25초 이하 ·
스톡 12~20개. 게이트 A8 8~40% · B1 ≥40%(목표 45~65%).
