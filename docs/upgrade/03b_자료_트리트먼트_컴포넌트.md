# 03b. 자료 트리트먼트 컴포넌트 — 사진을 "붙이지" 않고 "편집"한다

> 조달·스키마: [`03_자료_조달_엔진_v2.md`](03_자료_조달_엔진_v2.md). 게이트 B2: [`08_품질_게이트.md`](08_품질_게이트.md). 권리 제약: [`저작권_위험등급_정책.md`](저작권_위험등급_정책.md).
> 근거 실측: 테스트 영상의 실물 이미지 5개는 전부 pip(액자 폭 538~647px ≈ 화면 면적 13%), 전면 0회, 처리 방식은 "느린 푸시인" 한 가지였다.

## 0. 공통 규칙

1. **크기 규칙.** 증거 이미지는 **챕터마다 한 번 이상 전면**으로 나온다. 전면 = 풀블리드(`full`) 또는 화면 면적의 55% 이상(`hero`).
   pip 만으로 끝난 챕터는 게이트 B2 가 가장 좋은 자산을 `hero` 로 올린다. 숏폼은 증거가 있으면 한 번은 위 구역 전체(`reelTop`)로 쓴다.
2. **모션.** `useCurrentFrame()` + `interpolate()` 만 쓴다. 토큰은 `renderer/src/design/motion.ts`(`EASE`·`DUR`·`LONG`·`STAGGER`·`tween`·`tweenOut`). CSS transition/animation 금지.
3. **필터.** 화면 전체 SVG 필터(`feTurbulence` 등)·매 프레임 바뀌는 필터 금지. 입자는 `useNoiseTile`, 듀오톤·누끼 테두리·흐림은 **파이썬 전처리로 구워서**(`assets/prep.py`) 파일로 받는다.
4. **젠틀.** 진입은 `outQuint`/`outCubic`, 화면 안 이동은 `inOutCubic`, 퇴장은 `LONG.out`(10f). 팝·바운스·휩 없음. 스텝(2프레임 홀드) 움직임은 펀치 구간에서만.
5. **색.** 크림 종이(`NOTE.paper`)·웜 잉크(`NOTE.ink`)·시그널(`theme.accent`) 세 가지. 주석·밑줄은 시그널, 한 화면에 시그널은 한 곳.
6. **글자.** 라벨 = 주장의 한 조각(Jua/Pretendard 800), 캡션 = 사실(Pretendard 500 + `Numerals`), 손글씨 주석은 26px 이상(`FONT.hand`). 검색어·연출 메모·enum 은 오지 않는다(조달 단계에서 차단).
7. **렌더 속도.** `full`·`hero` 는 화자를 완전히 덮는 그래픽으로 취급한다(`LongForm` 의 `COVER_PAD` 규칙 — 가운데 구간에서 화자 영상을 그리지 않는다).
8. **등급 제약.** C 등급은 `full` 금지(`hero`·`board`·`doc_highlight`·`browser_frame` 만), 한 번 6초 이내. A-sa 는 `cutout`·합성 금지(설정으로 해제). B 는 크롭·재색 금지.

## 2. 무대 치수

좌표는 [`06_모션_그래픽_v2.md`](06_모션_그래픽_v2.md) 4-2 의 이름 붙인 구성(제안값)을 따른다. 괄호는 현행 코드 값이다.

| 이름 | 16:9 (1920×1080) | 면적 | 쓰임 |
|---|---|---|---|
| `full` | 구성 D(증거 전면): 0, 0, 1920×1080. 주석 블록 `96, 560, ≤852×320`, 출처 오른쪽 위 `y 54` | 100% | A·own 등급 사진·스톡 영상. 2.5~6초 |
| `hero` | 구성 C(전면 종이): 종이 내용 `96, 84, 1728×796` → 이미지 창 **1680×684** + 캡션 줄 64 | 55% | 기본 전면. 세로·정사각 이미지는 창 안에 맞춰 넣고 남는 곳은 종이 |
| `board` | 구성 B(책상): 종이 판 `680, 84, 1144×796`, 내용 1048×700 → 이미지 창 1048×636 (현행 `boardCard()` 1181×846) | 32% | 화자를 보이며 설명할 때 |
| `pip` | 구성 E(겹친 두 장): 사진 `96, 96, 706×440`, 얼굴과 가까우면 560×350 (현행 700×520 → 420) | ≤ 15% | 지나가는 언급. 챕터의 유일한 자료면 안 된다 |

| 이름 | 9:16 (1080×1920, `ReelShort`) | 면적 | 쓰임 |
|---|---|---|---|
| `reelTop` | 0, 0, 1080×830(이음새 `SEAM` 위 전체) | 43% | 숏폼의 전면. 아래 가장자리는 종이 그라디언트로 얼굴과 잇는다 |
| `reelCard` | `CARD` 980×720 @ (50, 70) | 34% | 카드 안 자료 + 캡션 |
| `reelFull` | 0, 0, 1080×1920 | 100% | 훅 첫 2.5초 안에서만 |

`hero`·`board` 는 무대 상자 `y 84~880` 안에 있어 자막 띠(`y 900~1026`)와 겹치지 않는다. 출처 줄은 16:9 22px 이상, 9:16 26px 이상(06 문서).
여러 그래픽을 잇는 시퀀스(증거 쌓기·몽타주)는 [`05_편집_문법_v2.md`](05_편집_문법_v2.md)의 `sequences` 가 맡는다. 이 문서의 `sequence` 는 **한 그래픽 안에서** 여러 장을 넘기는 것이다.

## 3. `EvidenceFrame` — 공통 껍데기

모든 트리트먼트가 이 안에서 그려진다: 종이(또는 풀블리드) + 이미지 창 + 라벨·캡션 + 크레딧.

```tsx
type EvidenceFrameProps = {mode: 'full' | 'hero' | 'board' | 'pip' | 'reelTop' | 'reelCard'; box: Box; frame: number; dur: number;
  label?: string; caption?: string; credit?: string; tier?: EvidenceAsset['tier']; theme: Theme; seed: number;
  children: (win: Box) => React.ReactNode};       // win = 이미지 창

export const EvidenceFrame: React.FC<EvidenceFrameProps> = ({mode, box, frame, dur, label, caption, credit, theme, seed, children}) => {
  const bleed = mode === 'full' || mode === 'reelTop';
  const pad = bleed ? 0 : mode === 'pip' ? 16 : 24;
  const capH = !bleed && (label || caption) ? 64 : 0;
  const win = {x: pad, y: pad, w: box.w - pad * 2, h: box.h - pad * 2 - capH};
  const p = tween(frame, 0, bleed ? DUR.normal : LONG.plateIn, 'outQuint');
  return (
    <div style={{position: 'absolute', left: box.x, top: box.y, width: box.w, height: box.h,
      opacity: p * tweenOut(frame, dur, LONG.out), translate: `0 ${interpolate(p, [0, 1], [bleed ? 0 : 18, 0])}px`}}>
      {bleed ? null : <PaperSheet w={box.w} h={box.h} seed={seed} />}      {/* 크림 종이 + 찢긴 윗변(tornTopPath) + 그림자 */}
      <div style={{position: 'absolute', left: win.x, top: win.y, width: win.w, height: win.h, overflow: 'hidden',
        background: NOTE.paperDeep}}>{children(win)}</div>
      {capH ? <CaptionRow y={win.y + win.h} h={capH} label={label} caption={caption} frame={frame} /> : null}
      <CreditLine text={credit} onPaper={!bleed} opacity={tween(frame, 10, DUR.normal)} />
    </div>
  );
};
```
- 이미지가 창과 비율이 다르면 **자르지 않고 맞춘다**(`contain`) — 포스터·문서·세로 화면. 사진·스톡 영상만 `cover`.
- `CreditLine`: 종이 위는 잉크 50%(22px, 캡션 줄 오른쪽), 풀블리드는 흰색 86% + 그림자(오른쪽 위 `y 54`). C 등급은 "© … · 비평 목적 인용".
- 유지 시간 기본: 단순 사물 2.5~3.5초, 읽을 것이 있는 이미지(포스터·화면) 4~6초, 주석 1개마다 +0.8초.

## 4. `FocusMove` — 대상을 아는 켄 번즈

현행 `Photo.tsx`(1.00→1.05 선형, 화면 중앙 기준)를 대체한다. 초점 상자를 향해(또는 거기서부터) 움직인다.

```tsx
type FocusMoveProps = {asset: EvidenceAsset; win: Box; frame: number; dur: number;
  move?: 'in' | 'out' | 'pan'; amount?: number; fit?: 'cover' | 'contain'};   // amount 0.04~0.08(기본 0.06)

export const FocusMove: React.FC<FocusMoveProps> = ({asset, win, frame, dur, move = 'in', amount = 0.06, fit = 'cover'}) => {
  const [fx, fy, fw, fh] = asset.focus ?? [0.3, 0.3, 0.4, 0.4];
  const cx = (fx + fw / 2) * 100, cy = (fy + fh / 2) * 100;                    // 변형 원점 = 초점 중심
  const t = interpolate(frame, [0, dur], [0, 1], {extrapolateRight: 'clamp', easing: EASE.inOutCubic});
  const s = move === 'out' ? 1 + amount * (1 - t) : 1 + amount * t;
  const tx = move === 'pan' ? interpolate(t, [0, 1], [-1.5, 1.5]) : 0;        // % — 읽는 방향(좌→우)
  const media = asset.kind === 'video'
    ? <OffthreadVideo src={staticFile(asset.src)} muted style={{width: '100%', height: '100%', objectFit: fit}} />
    : <Img src={staticFile(asset.tone ?? asset.src)} style={{width: '100%', height: '100%', objectFit: fit}} />;
  return <div style={{position: 'absolute', inset: 0, transformOrigin: `${cx}% ${cy}%`, scale: `${s}`, translate: `${tx}% 0`}}>{media}</div>;
};
```
- 방향 규칙: 첫 등장 = `in`(전체 → 대상), 맥락을 여는 장면 = `out`(대상 → 전체), 과정·시간 흐름 = `pan`.
  같은 방향을 3번 잇지 않는다(조달 단계가 번갈아 지정).
- 영상 스톡은 `amount` 0.03. 문서·화면 캡처에는 쓰지 않는다(글자가 흔들린다).
- `cover` 일 때 초점 상자가 잘려 나가지 않게 `objectPosition` 을 초점 중심으로 준다.
- 9:16: 같은 컴포넌트, `amount` 0.08, 세로 창에서는 `pan` 대신 `in`.

## 5. `DocHighlight` — 문서(논문 첫 화면·책 쪽·기사) 밑줄

1차 자료의 기본 처리. 문서 전체가 보이고 → 한 문장만 남기고 어두워지며 → 밑줄이 그어지고 → 종이 메모에 우리말 풀이.

```tsx
type DocHighlightProps = {asset: EvidenceAsset; lines: NBox[]; quote?: string; at?: number; win: Box; frame: number;
  fps: number; theme: Theme; marker?: boolean};     // marker: 숏폼만 형광펜, 롱폼은 밑줄 스윕

export const DocHighlight: React.FC<DocHighlightProps> = ({asset, lines, quote, at = 1.2, win, frame, fps, theme, marker}) => {
  const f0 = Math.round(at * fps);
  const dim = tween(frame, f0, DUR.normal, 'outCubic');
  const k = Math.min(win.w / asset.w, win.h / asset.h);                         // contain
  const ox = (win.w - asset.w * k) / 2, oy = (win.h - asset.h * k) / 2;
  return (
    <div style={{position: 'absolute', inset: 0}}>
      <Img src={staticFile(asset.src)} style={{position: 'absolute', left: ox, top: oy, width: asset.w * k, height: asset.h * k}} />
      <div style={{position: 'absolute', inset: 0, background: 'rgba(38,33,30,0.55)', opacity: dim}} />
      {lines.map(([x, y, w, h], i) => {
        const p = tween(frame, f0 + 4 + i * STAGGER.line, LONG.underline, 'outQuint');
        const L = ox + x * asset.w * k, T = oy + y * asset.h * k, W = w * asset.w * k, H = h * asset.h * k;
        return (
          <React.Fragment key={i}>
            <div style={{position: 'absolute', left: L, top: T, width: W, height: H, overflow: 'hidden', opacity: dim}}>
              <Img src={staticFile(asset.src)} style={{position: 'absolute', left: ox - L, top: oy - T, width: asset.w * k, height: asset.h * k}} />
            </div>
            <div style={{position: 'absolute', left: L, top: marker ? T : T + H + 2, width: W * p, height: marker ? H : 5,
              background: theme.accent, opacity: marker ? 0.32 : 1, mixBlendMode: marker ? 'multiply' : 'normal'}} />
          </React.Fragment>
        );
      })}
      {quote ? <QuoteNote text={quote} frame={frame - f0 - 10} />  /* 종이 메모: Noto Serif KR 40~48px, 오른쪽 아래 */ : null}
    </div>
  );
};
```
- 16:9 `hero` 창(1680×684): 문서는 왼쪽 60%에 세워 두고 오른쪽 40%에 `QuoteNote`. 9:16 `reelTop`: 문서를 창 폭에 맞추고 강조 줄이 세로 중앙에 오게 올린다, 풀이는 아래 얼굴 구역의 자막이 맡는다.
- `lines` 가 없으면(좌표를 못 얻음) 밑줄 없이 문서 + `QuoteNote` 만 낸다.
- 유지: 1.2초(문서 인지) + 풀이 글자 수 ÷ 12 + 1초. 보통 5~7초. C 등급이면 6초에서 자른다.
- 문서 이미지에는 `FocusMove` 를 걸지 않는다. 종이에 놓인 문서가 2° 이내로 기울어 있는 것은 허용.

## 6. `ArchiveCard` — 자료 카드 · 출처 카드

사진 + 사실 메타(연도·작가·소장처)를 한 장의 카드로. 사진이 없으면 **출처 카드**(논문·책)나 **타이포 자료 카드**(대체 사다리의 마지막 칸)가 된다.

```tsx
type ArchiveCardProps = {variant: 'photo' | 'source' | 'type'; asset?: EvidenceAsset; title: string; rows: {k: string; v: string}[];
  box: Box; frame: number; dur: number; theme: Theme; seed: number};

export const ArchiveCard: React.FC<ArchiveCardProps> = ({variant, asset, title, rows, box, frame, dur, theme, seed}) => (
  <PaperNote x={box.x} y={box.y} w={box.w} h={box.h} frame={frame} dur={dur} from="right" theme={theme} seed={seed} pad={36} id={`ac${seed}`}>
    {variant === 'photo' && asset ? <div style={{position: 'relative', height: box.h * 0.58, overflow: 'hidden'}}>
      <FocusMove asset={asset} win={{x: 0, y: 0, w: box.w - 72, h: box.h * 0.58}} frame={frame} dur={dur} amount={0.04} /></div> : null}
    <RiseLine frame={frame} delay={6}><div style={{fontFamily: variant === 'source' ? FONT.serif : FONT.display,
      fontWeight: variant === 'source' ? 600 : 900, fontSize: variant === 'photo' ? 40 : 56, lineHeight: 1.2, color: NOTE.ink}}>{title}</div></RiseLine>
    <Rule frame={frame} delay={10} color={NOTE.rule} />
    {rows.map((r, i) => (
      <RiseLine key={i} frame={frame} delay={12 + i * STAGGER.line}>
        <div style={{display: 'flex', gap: 18, fontFamily: FONT.sans, fontSize: 26, color: NOTE.inkSoft}}>
          <span style={{width: 120, fontWeight: 700, letterSpacing: '0.06em', color: NOTE.note}}>{r.k}</span>
          <span><Numerals text={r.v} /></span></div>
      </RiseLine>))}
  </PaperNote>
);
```
- `source` 예(이번 대본): 제목 "Design fixation" · 저자 `Jansson & Smith` · 저널 *Design Studies* 12(1) · 연도 **1991** · DOI. 저널명은 Playfair italic, 연도는 `Numerals`.
- 크기: `board`(1181×846) 또는 pip 확장판 760×520. 9:16 은 `reelCard`.
- 유지 3.5~5초. 출처 카드 뒤에 `DocHighlight` 나 재현 도식이 이어지면 한 묶음(`sequence`)으로 본다.
- `type` 변형은 실물 사진처럼 보이지 않게 사진 창 없이 글자만 쓴다.

## 7. `BrowserFrame` — 화면 캡처를 브라우저·폰 틀에

"핀터레스트부터 열면" 같은 문장에는 대표 인물 사진이 아니라 **그 화면**을 보여 준다.

```tsx
type BrowserFrameProps = {asset: EvidenceAsset; url?: string; device?: 'browser' | 'phone'; scroll?: number; win: Box;
  frame: number; dur: number};        // scroll 0~1: 전체 페이지 중 어디까지 내려갈지

export const BrowserFrame: React.FC<BrowserFrameProps> = ({asset, url, device = 'browser', scroll = 0.5, win, frame, dur}) => {
  const bar = device === 'browser' ? 56 : 0;
  const vw = device === 'phone' ? Math.min(win.w, win.h * 0.5) : win.w;        // 폰은 세로 틀
  const vh = win.h - bar;
  const k = vw / asset.w;                                                       // 폭 맞춤
  const maxY = Math.max(0, asset.h * k - vh);
  const y = interpolate(frame, [24, Math.max(25, dur - 24)], [0, -maxY * scroll],
    {extrapolateLeft: 'clamp', extrapolateRight: 'clamp', easing: EASE.inOutCubic});
  return (
    <div style={{position: 'absolute', left: (win.w - vw) / 2, top: 0, width: vw, height: win.h, borderRadius: device === 'phone' ? 36 : 14,
      overflow: 'hidden', background: NOTE.paper, boxShadow: '0 10px 28px rgba(0,0,0,0.25)'}}>
      {bar ? <div style={{height: bar, background: NOTE.paperDeep, display: 'flex', alignItems: 'center', gap: 10, padding: '0 20px'}}>
        {[0, 1, 2].map((i) => <i key={i} style={{width: 12, height: 12, borderRadius: 6, background: NOTE.rule}} />)}
        <span style={{marginLeft: 16, fontFamily: FONT.sans, fontSize: 22, color: NOTE.inkSoft}}>{url}</span></div> : null}
      <div style={{position: 'relative', height: vh, overflow: 'hidden'}}>
        <Img src={staticFile(asset.src)} style={{position: 'absolute', left: 0, top: y, width: vw, height: asset.h * k}} /></div>
    </div>
  );
};
```
- 틀은 **도식**이다(회색 점 셋 + 주소). 실제 기기·브라우저 로고를 그리지 않는다. 주소는 도메인만(`pinterest.com`).
- 처음 0.8초는 멈춰 있고(무엇인지 인지) 그 뒤 스크롤, 끝 0.8초 정지. 스크롤 속도는 초당 창 높이의 35% 이하.
- 캡처가 창보다 짧으면 스크롤 없이 정지 + 필요하면 `Annotate`.
- 16:9: `hero` 창 1680×684. 9:16: `reelTop` 안에 폰 틀(폭 430) 또는 브라우저 틀(폭 980).
- 유지 4~6초(C 등급 상한 6초). 캡처 높이는 전처리에서 6000px 로 자른다.

## 8. `Annotate` — 손으로 그린 표시

원·화살표·밑줄·괄호가 **그 단어를 말할 때** 그려진다. "여기를 보라"가 편집의 증거다.

```tsx
type AnnotateProps = {marks: Mark[]; win: Box; img: {x: number; y: number; w: number; h: number}; frame: number; fps: number;
  theme: Theme; seed: number};

export const Annotate: React.FC<AnnotateProps> = ({marks, img, frame, fps, theme, seed}) => (
  <svg width="100%" height="100%" style={{position: 'absolute', inset: 0, overflow: 'visible'}}>
    {marks.map((m, i) => {
      const [x, y, w, h] = m.box;
      const b = {x: img.x + x * img.w, y: img.y + y * img.h, w: w * img.w, h: h * img.h};
      const d = m.type === 'circle' ? wobbleEllipse(b, seed + i) : m.type === 'underline' ? wobbleLine(b, seed + i)
        : m.type === 'bracket' ? bracketPath(b) : arrowPath(b, seed + i);
      const p = tween(frame, Math.round(m.at * fps), m.type === 'circle' ? 16 : LONG.rule, 'outCubic');
      const {strokeDasharray, strokeDashoffset} = evolvePath(p, d);            // @remotion/paths
      return (
        <g key={i}>
          <path d={d} fill="none" stroke={theme.accent} strokeWidth={5} strokeLinecap="round"
            strokeDasharray={strokeDasharray} strokeDashoffset={strokeDashoffset} />
          {m.text ? <text x={b.x + b.w + 14} y={b.y + b.h / 2} fontFamily={FONT.hand} fontSize={34} fill={NOTE.ink}
            opacity={tween(frame, Math.round(m.at * fps) + 8, DUR.fast)}>{m.text}</text> : null}
        </g>
      );
    })}
  </svg>
);
```
- `wobbleEllipse`·`wobbleLine`·`arrowPath` 는 `paper/Paper.tsx` 의 `seeded()` 로 만드는 결정적 경로다(같은 seed → 같은 모양, 프레임마다 흔들리지 않는다). 외부 의존 없이 시작하고, 더 거친 선이 필요하면 rough.js(MIT)의 경로 생성만 빌린다.
- `@remotion/paths` 는 Remotion 과 같은 버전(4.0.530)으로 고정해 더한다.
- 한 화면에 표시 3개까지. 색은 시그널 하나. 글자는 손글씨 34px(최소 26). 풀블리드 사진 위에서는 글자에 종이 띠를 깐다.
- 표시 좌표는 비전 선택 단계가 준다(`focus_box`·주석 `target`). 좌표가 없으면 표시를 그리지 않는다 — 어림으로 그리지 않는다.
- 9:16: 선 굵기 7, 글자 44.

## 9. `DetailZoom` — 전체에서 부분으로

```tsx
type DetailZoomProps = {asset: EvidenceAsset; win: Box; frame: number; fps: number; zoomAt?: number; label?: string; theme: Theme};

export const DetailZoom: React.FC<DetailZoomProps> = ({asset, win, frame, fps, zoomAt = 1.6, label, theme}) => {
  const [fx, fy, fw, fh] = asset.focus!;
  const target = Math.min(2.4, 0.62 / Math.max(fw, fh));                       // 초점 상자가 창의 62%를 채울 때까지
  const t = tween(frame, Math.round(zoomAt * fps), DUR.reveal, 'inOutCubic');
  const s = interpolate(t, [0, 1], [1, target]);
  return (
    <div style={{position: 'absolute', inset: 0, overflow: 'hidden'}}>
      <div style={{position: 'absolute', inset: 0, transformOrigin: `${(fx + fw / 2) * 100}% ${(fy + fh / 2) * 100}%`, scale: `${s}`}}>
        <Img src={staticFile(asset.src)} style={{width: '100%', height: '100%', objectFit: 'contain'}} /></div>
      {label ? <div style={{position: 'absolute', right: 28, bottom: 24, opacity: tween(frame, Math.round(zoomAt * fps) + DUR.reveal, DUR.normal)}}>
        <LabelChip text={label} theme={theme} size={30} /></div> : null}
    </div>
  );
};
```
- 순서: 전체 1.6초 → 줌 0.8초(`DUR.reveal`) → 부분 2.5초 이상. 총 5~6초. 원본이 작아 줌 뒤 긴 변이 창 픽셀의 80% 미만이면 `target` 을 낮춘다(뭉개진 확대 금지).
- 대안(전체를 계속 보여야 할 때): 원형 확대경 인셋(지름 360) — 전체는 그대로 두고 초점만 2배.
- 9:16: `reelTop` 에서 같은 동작. `target` 상한 2.0.

## 10. `ComparePair` · `BeforeAfter` — 나란히 / 전·후

```tsx
type CompareProps = {a: EvidenceAsset; b: EvidenceAsset; labelA: string; labelB: string; mode: 'pair' | 'wipe'; win: Box;
  frame: number; fps: number; wipeAt?: number; theme: Theme};

export const ComparePair: React.FC<CompareProps> = ({a, b, labelA, labelB, mode, win, frame, fps, wipeAt = 2.0, theme}) => {
  if (mode === 'wipe') {                                                        // 같은 구도의 전·후
    const p = tween(frame, Math.round(wipeAt * fps), 30, 'inOutCubic');
    return (<>
      <Img src={staticFile(a.src)} style={{position: 'absolute', inset: 0, width: '100%', height: '100%', objectFit: 'cover'}} />
      <div style={{position: 'absolute', inset: 0, clipPath: `inset(0 0 0 ${(1 - p) * 100}%)`}}>
        <Img src={staticFile(b.src)} style={{width: '100%', height: '100%', objectFit: 'cover'}} /></div>
      <div style={{position: 'absolute', top: 0, bottom: 0, left: `${(1 - p) * 100}%`, width: 4, background: theme.accent}} />
    </>);
  }
  const gap = 48, w = (win.w - gap) / 2;
  return (<>
    {[a, b].map((x, i) => (
      <div key={i} style={{position: 'absolute', left: i * (w + gap), top: 0, width: w, height: win.h - 60, overflow: 'hidden',
        opacity: tween(frame, i * STAGGER.item * 2, DUR.slow), translate: `0 ${interpolate(tween(frame, i * 10, DUR.slow), [0, 1], [18, 0])}px`}}>
        <Img src={staticFile(x.src)} style={{width: '100%', height: '100%', objectFit: 'contain'}} /></div>))}
    <div style={{position: 'absolute', left: w + gap / 2 - 1, top: 0, width: 2, height: (win.h - 60) * tween(frame, 8, LONG.rule), background: NOTE.rule}} />
    {[labelA, labelB].map((t, i) => <div key={t} style={{position: 'absolute', left: i * (w + gap), top: win.h - 48, width: w,
      textAlign: 'center', fontFamily: FONT.round, fontSize: 34, color: NOTE.ink, opacity: tween(frame, 14 + i * 6, DUR.normal)}}>{t}</div>)}
  </>);
};
```
- 16:9 `hero`: 창 816×624 두 개 + 라벨 줄. B 가 A 보다 10프레임 늦게 온다(말의 순서). 9:16: 위아래로 쌓는다(980×340 두 개).
- 한쪽만 구했으면 비교를 만들지 않는다 — 구한 쪽을 `hero` 로, 다른 쪽은 자료 카드로.
- 유지 5~7초. `wipe` 는 화자가 "바뀌었다"를 말하는 순간에 `wipeAt` 을 맞춘다.

## 11. `ImageGrid` · `StackFan` — 여러 장

```tsx
type ImageGridProps = {assets: EvidenceAsset[]; cols: number; win: Box; frame: number; fps: number; pick?: number; pickAt?: number};

export const ImageGrid: React.FC<ImageGridProps> = ({assets, cols, win, frame, fps, pick, pickAt = 2.4}) => {
  const rows = Math.ceil(assets.length / cols), gap = 14;
  const cw = (win.w - gap * (cols - 1)) / cols, ch = (win.h - gap * (rows - 1)) / rows;
  const z = pick == null ? 0 : tween(frame, Math.round(pickAt * fps), DUR.reveal, 'inOutCubic');
  return (<>{assets.map((a, i) => {
    const x = (i % cols) * (cw + gap), y = Math.floor(i / cols) * (ch + gap);
    const p = tween(frame, i * STAGGER.item, DUR.slow, 'outCubic');
    const on = i === pick;
    return (
      <div key={a.src} style={{position: 'absolute', overflow: 'hidden', zIndex: on ? 2 : 1,
        left: on ? interpolate(z, [0, 1], [x, 0]) : x, top: on ? interpolate(z, [0, 1], [y, 0]) : y,
        width: on ? interpolate(z, [0, 1], [cw, win.w]) : cw, height: on ? interpolate(z, [0, 1], [ch, win.h]) : ch,
        opacity: on ? p : p * (1 - 0.75 * z), translate: `0 ${interpolate(p, [0, 1], [14, 0])}px`}}>
        <Img src={staticFile(a.tone ?? a.src)} style={{width: '100%', height: '100%', objectFit: 'cover'}} /></div>);
  })}</>);
};

// StackFan: 3~5장. 각도 [-6, -2, 3, 7]°, 겹친 채 등장 → DUR.reveal 동안 outCubic 으로 펼침(가로 간격 = 카드 폭의 0.42)
```
- 그리드: 4~12장, `cols` 3 또는 4. 칸마다 5프레임 스태거. 다 깔린 뒤 한 장으로 모일 수 있다(`pick`). "이렇게 많다 → 그중 이것".
- 크레딧은 칸마다 달지 않고 아래 한 줄로 묶는다("사진: Wikimedia Commons 기여자 9명 — 설명란 참조"). 전부 A 등급일 때만 그리드를 쓴다.
- 스택: 화자 자료(과제물 여러 장)에 좋다. 카드 폭 620, 흰 테두리 14, 그림자. 숏폼의 부채꼴과 달리 **튀지 않게** 펼친다.
- 16:9 `hero` 창 기준 3×3 은 칸 550×218, 4×2 는 409×335. 9:16 `reelTop` 은 2열.
- 유지: 스태거(0.17초 × n) + 2초, `pick` 이 있으면 +3초.

## 12. `CutoutCollage` — 오려 붙이기

```tsx
type CutoutProps = {items: {asset: EvidenceAsset; x: number; y: number; w: number; rot?: number}[]; frame: number; seed: number};

export const CutoutCollage: React.FC<CutoutProps> = ({items, frame, seed}) => (<>
  {items.map((it, i) => {
    const p = tween(frame, i * STAGGER.item * 2, DUR.slow, 'outCubic');
    const r = it.rot ?? (seeded(seed + i)() - 0.5) * 3;                         // ±1.5°
    return <Img key={i} src={staticFile(it.asset.cutout!)} style={{position: 'absolute', left: it.x, top: it.y, width: it.w,
      rotate: `${r}deg`, opacity: p, translate: `0 ${interpolate(p, [0, 1], [18, 0])}px`,
      filter: 'drop-shadow(0 8px 14px rgba(0,0,0,0.28))'}} />;                  // 요소 하나짜리 그림자만(화면 전체 필터 아님)
  })}
</>);
```
- 누끼와 흰 가위질 테두리(6~8px)는 전처리에서 굽는다(rembg 의 `birefnet-general`·`isnet-general-use` — 기본 모델 `bria-rmbg` 는 상업 이용에 유료 계약이 필요하므로 쓰지 않는다).
- 크림 종이 또는 칠판 위에 1~3개. 제품·인물 누끼 + 손글씨 라벨 + 화살표(`Annotate`)가 기본 조합.
- A·own 등급만. A-sa(CC BY-SA)는 설정 `allow_sa_derivatives` 가 켜졌을 때만. C·B 등급은 금지(변형).
- 누끼 품질이 낮으면(가장자리 알파 평균으로 판정) `hero` 로 되돌린다.
- 16:9: 종이 `hero` 위에 가장 큰 누끼의 높이 560 이하. 9:16: `reelTop` 에 1~2개, 높이 560 이하.

## 13. `EvidenceSequence` — 한 비트에 여러 장

- 2~3장을 장당 1.8~2.5초로 잇는다: 예) 출처 카드 → 문서 밑줄 → 재현 도식, 인물 → 작품 → 디테일.
- 장 사이는 15프레임 크로스 디졸브 또는 종이 넘김(밀기 12f). 컷마다 트리트먼트가 달라야 한다(같은 푸시인 3연속 금지).
- 한 시퀀스는 그래픽 1개로 센다(게이트 B7 의 반복 계산에서도 1회).
