## 0. 검증 상태와 전제

| 표기 | 뜻 |
|---|---|
| **tsc 통과** | 설치본 `choi studio/renderer/node_modules`(remotion 4.0.530 · @remotion/paths 4.0.530 · @remotion/layout-utils 4.0.530 · gsap 3.15.0 · typescript 5.9.3 · @types/react 19.3.0)를 가리키는 임시 `tsconfig`(`strict`, `noUnusedLocals`, `lib ES2020`)로 형 검사를 통과했다. **렌더는 하지 않았다** |

| **실행 검증 안 함** | 형 검사도 하지 않았다(설계만) |

설치본에서 확인한 것(`node_modules/<패키지>/package.json` 과 `.d.ts`):

| 패키지 | 상태 | 확인한 내보내기 |
|---|---|---|
| `remotion` 4.0.530 | 설치됨 | `Easing.bezier` · `Easing.spring(config)` · `interpolate(..., {output: 'perceptual-scale', posterize})` — `dist/cjs/easing.d.ts`, `interpolate.d.ts` |
| `@remotion/paths` 4.0.530 | 설치됨, **소스에서 import 0건** | `evolvePath` · `getLength` · `getPointAtLength`(→ `Point` 또는 `null`) · `getTangentAtLength`(→ `Point` 또는 `null`) · `interpolatePath` · `scalePath` · `translatePath` · `warpPath` 외 |
| `@remotion/layout-utils` 4.0.530 | 설치됨, **import 0건** | `fitText` · `measureText`(`validateFontIsLoaded`) |
| `gsap` 3.15.0 | 설치됨, 코어만 사용 | `SplitText.js` · `DrawSVGPlugin.js` · `MorphSVGPlugin.js` · `CustomEase.js` · `MotionPathPlugin.js` · `Flip.js` 와 각 `types/*.d.ts` |
| `@remotion/noise` · `motion-blur` · `transitions` · `rough-notation` · `lottie` · `effects` · `shapes` · `animation-utils` | **설치돼 있지 않다** | 이 문서의 레시피는 쓰지 않는다 |

공통 전제:

- 전부 `useCurrentFrame()` + `interpolate()` 다. CSS transition·animation 을 쓰지 않는다.
- CLAUDE.md 의 렌더 속도 규칙을 지킨다: 화면 전체 SVG 필터, 매 프레임 바뀌는 `filter` 를 쓰지 않는다. 흐림이 필요한 층은 파이프라인이 미리 만든 파일을 쓴다(A3).
- 스케치의 `EASE` 는 `06` 6-1 의 값(`enter 0.22,1,0.36,1` · `enterText 0.16,1,0.3,1` · `enterLarge 0.05,0.7,0.1,1` · `move 0.2,0,0,1` · `exit 0.3,0,0.8,0.15` · `settlePaper 0.34,1.35,0.64,1`)이다. 붙일 때는 `design/motion.ts`(06b)의 토큰을 import 한다. `staggerFor`·`stepFrame`·`boil`·`placeIn` 은 06b 의 것을 쓴다.
- 공통 조각: `const clamp = {extrapolateLeft: 'clamp', extrapolateRight: 'clamp'} as const;` · `h01(n)` = `Math.sin(n*127.1+311.7)*43758.5453` 의 소수부(0~1 해시).

**실제 프레임이 보여 준 것 → 레시피**(진단 `00` 3절, `06` 1장):

| 본 것 | 레시피 |
|---|---|
| 사진은 얼굴 옆 작은 액자 5번뿐, 전면 0회. 문서·논문이 한 번도 안 나옴 | A1 쌓이는 자료 · A2 문서에 표시하고 다가가기 · A3 두 층 사진 |
| 도식이 점·원·화살표로 작게, 화살촉이 툭 나타남 | B1 펜 끝 · B2 이어 그리기 · B3 경로 이동 · B4 판 위 카메라 |
| 더블 다이아몬드 5번이 매번 새로 등장, 그래픽마다 각자 페이드 | C1 이어지는 요소 · C2 퇴장 없는 교체 · C3 같은 판 위의 변화 |
| 등장 뒤 얼어 있음(숏폼 `g24` 6.6초) | D1 초점 이동 · D2 숫자와 막대 · D3 낱말 교체 · D4 `keys` 두 개 |
| 글자가 통째로 뜨거나 글자마다 팝 | E1 어절 리빌 · E2 형광펜·밑줄 · E3 카드의 줄 마스크 |

## A. 자료가 도착하고, 쌓이고, 표시된다

### A1. 쌓이는 자료 — 사진·문서가 한 장씩 온다

- **전하는 것**: "근거가 여러 개다", "이만큼 봤다". 한 장씩 말에 맞춰 놓이고, 앞 장은 뒤로 물러난다.
- **언제**: 레퍼런스 여러 장("핀터레스트부터 열면 비슷해진다"), 과제물·스케치 여러 장, 논문 두 편. 한 장에 1.2초 이상(`06` 홀드). 3~4장까지.
- **패키지**: `remotion` 만.
- **오늘 DSL**: 안 된다(`image` 는 서로 모른다). 도형으로 흉내 낸 것은 예제 `process_backfilled` · `only_last_sheet`. → 추가 요청 `stack`.
- **검증**: tsc 통과.

```tsx
export type StackItem = {src: string; atF: number};
export const PhotoStack: React.FC<{items: StackItem[]; w: number; h: number}> = ({items, w, h}) => {
  const frame = useCurrentFrame();
  return (
    <div style={{position: 'relative', width: w, height: h}}>
      {items.map((it, i) => {
        const local = frame - it.atF;
        if (local < 0) return null;
        const p = interpolate(local, [0, 10], [0, 1], {...clamp, easing: EASE.settlePaper});     // 붙이기: 10f
        // 뒤에 온 장 수만큼 뒤로 물러난다(옆으로 비켜나고, 조금 줄고, 종이색 막으로 눌린다)
        const newer = items.reduce((acc, o) => acc + (o.atF > it.atF
          ? interpolate(frame - o.atF, [0, 14], [0, 1], {...clamp, easing: EASE.move}) : 0), 0);
        const rest = (h01(i + 3) - 0.5) * 3;                                                     // 장마다 고정된 기울기 ±1.5°
        return (
          <div key={it.src} style={{position: 'absolute', left: '14%', top: '8%', width: '72%', height: '80%', zIndex: i,
            opacity: interpolate(local, [0, 4], [0, 1], clamp),
            translate: `${-newer * 36}px ${-newer * 10}px`,
            rotate: `${rest + (1 - p) * 2.5}deg`, scale: `${(1.03 - 0.03 * p) * (1 - newer * 0.05)}`}}>
            <div style={{position: 'absolute', inset: 0, background: '#FBF7EE', padding: 14}}>
              <Img src={staticFile(it.src)} style={{width: '100%', height: '100%', objectFit: 'cover'}} />
            </div>
            <div style={{position: 'absolute', inset: 0, background: '#26211E', opacity: Math.min(0.5, newer * 0.22)}} />
          </div>
        );
      })}
    </div>
  );
};
```

- 도착은 `06` 의 `place`(1.03배에서 내려앉고 회전이 0.5° 지나쳤다 돌아옴)와 같은 가족이다. 그림자·테이프의 시간차(`FOLLOW`)는 06b 의 `placeIn` 을 쓴다.
- 뒤로 물러난 장을 어둡게 하는 것은 **종이색 막**이다. `filter: brightness()` 를 프레임마다 바꾸지 않는다.
- 색·테두리는 예시 값이다. 실제로는 `HOUSE`·`paperShadow()`(06b)를 쓴다.

### A2. 문서 한 줄에 표시하고 다가간다

- **전하는 것**: "이 문장이 근거다". 문서 전체를 먼저 보여 주고(무엇인지 알게 한 뒤) 한 줄에 형광펜, 그다음 그 줄로 조금 다가간다.
- **언제**: 논문 첫 쪽(Jansson & Smith 1991), 과제 장표의 한 칸, 화면 캡처의 한 영역. 구성은 `06` 의 D(증거 전면).
- **패키지**: `remotion` 만. 손으로 친 동그라미·밑줄이면 `06` 의 `mark`.
- **오늘 DSL**: 안 된다. `06` 7-1 의 `doc` + `mark` 로 표시까지는 된다. 다가가기는 추가 요청 `camera`.
- **검증**: tsc 통과.

```tsx
export const DocAnnotate: React.FC<{src: string; W: number; H: number; line: {x: number; y: number; w: number; h: number};
  markAtF: number}> = ({src, W, H, line, markAtF}) => {
  const frame = useCurrentFrame();
  const mark = interpolate(frame, [markAtF, markAtF + 10], [0, 1], {...clamp, easing: EASE.enter});
  // 표시가 끝나고 0.5초 뒤, 26f 에 걸쳐 그 줄로 1.12배 다가간다
  const z = interpolate(frame, [markAtF + 25, markAtF + 51], [1, 1.12], {...clamp, easing: EASE.move});
  const k = (z - 1) / 0.12;
  const cx = W / 2 + (line.x + line.w / 2 - W / 2) * k;
  const cy = H / 2 + (line.y + line.h / 2 - H / 2) * k;
  return (
    <div style={{position: 'absolute', inset: 0, overflow: 'hidden'}}>
      <div style={{position: 'absolute', left: 0, top: 0, width: W, height: H, transformOrigin: '0 0',
        transform: `translate(${W / 2 - cx * z}px, ${H / 2 - cy * z}px) scale(${z})`}}>
        <Img src={staticFile(src)} style={{width: W, height: H, objectFit: 'cover'}} />
        <div style={{position: 'absolute', left: line.x, top: line.y, width: line.w * mark, height: line.h,
          background: 'rgba(232,104,44,0.38)', mixBlendMode: 'multiply'}} />
      </div>
    </div>
  );
};
```

- 순서가 규칙이다: **표시 → 0.5초 → 다가가기 → 1초 정지**. 표시와 줌을 동시에 하면 히어로 무브가 둘이다(`motion_craft.md` 3).
- 줌은 1.12배까지다. 카메라에는 오버슛을 쓰지 않는다. 강조 글라이드가 도는 동안과 앞뒤 6f 에는 겹치지 않게 한다(`motion_craft.md` 15).

### A3. 사진 한 장을 두 층으로

- **전하는 것**: 평평한 사각 사진이 아니라 "종이 위에 놓인 프린트". 사진 한 장으로 4~8초를 버틴다.
- **언제**: 전면 사진(`06` 의 D, 게이트 B2). 연속한 사진은 방향을 번갈아 준다.
- **패키지**: `remotion` 만. 흐린 배경은 `studio/broll/` 이 Pillow 로 **미리** 만든다.
- **오늘 DSL**: 템플릿 `photo`/`broll` 의 렌더러 변경이다(`Photo.tsx`·`Broll.tsx`). 지금 `Photo.tsx` 는 `interpolate(frame, [0, dur], [1.0, 1.05])` 한 줄이다.
- **검증**: tsc 통과.

```tsx
export const PhotoTwoLayer: React.FC<{src: string; blurredSrc: string; index: number; dur: number; focus?: [number, number]}>
  = ({src, blurredSrc, index, dur, focus = [50, 45]}) => {
  const frame = useCurrentFrame();
  const t = interpolate(frame, [0, dur], [0, 1], clamp);       // 장면 전체에 걸친 푸시인은 등속(사진에만)
  const dir = index % 2 ? -1 : 1;
  const reveal = interpolate(frame, [0, 18], [0, 1], {...clamp, easing: EASE.enterLarge});
  return (
    <AbsoluteFill style={{overflow: 'hidden', background: '#26211E'}}>
      <Img src={staticFile(blurredSrc)} style={{position: 'absolute', left: '-6%', top: '-6%', width: '112%', height: '112%',
        objectFit: 'cover', translate: `${dir * -12 * 0.3 * t}px 0`}} />
      <div style={{position: 'absolute', left: '12%', top: '9%', width: '76%', height: '70%', overflow: 'hidden',
        clipPath: `inset(0 ${(1 - reveal) * 100}% 0 0)`, rotate: `${dir * -1.2}deg`, translate: `${dir * -12 * t}px ${-6 * t}px`}}>
        <Img src={staticFile(src)} style={{width: '100%', height: '100%', objectFit: 'cover',
          scale: `${1.02 + 0.04 * t}`, transformOrigin: `${focus[0]}% ${focus[1]}%`}} />
      </div>
    </AbsoluteFill>
  );
};
```

- **등장은 래퍼에, 줌은 자식에** 둔다(HyperFrames). 같은 요소에 진입 트윈과 푸시인을 같이 걸면 서로 싸운다.
- 줌 초점(`transformOrigin`)은 피사체다. 얼굴 사진이면 얼굴 상자, 문서면 표시할 줄.
- 층의 이동 비는 뒤 0.3 · 앞 1.0(claude-remotion-skill, iart). 배경 제거 컷아웃이 생기면 세 층(0.3 · 1.0 · 글자 1.3)으로 늘린다.

### A4. 뒤에 쌓여 있던 것이 빠져나온다 (오늘 DSL)

- **전하는 것**: "보이는 것 뒤에 과정이 있었다". 앞 장 뒤에 숨어 있던 장들이 부채처럼 빠져나왔다가 흐려진다.
- **오늘 DSL**: 된다. `rect` 여러 장에 `keys` 로 `x`·`rotate` 를 주고, 장마다 키 시각을 0.12초씩 어긋나게 한다(겹치는 동작). 배열 순서가 겹침 순서이므로 뒤 장을 배열 앞에 둔다.
- **검증**: clean_spec 통과 — 예제 `only_last_sheet`(실제 `g23` 구간의 단어 시각 사용).

## B. 읽을 수 있는 크기의, 그려지는 도식

### B1. 선을 그리는 동안 펜 끝이 따라간다

- **전하는 것**: "여기에서 저기로". 방향이 처음부터 보인다.
- **언제**: 모든 화살표. 지금은 화살촉이 그리기 92% 지점에서 툭 나타난다(`MotionScene.tsx:246`).
- **패키지**: `@remotion/paths`(설치됨, 지금 import 0건).
- **오늘 DSL**: 스펙은 그대로, **렌더러 기본 동작만 바꾼다**(`ShapeEl` 의 `line`/`arrow`/`path`). DSL 추가 없음.
- **검증**: tsc 통과. `getPointAtLength`·`getTangentAtLength` 가 `null` 을 돌려줄 수 있어 가드가 필요하다는 것을 형 검사에서 확인했다.

```tsx
export const DrawWithPen: React.FC<{d: string; atF: number; frames: number; color: string; width?: number; head?: boolean}>
  = ({d, atF, frames, color, width = 4, head = true}) => {
  const p = interpolate(useCurrentFrame() - atF, [0, frames], [0, 1], {...clamp, easing: EASE.enter});
  const {strokeDasharray, strokeDashoffset} = evolvePath(p, d);
  const L = getLength(d);
  const tip = getPointAtLength(d, L * p);        // 4.0.530 에서 Point | null
  const tan = getTangentAtLength(d, L * p);
  const ang = tan ? (Math.atan2(tan.y, tan.x) * 180) / Math.PI : 0;
  return (
    <g>
      <path d={d} fill="none" stroke={color} strokeWidth={width} strokeLinecap="round"
        strokeDasharray={strokeDasharray} strokeDashoffset={strokeDashoffset} />
      {head && tip && p > 0.03 ? (
        <path d="M -14 -8 L 0 0 L -14 8" fill="none" stroke={color} strokeWidth={width} strokeLinecap="round"
          strokeLinejoin="round" transform={`translate(${tip.x} ${tip.y}) rotate(${ang})`} />
      ) : null}
    </g>
  );
};
```

- 경로 `d` 는 상자 px 좌표로 바꿔서 넘긴다(DSL 의 0~100 좌표를 `scalePath` 로 변환).
- 선은 **무언가에 닿아야** 한다(린트 L24). 실제 `g27` 은 선 셋이 허공에서 끝났다.

### B2. 이어 그리기

- **전하는 것**: 한 붓으로 이어지는 구조(다이아몬드의 네 변, 순환 고리).
- **언제**: 말과 무관하게 한 번에 그려도 되는 뼈대. **단계마다 말이 따로 있으면 쓰지 않는다** — 그때는 말하는 순간에 맞춘다(`motion_craft.md` 8).
- **오늘 DSL**: 된다. 요소마다 `at` 과 `dur` 를 아래 계산대로 적으면 된다(예제 `double_diamond_front` 는 `path` 한 개에 부분 경로 둘을 넣어 차례로 그린다).
- **검증**: tsc 통과(계산 함수).

```ts
export const chainStarts = (lengths: number[], startF: number, pxPerFrame = 40, overlap = 0.75) => {
  const out: {atF: number; frames: number}[] = [];
  let at = startF;
  for (const len of lengths) {
    const frames = Math.max(8, Math.min(18, Math.round(len / pxPerFrame)));   // 길이에 비례
    out.push({atF: Math.round(at), frames});
    at += frames * overlap;                                                   // 앞 선의 75% 시점에 다음 선
  }
  return out;
};
```

묶음 전체가 15f 를 넘으면 장식적 스태거 상한(`06` 6-4)을 넘는다. 그 이상이면 선을 줄이거나 말에 맞춘다.

### B3. 요소가 경로를 따라 간다

- **전하는 것**: "이 길로 갔다". 직선 보간이 아니라 그려 둔 길 위를 간다.
- **언제**: 돌아가는 길을 실제로 **가는** 점, 순환 도식의 현재 위치.
- **패키지**: `@remotion/paths`.
- **오늘 DSL**: 직선 구간만 된다(`keys` 의 x·y). 곡선은 추가 요청 `keys[].along`.
- **검증**: tsc 통과.

```ts
export const alongPath = (d: string, progress: number) =>
  getPointAtLength(d, getLength(d) * Math.max(0, Math.min(1, progress))) ?? {x: 0, y: 0};
```

### B4. 장면 카메라 — 요소가 아니라 판을 움직인다

- **전하는 것**: "전체 중에 지금 여기". 큰 도식 하나를 깔아 두고, 말하는 부분으로 다가갔다가 물러난다.
- **언제**: 같은 도식을 여러 발화에 걸쳐 설명할 때. 더블 다이아몬드를 5번 새로 띄우는 대신 **한 판 위에서 카메라가 옮겨 다닌다**. 이것이 작은 글자 문제의 해법이기도 하다 — 전체를 볼 때는 구조만, 다가갔을 때 라벨을 읽는다.
- **패키지**: `remotion` 만.
- **오늘 DSL**: 안 된다. → 추가 요청 `camera`.
- **검증**: tsc 통과.

```tsx
export type CamKey = {t: number; x: number; y: number; zoom: number};
export const SceneCamera: React.FC<{cam: CamKey[]; W: number; H: number; children: React.ReactNode; overlay?: React.ReactNode}>
  = ({cam, W, H, children, overlay}) => {
  const frame = useCurrentFrame();
  const {fps} = useVideoConfig();
  const ts = cam.map((c) => c.t * fps);
  const pick = (key: 'x' | 'y' | 'zoom') => cam.length < 2 ? cam[0][key]
    : interpolate(frame, ts, cam.map((c) => c[key]), {...clamp, easing: EASE.move});
  const z = pick('zoom');
  const cx = (pick('x') / 100) * W;
  const cy = (pick('y') / 100) * H;
  return (
    <div style={{position: 'absolute', inset: 0, overflow: 'hidden'}}>
      <div style={{position: 'absolute', left: 0, top: 0, width: W, height: H, transformOrigin: '0 0',
        transform: `translate(${W / 2 - cx * z}px, ${H / 2 - cy * z}px) scale(${z})`}}>
        {children}
      </div>
      {overlay /* 괄호 라벨·출처는 카메라 밖 */}
    </div>
  );
};
```

`spec.py` 가 강제할 규칙: `zoom` 1.0~1.3, 이동은 장면당 2회까지(각 22~26f), 내용이 안착하고 0.5초 뒤에 시작, 이동 뒤 `max(1.2초, …)` 정지, 카메라가 움직이는 동안 새 요소를 들이지 않는다. 카메라 이동은 그 장면의 히어로 무브다.

### B5. 도형이 다른 도형이 된다

- **전하는 것**: "같은 것이 변했다"(원이 네모가 된다 = 형태가 바뀌어도 같은 대상). 크로스페이드는 "다른 것으로 바뀌었다"로 읽힌다.
- **패키지**: `@remotion/paths interpolatePath`.
- **오늘 DSL**: 안 된다. → 추가 요청 `path.to`. 꼭짓점 수가 다른 두 경로의 결과는 확인하지 못했다(미확인) — 같은 명령 구성으로 쓰게 제한한다.
- **검증**: tsc 통과.

```tsx
export const MorphShape: React.FC<{from: string; to: string; atF: number; fill: string}> = ({from, to, atF, fill}) => {
  const k = interpolate(useCurrentFrame(), [atF, atF + 18], [0, 1], {...clamp, easing: EASE.move});
  return <path d={interpolatePath(k, from, to)} fill={fill} />;
};
```

## C. 그래픽과 그래픽이 이어진다

### C1. 이어지는 요소 — 앞 그래픽의 그 자리에서 출발한다

- **전하는 것**: "방금 본 그것이다". 같은 낱말·같은 도형·같은 사진이 다음 그래픽에도 있으면, 사라졌다 다시 생기지 않고 **옮겨 간다**.
- **언제**: 사진 → 그 사진 위 키워드(이미 `fold_keywords_into_media` 가 한다), 키워드 → 그 키워드가 제목인 도식, 도식 1 의 주황 원 → 도식 2 의 주인공.
- **패키지**: `remotion` 만.
- **오늘 DSL**: 안 된다. → 추가 요청 `carry`. 파이프라인(`props.py`)이 연속한 두 그래픽의 같은 `carry` 이름을 찾아 앞 상자를 뒤 그래픽에 넘긴다.
- **검증**: tsc 통과(보간 함수). 파이프라인 쪽은 실행 검증 안 함.

```ts
export type Box = {x: number; y: number; w: number; h: number; r: number};
export const carry = (a: Box, b: Box, local: number, frames = 16): Box => {
  const k = interpolate(local, [0, frames], [0, 1], {...clamp, easing: EASE.move});
  const m = (u: number, v: number) => u + (v - u) * k;
  return {x: m(a.x, b.x), y: m(a.y, b.y), w: m(a.w, b.w), h: m(a.h, b.h), r: m(a.r, b.r)};
};
```

이어지는 요소가 그 전환의 히어로 무브다. 나머지 요소는 제자리에서 바뀐다(`swap`).

### C2. 퇴장 없는 교체

- **전하는 것**: 그래픽 둘이 한 묶음이다. 얼굴로 돌아갔다 다시 오지 않는다.
- **언제**: 0.5초 안에 같은 자리에 다음 그래픽이 올 때(`06` 6-2 의 `swap`). 판은 그대로 있고 내용만 바뀐다(`06` 4-4).
- **오늘 DSL**: 그래픽 층의 변경이다(`graphics/index.tsx GraphicLayer`, `props.py`). 지금은 각 그래픽이 `pOut` 으로 페이드한다.
- **검증**: tsc 통과.

```tsx
export const tearClip = (p: number, seed = 1) => {
  const x = -5 + 110 * Math.max(0, Math.min(1, p));
  const edge = Array.from({length: 13}, (_, i) => `${(x + (h01(seed + i) - 0.5) * 3).toFixed(2)}% ${((i / 12) * 100).toFixed(2)}%`);
  return `polygon(0 0, ${edge.join(', ')}, 0 100%)`;
};
export const SwapNoExit: React.FC<{cutF: number; prev: React.ReactNode; next: React.ReactNode; seed?: number}>
  = ({cutF, prev, next, seed = 1}) => {
  const p = interpolate(useCurrentFrame(), [cutF, cutF + 16], [0, 1], {...clamp, easing: EASE.enterLarge});
  return (
    <AbsoluteFill>
      <AbsoluteFill>{prev}</AbsoluteFill>
      <AbsoluteFill style={{clipPath: tearClip(p, seed)}}>{next}</AbsoluteFill>
    </AbsoluteFill>
  );
};
```

- 기본은 `06` 의 `swap`(모션 없이 내용 교체)이다. 찢긴 경계(`tearClip`)는 **챕터 안에서 주제가 넘어갈 때만** 쓰는 변주다. 경계는 시드로 고정해 프레임마다 같은 모양이다.
- 앞 그래픽은 가려질 때까지 **온전히 보인다**. 먼저 페이드아웃하고 다음 것이 등장하면 "딥이 낀 점프 컷"이 된다(HyperFrames).

### C3. 같은 판 위의 변화 (오늘 DSL)

- **전하는 것**: 같은 도식의 다른 부분으로 이야기가 옮겨 갔다.
- **오늘 DSL**: 된다. 템플릿은 `highlight` 만 바꿔 연속 배치(지금 방식), 모션 장면은 한 장면 안에서 `keys` 로 강조를 옮긴다. `motion_addendum.md` 4번("새 그래픽이 아니라 같은 판 위의 변화")과 같다.
- **검증**: clean_spec 통과 — 예제 `double_diamond_front`(주황 점 하나가 탐색 → 정의로 건너가며 커졌다 작아진다).

## D. 등장한 뒤에도 일이 일어난다

얼지 않게 한다는 것은 **떠다니게 한다는 뜻이 아니다.** `motion_craft.md` 는 말과 상관없이 떠다니는 장식, 펄스 반복, 읽히는 중인 글자의 이동을 금한다. 등장 뒤의 움직임은 넷뿐이다: 강조가 옮겨 간다 · 값이 찬다 · 낱말이 바뀐다 · 상태가 변한다.

### D1. 초점 이동

- **전하는 것**: "지금은 이것". 말하는 부분만 남기고 나머지를 40%로 낮춘다.
- **언제**: 8초 넘는 장면의 2막. 목록·단계에서 지금 말하는 항목.
- **오늘 DSL**: 요소마다 `keys` 의 `opacity` 를 두 개씩 적으면 된다(예제 `first_idea_vs_alternatives`). 한 줄로 쓰려면 추가 요청 `focus`.
- **검증**: tsc 통과.

```ts
export const focusDim = (frame: number, t0F: number, t1F: number, focused: boolean) => {
  const f = interpolate(frame, [t0F, t0F + 6, t1F - 6, t1F], [0, 1, 1, 0], clamp);
  return focused ? 1 : 1 - 0.6 * f;                                                              // 나머지는 40%
};
```

흐림(`filter: blur`)은 쓰지 않는다. 불투명도만으로 충분하고 렌더 비용이 없다.

### D2. 숫자가 굴러 멈추고, 막대가 같이 찬다

- **전하는 것**: 양. 숫자와 도형이 **같은 구간·같은 이징**으로 움직여 한 사건으로 읽힌다(HyperFrames stat).
- **언제**: 통계·비율. 수치는 대본에 있는 것만(지어내지 않는다). 수치가 없으면 막대의 상대 길이만 쓴다(예제 `no_example_fixates_more`).
- **오늘 DSL**: `counter` + `bar` 로 되지만 서로 다른 길이·이징이다(`counter` outCubic 1.2초, `bar` outQuint 0.9초). `dur` 를 같게 적으면 구간은 맞는다. 자리마다 구르는 것과 이징 통일은 추가 요청 `counter.roll` · `bar.with`.
- **검증**: tsc 통과.

```tsx
export const NumberRoll: React.FC<{to: number; atF: number; size: number; color: string; suffix?: string}> = ({to, atF, size,
  color, suffix = ''}) => {
  const local = useCurrentFrame() - atF;
  const digits = String(Math.round(to)).split('');
  const done = 24 + digits.length * 2;
  return (
    <span style={{fontSize: size, lineHeight: 1, color, fontVariantNumeric: 'tabular-nums', display: 'inline-flex'}}>
      {digits.map((ch, i) => {
        const p = interpolate(local - i * 2, [0, 24], [0, 1], {...clamp, easing: EASE.enterText});
        const pos = (p * (Number(ch) + 10)) % 10;              // 한 바퀴 돌고 목표 숫자에 멈춘다(오버슛 없음)
        return (
          <span key={i} style={{display: 'inline-block', height: '1em', overflow: 'hidden'}}>
            <span style={{display: 'block', translate: `0 ${-pos}em`}}>
              {'01234567890'.split('').map((d, j) => <span key={j} style={{display: 'block', height: '1em'}}>{d}</span>)}
            </span>
          </span>
        );
      })}
      <span style={{opacity: interpolate(local, [done, done + 6], [0, 1], clamp)}}>{suffix}</span>
    </span>
  );
};
export const barWith = (local: number, value: number) =>
  interpolate(local, [0, 24], [0, value], {...clamp, easing: EASE.enterText});                    // 숫자와 같은 구간·같은 이징
```

단위와 라벨은 숫자가 **멈춘 뒤**에 온다. `bar.label` 은 막대 높이의 0.8배(최소 18px)로 그려져 28px 하한에 걸리니 쓰지 않고 `text` 요소로 따로 적는다(린트 L17).

### D3. 같은 자리에서 낱말이 바뀐다

- **전하는 것**: "A 가 아니라 B". 고쳐 쓰기.
- **언제**: 반전 문장("효율이 아니라 합리화", "서류가 아니라 브레이크"). 영상당 2~3회.
- **오늘 DSL**: 한 자리 교체는 안 된다. 옆에 새 낱말을 찍는 방식은 된다(예제 `efficiency_was_excuse`: 줄 긋기 + 새 낱말). → 추가 요청 `text.swap`.
- **검증**: tsc 통과.

```tsx
export const WordSwap: React.FC<{swaps: {f: number; text: string}[]; width: number}> = ({swaps, width}) => {
  const frame = useCurrentFrame();
  let i = 0;
  for (let j = 0; j < swaps.length; j++) if (frame >= swaps[j].f) i = j;
  const local = frame - swaps[i].f;
  const pin = interpolate(local, [0, 12], [0, 1], {...clamp, easing: EASE.enterText});
  const pout = interpolate(local, [0, 9], [0, 1], {...clamp, easing: EASE.exit});
  return (
    <span style={{display: 'inline-block', position: 'relative', overflow: 'hidden', width, height: '1.15em', verticalAlign: 'top'}}>
      {i > 0 ? <span style={{position: 'absolute', inset: 0, translate: `0 ${-pout * 100}%`}}>{swaps[i - 1].text}</span> : null}
      <span style={{position: 'absolute', inset: 0, translate: `0 ${(1 - pin) * 100}%`}}>{swaps[i].text}</span>
    </span>
  );
};
```

폭은 가장 긴 낱말로 **미리** 잡는다(`measureText`). 그러지 않으면 주변 글자가 밀린다.

### D4. `keys` 두 개로 상태를 바꾼다 (오늘 DSL)

- **오늘 DSL**: 된다. `sampleKeys` 는 요소의 `at` 에서 첫 키까지 **서서히** 보간하므로, 가만히 있다가 바뀌게 하려면 키를 둘 쓴다: `{"t": 4.4, "opacity": 1}`(유지) + `{"t": 4.9, "opacity": 0.35}`(도착).
  실제 스펙 `g23` 의 `keys: [{"t": 2.8, "opacity": 0.3}]` 은 0.5초부터 2.3초 동안 흐려지는 것으로 렌더된다 — 의도와 다를 가능성이 크다.
- 한 장면에서 크게 움직이는 구간은 하나다(린트 L26). 여러 요소가 같은 구간에 같이 움직이면 한 묶음으로 센다.
- **검증**: clean_spec 통과 — 예제 10개 중 9개가 이 방식으로 사건을 만든다.

## E. 글자

### E1. 어절 단위 마스크 리빌

- **전하는 것**: 문장이 말의 단위로 선다. 한국어는 조사가 앞말에 붙으므로 **띄어쓰기 단위(어절)** 가 가장 작은 뜻 단위다. 음절 단위는 글자가 흩어져 읽기 어렵다(10음절 이하 제목에 영상당 2회까지 — `motion_craft.md` 14).
- **언제**: 한 줄 헤드라인. 두 줄 이상이면 줄 단위(줄 간격 3f).
- **패키지**: `@remotion/layout-utils`(설치됨, import 0건) — `fitText` 로 상자 폭에 맞추고 `validateFontIsLoaded` 로 폰트 로드를 확인한다.
- **오늘 DSL**: **이미 된다.** `reveal: "words"`(기본값)는 공백으로 나누므로 곧 어절 단위다(`MotionScene.tsx TextEl`, 2f 간격). 빠진 것은 실측 맞춤과 스태거 상한이다 → 렌더러 변경, DSL 추가 없음.
- **검증**: tsc 통과.

```tsx
export const EojeolReveal: React.FC<{text: string; atF: number; fontFamily: string; fontWeight: number; maxW: number;
  maxSize: number; minSize?: number}> = ({text, atF, fontFamily, fontWeight, maxW, maxSize, minSize = 56}) => {
  const local = useCurrentFrame() - atF;
  const units = text.split(' ');                              // 어절 = 띄어쓰기 단위. 조사·어미는 앞말에 붙어 있다
  const fit = fitText({text, withinWidth: maxW, fontFamily, fontWeight, validateFontIsLoaded: true});
  const fontSize = Math.max(minSize, Math.min(maxSize, fit.fontSize));
  const each = staggerFor(units.length, 2);                   // 낱말 2f, 묶음 전체 ≤ 15f
  return (
    <div style={{fontFamily, fontWeight, fontSize, lineHeight: 1.12, letterSpacing: '-0.03em', whiteSpace: 'nowrap'}}>
      {units.map((u, i) => {
        const p = interpolate(local - i * each, [0, 12], [0, 1], {...clamp, easing: EASE.enterText});
        return (
          <span key={i} style={{display: 'inline-block', overflow: 'hidden', verticalAlign: 'top', paddingBottom: '0.06em',
            marginRight: i < units.length - 1 ? '0.26em' : 0}}>
            <span style={{display: 'inline-block', translate: `0 ${(1 - p) * 105}%`}}>{u}</span>
          </span>
        );
      })}
    </div>
  );
};
export const fitsOneLine = (text: string, fontFamily: string, fontWeight: number, fontSize: number, maxW: number) =>
  measureText({text, fontFamily, fontWeight, fontSize, validateFontIsLoaded: true}).width <= maxW;
```

- `fitText` 가 `minSize` 아래로 내려가면 줄이지 말고 **글자를 줄이라**고 수정 요청을 낸다(`06`: "모자라면 글자를 줄인다").
- `fitText`·`measureText` 는 폰트가 로드된 뒤에 불러야 한다. `useFontGuard` 가 이미 그 시점을 보장한다. 지금 `lib/fit.ts` 는 글자 폭 근사(한글 0.94em)라 Black Han Sans·Jua 에서 어긋난다.

### E2. 형광펜·밑줄은 글자가 선 뒤에

- **전하는 것**: 한 낱말이 핵심이다. 강조는 색이 아니라 **표시**로 한다(`06` 의 `mark` 와 같은 생각의 가벼운 판).
- **언제**: 헤드라인당 한 낱말. 글자가 안착한 6f 뒤(`06b FOLLOW.underline`).
- **오늘 DSL**: 모션 장면의 `highlight` 는 색만 바꾼다. 밑줄은 롱폼 `Stage.tsx Annotated`, 형광펜은 카드 `highlight` 에만 있다. 손으로 친 표시는 `06` 7-1 의 `mark` 가 맡는다 → 여기서는 추가 요청 없음.
- **검증**: tsc 통과.

```tsx
export const Marker: React.FC<{landedF: number; color: string; children: React.ReactNode; kind?: 'marker' | 'underline'}>
  = ({landedF, color, children, kind = 'marker'}) => {
  const m = interpolate(useCurrentFrame(), [landedF + 6, landedF + 16], [0, 1], {...clamp, easing: EASE.enter});
  const band = kind === 'marker' ? `linear-gradient(transparent 58%, ${color} 58%)` : `linear-gradient(transparent 90%, ${color} 90%)`;
  return (
    <span style={{backgroundImage: band, backgroundRepeat: 'no-repeat', backgroundSize: `${m * 100}% 100%`,
      boxDecorationBreak: 'clone', WebkitBoxDecorationBreak: 'clone'}}>{children}</span>
  );
};
```

### E3. 카드의 줄·어절 마스크 리빌 (GSAP SplitText)

- **전하는 것**: E1 과 같다. 카드는 HTML 이라 줄바꿈이 브라우저에서 정해지므로, 줄 단위 리빌은 렌더된 줄을 알아야 한다. SplitText 가 그것을 한다.
- **패키지**: `gsap/SplitText`(3.15.0 에 들어 있다. gsap-skills 저장소는 플러그인이 전부 무료라고 적는다).
- **오늘 카드 DSL**: `kinetic-chars`·`typewriter` 는 글자 단위뿐이다. → 추가 요청 `reveal-lines`.
- **검증**: tsc 통과(형만). 일시정지 타임라인을 `seek` 했을 때의 결정론, `check.mjs`(고전 스크립트 주입)에서의 플러그인 등록은 실행 검증 안 함.

```ts
gsap.registerPlugin(SplitText, DrawSVGPlugin, MorphSVGPlugin, CustomEase);
CustomEase.create('choiEnterText', '0.16, 1, 0.3, 1');

/** data-anim="reveal-lines": 줄(또는 어절) 단위 마스크 리빌. 폰트가 로드된 뒤에 부른다. */
export const revealLines = (tl: gsap.core.Timeline, el: HTMLElement, at: number, unit: 'lines' | 'words' = 'lines') => {
  const split = new SplitText(el, {type: unit, mask: unit, autoSplit: false});
  const targets = unit === 'lines' ? split.lines : split.words;
  tl.from(targets, {yPercent: 105, duration: 0.4, ease: 'choiEnterText', lazy: false,
    stagger: {amount: Math.min(0.5, targets.length * 0.1), from: 'start'}}, at);
  return split;
};

/** data-anim="stagger-in" 의 확장: 가운데부터, 묶음 전체 0.5초 */
export const staggerFromCenter = (tl: gsap.core.Timeline, items: Element[], at: number) =>
  tl.fromTo(items, {opacity: 0, y: 18}, {opacity: 1, y: 0, duration: 0.45, ease: 'power3.out', lazy: false,
    stagger: {amount: 0.5, from: 'center'}}, at);

/** data-anim="draw-path" 를 DrawSVG 로(선의 일부만 그리기 가능) */
export const drawPart = (tl: gsap.core.Timeline, path: SVGPathElement, at: number) =>
  tl.fromTo(path, {drawSVG: '0% 0%'}, {drawSVG: '0% 100%', duration: 0.6, ease: 'power2.out', lazy: false}, at);

/** data-anim="morph-shape": 같은 자리의 도형이 다른 도형으로 */
export const morphTo = (tl: gsap.core.Timeline, path: SVGPathElement, toD: string, at: number) =>
  tl.to(path, {morphSVG: {shape: toD}, duration: 0.8, ease: 'power2.inOut', lazy: false}, at);
```

- `autoSplit: false` 로 둔다. 폰트 로드 뒤에 다시 쪼개는 동작은 `seek` 로 값을 정하는 방식과 맞지 않는다.
- `stagger` 의 `from: "random"` 은 쓰지 않는다(결정론).

1차 리서치 노트에는 있었지만 채널 톤과 `06`·`motion_craft.md` 에 맞지 않아 뺐다.

| `@remotion/rough-notation`·`noise`·`effects`·`lottie` | 설치돼 있지 않다. 손 주석은 `06` 의 `mark` 가 SVG 로 직접 그린다 |
