# 14. Claude 총괄 제작 — 조사하고, 설계하고, 직접 짓는다

2026-10-02 채널 주인:

> 클로드의 역할은 예쁜 디자인으로 컷편집을 잘하는 게 아니야. 주제 설명·대본·원본으로 맞춤형 구성과 레이아웃을 대본의 흐름에 맞춰
> 기획하고, 조사하고, 알맞은 자료를 찾아 활용하는 거야. 토큰을 써도 괜찮아. 너의 주관적인 디자인과 구성이 들어간 영상을 원해.
> 가장 메인이 되는 에이전트는 클로드다. 다른 알고리즘·모델은 같은 품질을 낼 수 있을 때만.

## 1. 진단 — 왜 밋밋했나

| 원인 | 예전 | 이제 |
|---|---|---|
| Claude 가 웹을 못 봤다 | 모든 호출 `--tools ""` — 기억으로만 | 🔎 리서치 디렉터·🛠 시그니처 장면은 WebSearch·WebFetch(미리 허락) |
| 서식 채우기 | 에이전트마다 JSON 한 번 | 조사 노트 → 트리트먼트(콘셉트·구성표·시그니처 장면) → 빌더가 장면마다 정밀 제작 |
| 이 주제만의 설계가 없었다 | 구조·비트·톤뿐 | `BRIEF.treatment` — 콘셉트·모티프·대본 흐름대로의 화면 구성표·시그니처 장면·소리 콘셉트 |
| 효과음이 하나도 안 들렸다 | 문구 팔레트(paper_slide·page_turn…)에 실제 파일이 없어 절차적 소리뿐 → 믹스가 거절 | 실제 파일(Pixabay·Mixkit)로 받기(`REAL_FOR`) + 감독이 고른 곳에만(`sfx_mode=directed`) |
| 음악이 없었다 | 매니페스트 12곡 중 11곡이 Content ID 등록이라 꺼짐, 내 음악 폴더가 비면 없음, 여러 곡이면 해시로 아무 곡 | 내 음악 폴더의 곡을 재서(템포·밀도·말 대역·LUFS) 🎼 음악 감독이 고른다 |
| 그림 자료 | 리서처가 낱말로 검색 | 조사 노트가 직접 확인한 커먼즈 파일을 사다리가 먼저(`research` 칸) |
| 모션 | 템플릿·DSL 한 번 | Jitter 갤러리에서 움직임을 고르고(목록 404개), 미리보기 프레임을 보고 다시 짓는다 |
| 스킬 | 모든 에이전트가 같은 노트 | 에이전트별 스킬 노트(`prompts/skills/agents/*.md` — 영화·모션·소리·패키징 전문가 자료) |

## 2. 흐름

```
probe → [audio→asr ∥ face ∥ 🔎 research] → align → [🎬 director(+treatment) → (전문가들 ∥ 🛠 시그니처 장면×N) ∥ grade→proxy] → …
```

1. **🔎 리서치 디렉터**(`studio/agents/research.py`, 프롬프트 `agents/researcher.md`, 스키마 `RESEARCH`, 단계 `research` — 소리·얼굴과
   동시에, 대본과 주제 설명만 본다): 대상(인물·제품·작품)마다 사실+출처·생김새·**확인한 커먼즈 파일**, 개념·연표·숫자·인용(✔ 원문 확인),
   **재현 사양**(UI·제품의 비율·색·배치), 대본 확인(wrong·caution — 대본은 고치지 않는다), 연출 제안. 캐시 `work/research.json`,
   화자에게 `부가자료/조사노트.md`. 공유 컨텍스트 끝에 붙어 모든 에이전트가 같은 사실에서 출발한다(`research_block`).
2. **🎬 총괄 감독 + 트리트먼트**(`BRIEF.treatment`): 콘셉트·모티프·질감·서체·소리 콘셉트, 대본 흐름대로의 **화면 구성표**
   (`segments`: face·collage·photo_full·stock_video·quote_over_footage·document·motion·signature… + 보일 것·자료·움직임·효과음),
   **시그니처 장면 3~6개**(ui_recreation·object_recreation·data_story·diagram·timeline — `motion_ref` 로 Jitter 템플릿 하나).
   모션 디자이너·자료 리서처·편집 감독·자막 디자이너 지시 끝에 그들 몫이 붙는다(`treatment_block`).
3. **🛠 시그니처 장면 빌더**(`agents/setpiece.md`, 스키마 `SETPIECE`): 장면마다 한 호출(동시에), 조사 노트의 사양 + 모션 레퍼런스
   프레임 시트를 보고 HTML 카드로 정밀 제작 → `card` 그래픽(`signature=True`, 겹치면 +3 우선) → 렌더 전 검사(`check.mjs`)·수정.
   카드 상한은 HTML·CSS 24KB·요소 260개(UI 재현).
4. **모션 레퍼런스**(`studio/assets/motion_ref.py`, `renderer/scripts/motion_ref.mjs`, 목록 `assets/jitter_catalog.json`): 총괄 감독이
   목록에서 고른 slug 의 템플릿 페이지를 렌더 Chrome 으로 열어 미리보기 영역을 0.45초 간격 8장 → 시트(캐시 `user/cache/motion_refs`).
   템플릿 파일을 받거나 그대로 쓰지 않는다 — 움직임을 보고 우리 스타일로 다시 짓는다. 글자·로고·사진은 옮기지 않는다.
5. **조달**: 자료 리서처의 `commons_files`(없으면 조사 노트에서 이름으로 이어 줌) → 사다리 `research` 칸이 가장 먼저(라이선스·크기는
   다시 확인, 로고 자리 제외).
6. **소리**: 효과음 `sfx_mode` = directed(기본: 트리트먼트의 단락·시그니처 장면 효과음만, 그래픽 등장에 맞춤, 60초 3개, 홀드·첫 3초
   제외) · auto(예전 규칙) · off. 범주는 모션 그래픽에서 흔한 whoosh_soft·swoosh_short·swipe·pop·click·typing·camera_shutter·paper·
   ding·bell_soft·notification. 배경음악은 내 음악 폴더에서 🎼 음악 감독이 고른다(`MUSIC.track`, `studio/sound/tracks.py`), 맞는 곡이
   없으면 음악 없이.
7. **모델 확인**: Claude Code 의 실제 응답 모델을 로그에 남기고, Opus 를 요청했는데 다른 모델이 답하면 경고(구독 등급·한도). 설정의 로그인
   상태는 `Claude Max`/`Claude Pro` 로 보여 준다 — Max 인데 Pro 로 보이면 로그아웃 → 다시 로그인.

## 3. Claude 가 하는 일 / 알고리즘이 하는 일

  효과음 자리 · 카피 · 숏폼 · 검수.
- 알고리즘: 음성 인식(Whisper) · 얼굴 추적 · 색 측정·LUT · 오려 내기 · 라이선스 확인 · 렌더 · 믹스·라우드니스 · 품질 게이트(측정).
