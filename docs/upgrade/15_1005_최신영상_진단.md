  `topic_line`(`pipeline.py:5201`)은 첫 문장을 28자에서 어절 경계로 잘라 '…' 를 붙인다. 화면용 문장이 아닌 것을 자른 것.

### 2-2. 한 낱말 카드 '문제' · '이론' · '하는'
- **4:05** 흰 상자에 `문제` 하나(3초) · **10:46~10:49** `이론` · **11:03~11:05** `하는`. 모두 맨얼굴 78초·50초 구간 안의 **보충 카드**(18초 간격)다.

  **`card_worthy` 검사 없이** 그대로 카드로 쓴다. `studio/text/script.py:176` 은 **따옴표 속 말을 전부 용어로** 넣는다(`'하는' 법` · `'문제'` · `'이론'`).
  그래서 `card_worthy("하는")` 은 `GAP_STOP` 때문에 False 인데도 '하는' 카드가 뜬다. `strict=False` 폴백(`fallback._keywords`)도 `card_worthy` 를 거치지 않는다.
- 해법: 용어 가지에도 `card_worthy`(한 낱말은 4자 이상 · `GAP_STOP`·`_VERBISH` 제외)를 걸고, `glossary_terms` 의 따옴표 용어는 **3자 이상 + 대본에서
  따옴표 밖으로도 쓰이지 않는 말**만. 폴백은 낱말 대신 **그 문장 자체를 인용 자막(lower third)으로** — 한 낱말 상자는 어떤 경우에도 넣지 않는다.
- 더 위의 원인: 78초를 비워 둔 것은 기획(트리트먼트 `segments` 가 단락마다 화면을 정하는데 2장 전반 3:52~5:10 에 아무것도 없음)이고, 보충 카드는 그 증상을
  **더 티 나게** 만든다. `_fill_gaps` 는 글자 카드가 아니라 ① 그 문장의 스톡/자료 후보(`evidence.json` 의 못 쓴 후보) ② 인용 자막 ③ 글라이드만 — 순으로.

## 6. [P0·확인 필요] 디자인 층이 없다 — 왜 빠졌는지 로그로 확인

- 13분 안에 **자유 HTML 카드(GSAP)·모션 DSL 장면이 하나도 보이지 않는다.** 전면·분할 그래픽은 모두 내장 템플릿: 목록 카드 10장(1:17 · 1:52 · 6:44 · 7:10 · 7:54 ·

- 세 가지 가능성 — 로그 한 줄로 갈린다:
  1. 옛 설치본(1절) — 자유 카드 수가 원래 적던 때.
  2. 카드가 **검사·심사에서 전부 탈락해 키워드 카드로 대체**됐다(`pipeline.py:1803` "🃏 … 검사에 두 번 실패해 키워드 카드로 대체", `:3697` "🧑‍⚖️ … 심사에 두 번 탈락해
     키워드 카드로 대체"). 그렇다면 fail-closed 가 **영상 하나를 통째로 PPT 로 바꾼 것**이고, 심사 기준(`card_critic` 하드 실패)과 검사(`check.mjs`)가 새 대본에서 왜
     전부 떨어뜨리는지가 진짜 문제다. 분할 키워드 카드 "학교에선 분명히 배우는데 / 조용히 사라지는 이론"(0:50), "그럴 만한 예산·지원 없이 / 새 기계가 아니었다"(7:42),
     "해적선 촬영실의 대본 / 배 위에선 가만히"(8:20) 의 모양(머리글 40자 + 제목 12자, split)이 대체 카드와 같다.
  3. 모션 디자이너가 처음부터 목록·키워드만 냈다(프롬프트 문제).
- 해법(어느 경우든): **"대체는 되돌림이 아니다"** — 카드가 둘 이상 대체되면 그 챕터를 다시 짓게(`motion_revise` 에 심사 이유를 주고 원형을 바꿔 1회), 영상 전체에서
  자유 카드가 0이면 **게이트 block**(렌더하지 않고 `품질게이트_중단.md`). 목록 카드는 챕터당 1장 상한(B7 에 템플릿별 상한 추가).
