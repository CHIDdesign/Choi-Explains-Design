## 0. 원칙

1. **인쇄물에는 종이보다 밝은 색도, 잉크보다 어두운 색도 없다.** 밖에서 온 그림의 톤을 [잉크 `#26211E`, 종이 `#F5F2EA`] 안으로 담는다. 순흑·순백이 크림 종이 위에 올라오는 것이 "붙여 넣은 것 같다"의 정체다.
2. **색은 셋뿐이다**(종이·잉크·시그널). 사진은 색을 가질 수 있지만 채도와 방향을 채널 쪽으로 맞추고, 그것으로 안 되는 그림은 잉크 한 색으로 바꾼다.
3. **시그널(주황)은 강조 한 가지 일만 한다.** 사진에 주황을 물들이지 않는다.
4. **입자는 한 번만.** 그림에 미리 굽지 않는다. 렌더러 최상단의 입자 한 장이 화자·자료·종이를 같이 지난다([07](07_영상_룩_v2.md) 4-3).
5. 어두운 무대(`#1D1916`) 위에서는 같은 그림을 **뒤집지 않는다.** 사진은 그대로(블랙이 무대보다 조금 밝게 뜨는 것이 맞다), 선화만 크림 잉크로 바꾼다.

고르는 규칙(제안 — 문턱은 실제 자료 10장에서 잡은 것):

```python
def pick_treatment(kind: str, st: dict, w: int, h: int, keep_color: bool, series_std: float = 0.0) -> str:
    if kind in ("vector", "illustration"):            # 클립아트
        return "lineart"
    if keep_color:                                     # 자료 리서처가 "색이 정보"라고 표시
        return "graded"
    if max(w, h) < 1200:
        return "halftone"
    cool = st["b_med"] < 0 and st["c_med"] > 15        # 차가운 지배색
    loud = st["c_med"] > 30                            # 원색
    if cool or loud or series_std > 12:                # 같은 챕터 사진들의 (a*, b*) 중앙값 표준편차
        return "duotone"
    return "graded"
```

- `keep_color` 는 자료 리서처([`visual_researcher.md`](../../prompts/agents/visual_researcher.md))가 낸다: 작품·제품·브랜드 색·화면 캡처면 참.
- 에이전트가 직접 고를 수도 있다: 그래픽 `data.treatment: "graded" | "duotone" | "halftone" | "lineart"`. 없으면 규칙.

## 3. 레시피 — 실행한 코드

아래는 테스트에 **실제로 돌린 코드**다(앱의 파이썬 3.13 · numpy · Pillow, 색 변환은 `studio/grade/auto.py` 의 함수를 그대로 썼다). 새 파일 `studio/grade/house.py` 로 옮긴다.

```python
import numpy as np
from PIL import Image, ImageFilter
from .auto import srgb_to_lab, lab_to_srgb, _luma, _scurve, REFERENCE_LAB

INK = np.array([38, 33, 30], np.float32) / 255          # #26211E
PAPER = np.array([245, 242, 234], np.float32) / 255     # #F5F2EA


def house_stats(x: np.ndarray) -> dict:
    """x: sRGB 0~1. 레벨·채도·색 방향."""
    pix = x.reshape(-1, 3); lum = _luma(pix)
    lo, hi = np.percentile(lum, [0.5, 99.5])
    L, a, b = srgb_to_lab(pix); C = np.hypot(a, b); mid = (L > 25) & (L < 80)
    return dict(lo=float(lo), hi=float(max(hi, lo + 1 / 1.4)),         # 늘림은 1.4배까지
                c_med=float(np.median(C[mid])), a_med=float(np.median(a[mid])), b_med=float(np.median(b[mid])))


def house_grade(x, st, k=0.5, c_target=16.0, pull=0.5):
    """T1. k: [잉크, 종이] 리맵 세기(전면 0.5 · 종이 위 0.85 · 색이 정보면 0.3)."""
    x = np.clip((x - st["lo"]) / (st["hi"] - st["lo"]), 0, 1)
    L, a, b = srgb_to_lab(x)
    w = 4 * (L / 100) * (1 - L / 100)                                   # 중간톤에서만 방향을 옮긴다
    a = a + pull * (REFERENCE_LAB["a"] - st["a_med"]) * w * 0.5
    b = b + pull * (REFERENCE_LAB["b"] - st["b_med"]) * w * 0.5
    C = np.hypot(a, b) + 1e-6
    g = np.clip(c_target / max(st["c_med"], 4.0), 0.6, 1.25)
    C2 = np.where(C * g > 40, 40 + (C * g - 40) * 0.3, C * g)           # 원색은 무릎
    x = lab_to_srgb(L, a * C2 / C, b * C2 / C)
    lo, hi = k * INK, 1 - k * (1 - PAPER)
    return lo + x * (hi - lo)


def duotone(x, mid=(0.55, 0.50, 0.45)):
    """T2. 잉크 → 따뜻한 회색 → 종이."""
    lum = _luma(x); lo, hi = np.percentile(lum, [0.5, 99.5])
    t = _scurve(np.clip((lum - lo) / (hi - lo), 0, 1), 0.15)[..., None]
    m = np.array(mid, np.float32)
    return np.where(t < 0.5, INK + (m - INK) * np.clip(t * 2, 0, 1), m + (PAPER - m) * np.clip(t * 2 - 1, 0, 1))


def halftone(x, cell=7.0, angle=45.0):
    """T3. 망점 면적 = 어두운 정도. cell 은 출력 화소 기준(1080p 에서 6~8)."""
    g = np.asarray(Image.fromarray((_luma(x) * 255).astype(np.uint8)).filter(ImageFilter.GaussianBlur(cell / 2)),
                   np.float32) / 255
    lo, hi = np.percentile(g, [1, 99]); g = np.clip((g - lo) / (hi - lo), 0, 1)
    h, w = g.shape; yy, xx = np.mgrid[0:h, 0:w].astype(np.float32); th = np.deg2rad(angle)
    u = (xx * np.cos(th) + yy * np.sin(th)) / cell; v = (-xx * np.sin(th) + yy * np.cos(th)) / cell
    d = np.hypot(u - np.round(u), v - np.round(v))
    r = np.sqrt(np.clip(1 - g, 0, 1) / np.pi)
    alpha = np.clip((r - d) * cell + 0.5, 0, 1)[..., None]              # 1px 안티에일리어싱
    return PAPER + (INK - PAPER) * alpha


def lineart(rgba: Image.Image, ink=INK) -> Image.Image:
    """T4. 클립아트 → 잉크 한 색 + 알파(밝은 면은 투명). 어두운 무대 위에서는 ink 에 PAPER 를 준다."""
    a = np.asarray(rgba.convert("RGBA"), np.float32) / 255
    lum = _luma(a[..., :3]) * a[..., 3] + (1 - a[..., 3])                # 투명한 곳 = 흰색
    cover = np.clip((0.82 - lum) / 0.45, 0, 1)                           # 어두울수록 잉크
    out = np.concatenate([np.broadcast_to(ink, a[..., :3].shape), cover[..., None]], -1)
    return Image.fromarray((out * 255).astype(np.uint8), "RGBA")
```

표면에 따른 값:

| 그림이 놓이는 곳 | T1 의 `k` | 블랙 → | 화이트 → | 비고 |
|---|---|---|---|---|
| 전면(풀스크린) 사진·스톡 영상 | 0.5 | (19, 17, 15) | (250, 249, 245) | 화자 영상의 암부 바닥(레시피 목표 0.012)과 컷이 튀지 않게, 너무 띄우지 않는다 |
| 종이 메모·보드 위(pip · 패널) | 0.85 | (32, 28, 26) | (247, 244, 237) | 잉크·종이와 거의 같은 범위 |
| 색이 정보(`keep_color`) | 0.3, `pull=0`, `c_target` 은 원본 유지(이득 1.0) | (11, 10, 9) | (252, 251, 249) | 레벨만 담는다 |
| 어두운 무대 위 | 0.5 | 〃 | 〃 | 사진은 뒤집지 않는다. 선화는 `ink=PAPER` |

- T4(책 일러스트): 빨강·초록·노랑 면이 사라지고 외곽선과 음영만 잉크로 남는다. 종이 위에서는 펜으로 그린 삽화처럼, 무대(`#1D1916`) 위에서는 크림 분필 선처럼 보였다. 외곽선이 없는 플랫 일러스트(커피컵·노트북)는 면 실루엣이 된다 — 쓸 만하지만 그림에 따라 뭉개진다.
- **이 테스트에서 얻은 규칙**: T1 은 "이미 따뜻하거나 중립인 사진"에만 충분하다. 차가운 지배색(중간톤 b\* < 0, 채도 > 15)은 `pull` 을 1.0 으로 올려도 셔츠가 회색빛 파랑으로 남을 뿐이라, 듀오톤으로 보내는 편이 낫다(2절 규칙의 `cool`).
- 하지 않은 것: 스톡 **영상**(`piv*.mp4`)에는 돌리지 않았다. 나머지 정지 자료 8장도 눈으로 분류만 했다.

## 5. 가장자리와 그림자 — 광원 하나

틀의 모양·크기·기울임·움직임은 [03b](03b_자료_트리트먼트_컴포넌트.md)의 `EvidenceFrame` 이 정한다. 여기서는 **색과 재질**만 정한다. 광원은 [06](06_모션_그래픽_v2.md) 3-3 대로 왼쪽 위 하나다.

| 요소 | 규칙 |
|---|---|
| 그림자 색 | 순검정 금지. 웜 잉크 `rgba(38,33,30,α)` |
| 그림자 방향 | 오른쪽 아래, `dx : dy = 2 : 3`. 한 화면의 모든 자료가 같은 방향 |
| 그림자 겹 | 두 겹: 맞닿은 그림자(`2px 3px 4px`, α 0.25) + 번진 그림자(`10px 15px 30px`, α 0.18). 무대 위에서는 α 를 0.35 · 0.30 으로 |
| 인화 테두리(T1) | 종이색 `#F5F2EA` 그대로(새 색을 만들지 않는다 — B9), 폭 14~18px. 종이 위에서의 구분은 그림자와 안쪽 1px 잉크 12% 선이 한다 |
| 듀오톤·하프톤(T2 · T3) | 테두리 없음. 종이에 직접 찍힌 것처럼 — 찢긴 가장자리 또는 재단선. 그림자는 맞닿은 한 겹만 |
| 선화(T4) | 그림자 없음(종이에 그린 것이다). 떠 있어 보이면 틀린 것 |
| 위쪽·왼쪽 가장자리 | 광원 쪽이라 1px 밝은 선(`rgba(255,255,255,0.35)`)을 줄 수 있다. 오른쪽·아래에는 주지 않는다 |
| 하이라이트·광택 | 금지. 종이는 무광이다 |
| 사진 위 글자 | 사진을 어둡게 덮을 때도 순검정이 아니라 `rgba(29,25,22,0.58)`(무대색) |
| 전면 사진의 비네트 | `FilmLook` 그대로. 다만 사진 색은 이 문서의 처리를 먼저 거친다 |

## 6. 스톡 영상

- 클립마다 3~5 프레임을 뽑아 `house_stats` 를 내고, `house_grade` 를 33³ 격자에 태워 `.cube` 를 굽는다(`auto.write_cube` 와 같은 격자 순서). `house_grade` 는 픽셀 독립이라 LUT 에 그대로 들어간다.
- T2 도 픽셀 독립(휘도 → 색)이라 같은 방식으로 굽는다. T3 는 영상에 쓰지 않는다(망점이 프레임마다 흔들린다).

```
# studio/stock/process.py prepare_video — 실행 검증 안 함
scale=1920:1080:force_original_aspect_ratio=increase:flags=lanczos,crop=1920:1080,fps=30,
scale=in_color_matrix=bt709,format=gbrp16le,
lut3d=file='house_<id>.cube':interp=tetrahedral,
zscale=m=bt709:r=tv:d=error_diffusion,format=yuv420p
# 인코더 인자 뒤에: -colorspace bt709 -color_primaries bt709 -color_trc bt709 -color_range tv
```

- 뒤 세 줄(16비트 LUT + 디더)은 화자 프록시에서 실행 검증한 것과 같은 꼴이다. 스톡 입력으로는 돌려 보지 않았다.
- 지금 `prepare_video` 는 색 태그를 붙이지 않는다. 위 태그 인자를 반드시 더한다.
- 클립 안에 컷이 있으면 `house_stats` 가 섞인다 — 컷 없는 구간을 고른 뒤 그 구간에서만 표본을 뽑는다(리서치 9.2).

## 7. 클립아트·벡터(모션 장면의 이미지 요소)

- `studio/stock/research.py resolve_images` 가 `pixabay:<vector|illustration>:…` 을 받아 오면 **항상 `lineart`** 를 거친다. 장면의 표면이 종이면 `ink=INK`, 칠판·무대면 `ink=PAPER`.
- 불투명 JPG(배경이 든 일러스트)는 배경 제거가 필요하다. 배경이 단색이면 모서리 화소색과의 거리로 알파를 만든다. 아니면 **쓰지 않는다**(B6 로 떨어뜨리고 모션 디자이너가 선으로 직접 그린다 — 이번 작업에서 아트 디렉터가 전구를 그렇게 고쳤다).
- 한 장면에 선화는 둘까지. 시그널 색은 선화에 쓰지 않는다(강조 요소 하나에만).
- 사진형(`pixabay:photo:…`)이 모션 장면에 들어오면 T2 로 고정한다(작은 크기에서 T1 은 원색 조각으로 보인다).
