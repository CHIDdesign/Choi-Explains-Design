## 🎓 6. 템플릿처럼 보이지 않게 — 실제 결과물에서 나온 표식과 반대 규칙

채널 운영자는 디자이너다. 아래는 지난 결과물에서 실제로 보인 것이다. 하나라도 만들고 있다면 멈추고 반대 규칙을 따른다.

| 화면에서 보인 것 | 반대 규칙 |
|---|---|
| 6분 안에 재질이 아홉 번 바뀜(크림 보드, 회색 구겨진 종이, 순백 카드, 검정 카드, 주황 전면…) | **한 영상 = 한 재질.** 크림 종이 + 웜 잉크 + 시그널 한 곳. 순백·순흑 전면 금지. 변주는 구도와 진입에서 낸다 |
| 큰 판에 작은 도식, 화면 아래 절반이 빔 | **상자의 45% 이상을 채운다.** 못 채우면 작은 구성(옆 메모, 아래 띠)을 쓴다 |
| 도식 글자 24~32px, 숏폼 카드 글자 12~16px | 최종 화면에서 본문 34px(숏폼 44px), 라벨 28px(숏폼 32px) 이상. 롱폼 카드를 숏폼에 줄여 넣지 않는다 |
| 빈 화면에 줄 하나·낱말 하나가 2~3초 | **0프레임에 무대가 선다.** 제목, 주 오브젝트, 자리 표시를 먼저 놓고 말에 맞춰 채운다 |
| 화자는 줄어 있는데 옆 판이 비어 있음 | 화자가 줄어든 동안에는 판에 늘 내용이 있다. 없으면 화자를 전면으로 돌린다 |
| "리서치·스케치·고민" = 빈 네모 셋, "첫 아이디어" = 주황 점 | **기호보다 실물.** 스케치, 장표, 논문 지면, 제품 사진, 화면 캡처를 놓는다. 실물이 없을 때만 도식을 그린다 |
| 회색 종이 위 컬러 클립아트(초록 로고 커피컵, 책 더미) | 컬러 벡터와 일러스트를 쓰지 않는다. 쓰려면 잉크 단색으로 바꾸고, 한 장면에는 화풍 하나만 둔다 |
| `motion` `card` `keyword` `brand` `CHAPTER 04` 가 화면에 찍힘 | 템플릿 이름, 종류값, 영어 내부 낱말, 발화 번호(S12)·그래픽 id 를 화면 글자로 쓰지 않는다. 라벨은 역할(이유, 예시, 결론)만 |
| 스톡 제목이 검색어 그대로("책 펼치고 메모하기") | 제목은 그 순간의 **주장**이다. 검색어와 연출 메모("…을 보여준다")는 화면에 내지 않는다 |
| `compare` 3회, `double_diamond` 5회, `keyword` 8회 — 구조는 같고 글자만 바뀜 | **글자가 아니라 구조를 바꾼다.** 같은 형식은 2회 연속까지. 직전 그래픽과 구도와 진입이 둘 다 같으면 안 된다. 한 조합은 전체의 20% 이하 |
| 숏폼 55초 내내 위 카드 + 아래 얼굴 | 한 구성은 12초까지. 한 편에 구성 셋 이상: 얼굴 전면, 증거 전면, 카드 + 얼굴, 얼굴 + 메모 |
| 카드 안의 카드 안의 카드(앱 창 장식, 신호등 점) | 틀은 한 겹이다. 장식용 창, 테두리, 배지를 겹치지 않는다 |
| 화자 화면 전체에 찢어진 흰 테두리가 생겼다 사라짐 | 이유 없는 테두리와 액자를 쓰지 않는다 |
| 얼굴 위에 재질 없이 뜬 굵은 흰 글씨 | 재질 없는 글자는 자막뿐이다. 나머지는 종이 위에 올린다 |
| 콜아웃 + 강조 자막 + 자막이 동시에 | 같은 순간 글자 층은 둘까지다(그래픽 + 자막) |
| 사라지는 도식이 커지는 얼굴 위에 겹침 | 그래픽이 다 사라진 뒤에 화자가 커진다. 얼굴 위에는 어떤 프레임에도 그래픽이 없다 |
| 챕터 카드가 두 가지 디자인 | 길잡이 부품(챕터 카드, 소제목 바, 정리 보드, 출처)은 늘 같은 모양이다. 변주는 개념 그래픽에만 준다 |
| 썸네일: 눈 감은 프레임, 글자가 얼굴 위, 침대와 기타 가방 | 눈 뜨고 렌즈를 보는 프레임만 쓴다. 방을 치우고, 글자는 한 낱말~2줄, 얼굴과 겹치지 않게 |

### 그 밖에 흔한 기본값 — 쓰지 않는다

- 같은 반경의 둥근 카드를 나란히 놓기. 반경은 재질이 정한다(종이 0~4).
- 반투명 유리 + 블러 + 테두리 + 그림자를 한꺼번에 쓰기.
- 가운데 정렬 3단 스택(라벨 → 큰 글자 → 작은 글자).
- 모든 요소에 같은 fade-up.
- 굵기 600~700 뿐인 평평한 위계.
- 가는 선 아이콘 세트, 그라데이션 블롭, 글로, 이모지.
- 모든 요소에 드롭 섀도. 그림자는 떠 있는 종이에만, 전부 오른쪽 아래로.
- 완벽한 좌우 대칭과 0° 로 반듯한 종이.
- 모든 요소에 붙인 칩·배지·번호.
- "핵심 포인트", "중요한 개념" 같은 무게 없는 제목.
