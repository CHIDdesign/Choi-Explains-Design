### P0 — 사실 오류·글자 누수(먼저)
**A. 보충 카드 한 낱말 금지** — `studio/pipeline.py _gap_keyword`
- 용어 가지(`terms = [t for t in glossary if t in u.text]`)에도 `card_worthy(t, gl_lower)` 를 걸되, 용어는 **3자 이상**이거나 두 어절일 때만 통과. 대본 용어라도 '하는'·'문제'·'이론' 같은 2자 흔한 말은 카드가 아니다.
- `text/script.py glossary_terms`: 따옴표 용어는 `len >= 3` 또는 공백 포함일 때만, 그리고 대본에서 따옴표 **밖**에도 같은 말이 3번 넘게 나오면 용어가 아니다(강조 따옴표).
- `strict=False` 폴백: 낱말 카드 대신 **그 문장의 인용 자막(lower_third, `subtitle` 없이 문장 ≤ 28자)** 또는 `evidence.json` 에서 그 발화의 못 쓴 스톡 후보. 한 낱말 상자는 어떤 경우에도 만들지 않는다.
