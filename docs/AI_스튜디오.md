# 🎬 AI 스튜디오: 감독 한 명과 전문 에이전트 팀

Choi Studio 는 Claude 한 번에게 "알아서 편집해"라고 맡기지 않습니다. 영상 제작사처럼 **총괄 감독 한 명이 전문가 팀을 동시에 굴리고**, 마지막에 **아트 디렉터가 실제로 렌더된 화면을 보고** 고칩니다.

> Claude API 키는 **본인 것**이 필요합니다(console.anthropic.com 에서 발급 → 앱 **설정 → AI**). 이 앱을 만든 AI(저)는 제 키를 넣어 드릴 수 없고, 키는 사용자 PC 의 `user/settings.json` 에만 저장됩니다. 키가 없으면 대본 태그 기반 규칙 편집으로 동작합니다.

## 팀 구성

| 역할 | 하는 일 | 출력 | 사고 강도(기본) |
|---|---|---|---|
| 🎬 총괄 감독 | 전사본 전체를 읽고 로그라인·챕터 구조·연출 비트(20~40초마다)·숏폼 아이디어·자막 톤을 정한다 | 크리에이티브 브리프 | high |
| ✂️ 편집 감독 | 불필요한 발화를 추가로 자르고, 논점 전환과 결론에 펀치인 | drop / punch | medium |
| 🎨 모션 디자이너 | 템플릿 도식 배치 + 템플릿으로 안 되는 개념은 **모션 DSL 로 새 장면을 직접 설계** | graphics / scenes | high |
| 🎞 자료 리서처 | 구체적 장면·사물을 Pexels 검색어로 만들고, **후보 썸네일을 직접 보고** 고른다 | 스톡 요청 → 선택 | medium / low |
| 🔤 자막 디자이너 | 강조어를 유형별로(전문용어·핵심어·숫자·대비) 고르고 자막 프리셋을 정한다 | emphasis + preset | medium |
| 📱 숏폼 PD | 후킹 리서치(14가지 훅)를 적용해 숏폼 구간·콜드 오픈·훅 타이틀 기획 | shorts | high |
| ✍️ 카피라이터 | 유튜브 제목 5안, 설명란, 해시태그, 썸네일 문구, 고정 댓글 | youtube | medium |
| 🧐 아트 디렉터 | 렌더된 스틸만 보고(블라인드 비평) 넘침·가독성·과밀·강조색 남용을 지적 | 수정 지시 | high |

## 작업 흐름

```
전사본(+대본 태그, 메모, 편집 지시)
   │
   ▼
🎬 총괄 감독 ── 브리프(구조·비트·톤) ──┐
                                        ▼  (동시에, 같은 프롬프트 캐시 공유)
   ✂️ 편집   🎨 모션   🎞 자료   🔤 자막   📱 숏폼   ✍️ 카피
                                        │
                                        ▼
                     편집 계획(plan.json) ← 대본 태그는 항상 강제 반영
                                        │
   프록시·오디오 컷 → 자료 사진(위키미디어) → 🎞 Pexels 검색 → 후보 시트 → 비전 선택 → 다운로드·정리
                                        │
                                        ▼
   🧐 검수: 각 그래픽이 '도착한' 순간의 스틸 + 자막 스틸 → 문제 지적
        → 글자 줄이기 · 레이아웃 변경 · 삭제 · 🎨 모션 장면 재설계 → (설정한 라운드만큼 반복)
                                        │
                                        ▼
                             Remotion 최종 렌더(번들 재사용)
```

- **병렬 + 캐시**: 모든 에이전트가 같은 시스템 프롬프트(채널 헌장·스타일 가이드·후킹 가이드·카탈로그·모션 DSL·디자인 스킬 노트)와 같은 전사본을 공유합니다. 감독 호출이 캐시를 만들면 나머지 호출은 그 캐시를 읽어서 비용과 시간이 줄어듭니다. 에이전트별 토큰 사용량은 편집 리포트에 표로 남습니다.
- **실패에 강함**: 전문가 한 명이 실패해도 나머지 결과로 진행합니다. 총괄 감독이 실패하면 단일 디렉터 모드로, 그것도 실패하면 규칙 기반 편집으로 내려갑니다.
- **블라인드 비평**: 아트 디렉터에게는 설계 이유를 주지 않고 **렌더된 화면과 그 구간의 발화만** 줍니다. 설계자가 자기 설계를 변호하는 확증편향을 막는 방식입니다([remotion-director](https://github.com/anupamme/remotion-director)의 교훈).
- **정지 프레임 검수**: 움직이는 중간 프레임을 결함으로 오판하지 않도록, 진입 애니메이션이 끝난 순간(모션 장면은 모든 요소가 도착한 뒤)의 프레임을 뽑습니다.
- **틀린 B-roll 보다 없는 게 낫다**: 맞는 후보가 없으면 자료 리서처가 -1 을 고르고 그 컷은 빠집니다.

## 앱에서 쓰는 법

1. **설정 → AI**: Claude API 키(필수), Pexels API 키(스톡용, 무료), 동시 에이전트 수(기본 4; 요청 한도가 낮은 계정이면 2로).
2. 메인 창 오른쪽 **🎬 AI 스튜디오** 상자:
   - **멀티 에이전트**: 끄면 Claude 를 한 번만 부르는 단일 디렉터 모드(빠르고 저렴, 모션 장면·스톡 없음).
   - **🎞 Pexels 스톡 영상·사진**, **🎨 모션 장면 직접 설계**: 켜고 끌 수 있습니다.
   - **🧐 아트 디렉터 검수**: 0(끔)~3 라운드. 1라운드면 검수 후 수정까지, 2라운드면 수정한 장면을 다시 봅니다.
3. 왼쪽 **5. 편집 지시** 탭: 모든 에이전트에게 최우선으로 전달되는 자유 지시.
   - 예) "이번 편은 모션 그래픽을 평소보다 많이", "스톡은 자연광 톤만", "인트로 30초 이내"
4. **편집 계획만** → `output/plan.json` 을 확인하고 고친 뒤 → **전체 제작**. 고친 내용이 우선합니다.

## 에이전트별 모델·사고 강도 바꾸기(고급)

`user/settings.json` 에서 에이전트별로 바꿀 수 있습니다.

```json
{
  "agent_effort": {"motion": "max", "copy": "low", "art_director": "xhigh"},
  "agent_models": {"copy": "claude-sonnet-5-5"}
}
```

키: `director`, `editor`, `motion`, `stock`, `stock_pick`, `captions`, `shorts`, `copy`, `art_director`, `motion_revise`.

## 결과물에서 확인할 것

- `*_편집리포트.md`
  - 🎬 AI 스튜디오 브리프: 로그라인, 비트 표, 팀 메모
  - 🧐 아트 디렉터 검수: 라운드별 지적과 반영
  - 자료 사진·스톡 출처
  - 에이전트별 토큰 사용량
- `*_업로드정보.txt`: 설명란 맨 아래에 Pexels 작가 크레딧이 자동으로 들어갑니다. 화면에도 ▣ 크레딧이 표시됩니다.
- `work/qa/r1/*.jpg`: 아트 디렉터가 실제로 본 스틸
- `work/stock.json`: 요청별로 고른 스톡 소재. 재실행하면 검색과 다운로드를 다시 하지 않습니다.
