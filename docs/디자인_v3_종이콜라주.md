# 디자인 v3 — 종이 콜라주

2026-10-02 채널 주인 요청(레퍼런스: 센트럴 파크 에디토리얼 콜라주 영상의 프레임 6장 — 이미지는 저장소에 넣지 않고 측정값만 적는다):

> 스톡 영상·이미지 활용도가 낮다. 되도록 내 얼굴보다 시청각 자료를 최대한 많이 쓰고, 가져온 이미지에도 그래픽 효과를 넣어 변화시켜라.
> 모션 그래픽의 완성도와 디자인이 가장 중요하다. 지금은 너무 모던하다 — 종이 같은 질감으로, 이 레퍼런스 같은 디자인과 애니메이션으로.
> 폰트도 전부 뜯어고치고 예술적인 세리프체를 적극적으로. 대본 자막은 더 가늘고 작게.

## 2. 서체 역할(tokens.ts `FONT`)

| 역할 | 글꼴 | 쓰는 곳 |

| `serif` | Gowun Batang 400/700 | 문장·인용·주장·본문 명조(보드·숫자 카드 설명) |

| `round` | 'Press Serif'(고운바탕 700만 등록) | 말하듯 붙인 메모·콜아웃 |
| `sans` | Pretendard | 자막·라벨·26px 미만 |

Hahmlet 은 번들에 남아 있지만 역할에서 뺐다 — 굵게 쓰면 고딕처럼 보인다(시험 렌더 비교). 한 화면에 세 가족까지.
모션 DSL `font: display|serif|poster|italic|heavy|round|hand|sans|latin`, 카드 `--font-head`(고운바탕)·`--font-editorial`(송명)·
`--font-serif`·`--font-poster`·`--font-italic`·`--font-numeral` 도 같은 표를 따른다.

## 3. 색 — 고급 설정 '디자인 색'

`Brand.palette`: `forest`(기본 — accent #2B8A64 · deep #1E6B4F · tint #86D9B5, 레퍼런스의 초록) 또는 `brand`(브랜드 강조색 그대로,
짙은·옅은 색은 렌더러가 섞어 만든다). `studio/render/props.py PALETTES` → props `brand.deep/tint` → `makeTheme` 의
`accentDeep`/`accentTint`. 종이 위 글자는 `accentDeep`, 형광펜·이름표 상자·바닥 타원은 `accentTint`.

## 4. 사진을 붙이지 않고 편집한다

- **오려 내기**(`studio/assets/cutout.py`, 모델을 새로 받지 않음): ① 테두리가 고른 바탕(판화·스캔·제품)이면 테두리에 닿은 바탕색 덩어리 +
  화면 2.5% 이상인 안쪽 바탕색 구멍을 지운다. ② 인물 사진은 얼굴(YuNet)로 자리를 잡고 GrabCut — 경계의 85% 이상이 안팎 색 차(Lab ΔE 14)로
  갈릴 때만 받아들인다(머리가 배경에 녹으면 들쭉날쭉한 덩어리가 된다 → 버리고 프린트로). 이미 투명한 PNG 는 그대로. 결과 `*.cut2.png`.
  조달 사다리(`ladder._add_file`, 사진·A/own 등급)와 전면 스톡 사진(`StockResearcher._collage_extras`)이 부른다.
- **콜라주**(`press/CollageScene.tsx`, 트리트먼트 `collage`): 오린 사진 + 큰 글자 = 가운데(사진은 화면 너비 22% 이하라 글자가 읽힌다) ·
  프린트 + 큰 글자 = 글자 왼쪽, 사진 오른쪽(살짝 겹침) · 큰 글자 없음 = 가운데 사진. 연도는 위에 이탤릭 숫자. 안무: 연도 마스크(2f) →
  큰 글자 떠오름(4f) → 바닥 타원(6f) → 사진(8f) → 이름표(18f), 전체 3.5% 푸시 + 큰 글자 시차.
- **문서**(`DocPage`): 화면 너비 60%의 스캔 한 장을 비스듬히(±0.9°) + 뒤에 한 장, 핵심 줄이 화면 44% 높이에 오게, 형광펜 → 7% 푸시.
- **전면 영상·사진 위 인용**(`quote`): 채도↓·밝기 0.78 그레이드 + 가운데 고운바탕 한 줄(최대 78px). 이름표가 있으면 `NameChip`.
- 얼굴 옆 사진(pip)은 종이 테두리 프린트 + 테이프 + 흑백, 전면 사진·영상은 6프레임 디졸브로 들어온다(위에서 쓸어내리면 뒤의 화자가 드러난다).

자료 리서처(`prompts/agents/visual_researcher.md`)가 `treatment: collage`, `display`(2~8자, 화자가 말한 핵심 낱말),
`quote`(36자, 화자의 말을 줄인 것), `subject.year` 를 준다. `graphics.to_graphics` 는 오린 사진이나 `display` 가 있는 hero 를 collage 로,
`plan._keep_collage_text` 가 연도(숫자 4자리)·글자 수를 다듬어 보존한다.

## 6. 화면 구성

`studio/edit/style.py STYLE_MIX=False` — 모든 챕터가 같은 종이 콜라주(예전 종이/기본 섞기는 시험용으로 남김). 표면은 `collage` 하나:
리포트 머리글·위에서 쓸어내리는 진입 없이 종이 무대가 8프레임에 깔리고 내용이 올라온다. 보드 판(split)은 크림 종이 + 명조 제목 +
옅은 강조색 역할 라벨(`Kicker`) — 검은 알약 배지·브랜드 줄은 쓰지 않는다. 키워드 카드는 인쇄 얼룩 큰 글자 + 아래 명조 한 줄.
