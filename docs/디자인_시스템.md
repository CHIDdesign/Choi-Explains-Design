# 채널 디자인 시스템 — CHOI EXPLAINS DESIGN

레퍼런스 세 가지를 하나의 시스템으로 합쳤습니다.

0. **채널 운영자가 직접 편집한 장면·템플릿**(2026-09) — 기본 디자인을 대체하지 않고 *부분* 참고: 찢어진 흰 액자 사진, 개념 카드의 글 위계, 우상단 출처, 흰 종이 상자 자막, 따뜻하고 진한 색. 전부 쓰고 싶으면 '종이 콜라주' 스킨(아래 8장).
1. **셜록현준** (docs/research/셜록현준_편집스타일_리서치.md) — 화자 중심의 차분한 교양 토크, 칠판형 사이드 패널, 평면·단면도 같은 *설명 도구로서의* 그래픽, 장소/사물 중심 챕터.
2. **Musicbed × Filmsupply, Commercial Filmmaking Trend Report 2026** (첨부 PDF) — 에디토리얼 레이아웃(러닝 헤더, 초대형 콘덴스드 타이포, 괄호 캡션, ▣ 크레딧), 시그널 레드-오렌지, 필름 질감, 그리고 "Keep it stupid cinematic / Keep it human / Controlled chaos의 대비" 라는 편집 철학.

## 1. 원칙 (리포트에서 가져온 것)

| 리포트 트렌드 | 이 채널에서의 적용 |
|---|---|
| Keep It Stupid Cinematic — "보여줄 것만 보여주고 나머지는 자른다" | 그래픽은 설명 도구만. 장식·밈·과한 트랜지션 금지. 다만 말하는 내용은 화면에 보여야 한다 — 8~15초마다 도식·키워드·자료 사진·스톡(“그래픽이 너무 적다” 피드백) |
| Keep It Human — 다큐멘터리적 진정성 | 화자의 얼굴·호흡이 중심. 결론·웃음 순간은 그래픽으로 가리지 않음. 무음은 0.55초 넘는 것만 줄여 '생각하는 호흡'을 남김 |
| Controlled Chaos — 핵심은 *대비* | 그래픽 사이 3~6초는 얼굴로 숨 고르기(얼굴만 보이는 구간 최대 12초). 숏폼 첫 1초만 에너지 있게 |
| Cohesive Multi-Frame — 분할 화면, 세로 스택 | 롱폼 칠판 패널(화자 1/3 + 패널 2/3), 숏폼 상단 도식 + 하단 얼굴, 오프닝 표지의 작은 영상 프레임 |
| Analog Aesthetics — 기술적 한계를 감정으로 | 따뜻하고 진한 색(웜 리치: 레퍼런스 장면 CIELAB b\*≈14.5 · C\*≈17에 맞춤), 약한 비네팅, 그레인은 기본 끔 |
| Solo Instrumentation / Timeless Scores — 침묵이 이야기를 숨 쉬게 | BGM 은 목소리 아래 -25dB, 인트로·챕터·엔드카드에서만 부풀림. 추천 무드: 솔로 피아노/어쿠스틱 |
| 리포트 표지·페이지 레이아웃 | 오프닝 타이틀 = 표지(레드 바탕 + 짙은 레드 초대형 제목 + 가장자리 '20'/'26' + 가운데 작은 영상 프레임), 풀스크린 그래픽 = 리포트 페이지(상단 러닝 헤더: 채널 · 에피소드 · 연도 · ch 02) |

## 2. 색

| 토큰 | 값 | 쓰임 |
|---|---|---|
| accent (Signal) | `#F93107` (리포트 표지에서 추출) | 강조 한 곳, 챕터 번호, 표지 |
| 종이 주황 | `#F85301` (운영자 템플릿 실측) | 종이 콜라주 스킨의 강조 낱말 |
| 종이 | RGB(40,40,45) 구겨진 종이 · 테두리 `#7F7F81` | 종이 콜라주 스킨 배경 |
| accentDeep | accent 에 검정 32% | 표지 위 거대 타이포 |
| ink | `#111111` | 챕터 카드, 엔드카드 |
| board | `#1A1C1B` | 칠판 패널·도식 |
| chalk | `#F1ECDD` | 칠판 위 선·글자(분필 질감 필터) |
| paper | `#F4F4F2` | 인용·정의 |

강조색은 **한 화면에 한 곳**만. 설정 → 브랜드에서 바꿀 수 있습니다.

## 3. 타이포

- **Pretendard** (OFL) — 한글 본문·자막·제목. 제목은 Black(900) + 자간 -4~-5% 로 포스터처럼.
- **Anton** (OFL) — 숫자·영문 디스플레이(챕터 번호, 연도, 퍼센트). 리포트의 콘덴스드 그로테스크 역할.
- **Noto Serif KR** (OFL) — 인용문 전용 명조.
- 1080p 기준 스케일: 러닝 헤더 18 · 라벨 22 · 본문 34~46 · 제목 64~150 · 표지 230.

## 4. 표면(Surface)

| 표면 | 템플릿 |
|---|---|
| Ink | 챕터, 엔드카드 |
| Board(칠판) | 모든 도식(프로세스·순환·더블 다이아몬드·매트릭스·벤·피라미드·연표·목록·비교), 칠판 패널 |
| Paper | 인용, 용어 정의 |
| Signal | 오프닝 표지, 풀스크린 키워드/숫자 |
| Overlay | 화자 위 키워드·숫자(스크림) |
| Photo | 자료 사진(최대 105% 느린 푸시인, ▣ 출처) |

## 5. 모션

교육 영상이라 **튀지 않게**(2026-09 운영자 피드백: “훅훅 튀어 정신없다”).
- 등장: ease-out 12~18프레임, 텍스트는 마스크 안에서 아래→위로 3~4프레임 간격 스태거. 퇴장은 진입의 75%.
- 카메라: 와이드 100% ↔ 미디엄 106%, 실수를 잘라낸 자리·챕터·그래픽 복귀에서만. 샷 안은 초당 0.4%(최대 5%)로 아주 느리게.
- 점프컷: 같은 프레이밍이면 앞 장면 마지막 프레임을 0.1초 섞는 소프트 컷(길이·싱크 불변).
- 강조: 0.7초에 걸쳐 당기고 0.9초에 걸쳐 풀리는 글라이드(+4~9%). 콜아웃 자리 만들기도 천천히 옮겨 간다.
- 전환: 블러·푸시·와이프(챕터)·빛샘(타이틀)만. 휩·플래시·줌 전환은 쓰지 않는다.
- 칠판 패널: 바깥쪽 가장자리에서 열리고, 화자는 같은 시간에 1/3 열로 이동(얼굴이 열 가운데 오도록 추적).
- 도식 선: 분필처럼 그려지는 stroke 애니메이션, 지금 말하는 단계는 강조색 면. 목록/연표는 말하는 속도에 맞춰 순서대로.

## 6. 자막

- 롱폼: 하단 중앙 **흰 종이 상자 + 검정 글씨, 핵심어 어간만 굵게**(운영자 템플릿). 한두 마디(13자·2.4초 이하)씩, 말소리 시작에 맞춤.
- 화면 그래픽(개념 카드·도식·콜아웃)이 같은 말을 이미 보여 주면 그 자막은 화면에서 숨긴다(SRT 에는 남김).
- 숏폼(릴스식): 위 카드와 아래 얼굴 사이 이음새에 1~2어절(8자 안팎)씩 아주 굵은 흰 글씨 + 검정 외곽선·그림자, 강조어는 강조색.
- 자막 스타일(폰트 섞기·색 변화·단어별 모션·배치 변화)은 참고 채널 조사 결과로 계속 다듬는 중.

## 7. 사용자 템플릿에서 가져온 요소(기본 스킨)

| 요소 | 모양 | 쓰는 곳 |
|---|---|---|
| 찢어진 흰 액자 | 흰 테두리 약 12px, 손으로 찢은 듯한 가장자리 + 그림자 | 얼굴 옆 자료 사진·스톡(pip), 칠판 패널 사진, 타이틀의 화자 |
| 개념 텍스트 | 검정 라벨 + 아주 굵은 흰 글씨(그림자), 한 낱말만 강조색 | 얼굴 옆 키워드·숫자, 콜아웃 |
| 개념 카드 글 위계 | 흰 라벨 태그 → 헤드라인(한 낱말만 강조색) → 본문 → 회색 괄호 주석 | 칠판 패널의 키워드·정의·인용·숫자, 타이틀 |
| 출처 | 우상단 작은 흰 글씨 “출처: …” | 자료 사진·스톡·인용 |
| 엔드카드 | 오늘의 정리(챕터 목록) + 다음 영상 자리 2칸(액자) | 롱폼 끝 |

## 8. 종이 콜라주 스킨(선택)

⚙ 고급 설정 → 브랜드 → 화면 스타일에서 고른다. 운영자 템플릿 3장을 측정해 그대로 옮긴 것:
구겨진 짙은 종이(절차적 생성) · 회색 거친 테두리(두께 약 38px) · 개념 카드 + 오른쪽 화자 액자 · 화자 전체를 액자에 담은 세 번째 앵글 · 얼굴 옆 액자 사진 + 개념 텍스트.

## 9. 숏폼 구성

- **릴스식(기본)** — 참고 릴스 구성: 위 큰 둥근 카드(사진·스톡이 가득 / 어두운 앱 창 같은 도식 카드 / 흰 개념 카드 + 형광펜)가 말에 맞춰 바뀌고, 아래는 얼굴 전체 폭, 이음새에 굵은 자막. 사진이 있으면 첫 2.2초는 카드 여러 장이 부채꼴로 겹친 흰 화면 + 큰 제목.
- 레터박스(셜록현준식) · 얼굴 전체 + 위 도식 패널도 고를 수 있다.

## 10. 템플릿 확장하기

`renderer/src/components/graphics/` 에 컴포넌트를 추가하고,
`renderer/src/lib/types.ts`(TemplateName) · `renderer/src/components/graphics/index.tsx`(등록) ·
`studio/director/catalog.py`(Claude 에게 알려줄 설명) 세 곳에 이름을 맞춰 넣으면 됩니다.
`cd renderer && npm run studio` 로 `src/samples.ts` 예시를 보며 디자인을 다듬을 수 있습니다.
