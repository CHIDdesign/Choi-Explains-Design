# 채널 디자인 시스템 — CHOI EXPLAINS DESIGN

레퍼런스 세 가지를 하나의 시스템으로 합쳤습니다.

0. **채널 운영자가 직접 편집한 장면·템플릿**(2026-09) — 기본 디자인을 대체하지 않고 *부분* 참고: 찢어진 흰 액자 사진, 개념 카드의 글 위계, 우상단 출처, 흰 종이 상자 자막, 따뜻하고 진한 색. 템플릿 전체(구겨진 종이 · 거친 테두리 · 액자 샷)는 영상마다 대본·기획을 보고 기본 디자인과 **챕터·그래픽 단위로 섞어** 쓴다(아래 8장, 자동 하이브리드 — 고르는 설정 없음).
   참고 릴스(세로 구성)와 **Nick Saraev** 채널(자막·전환·효과음·음악의 절제)도 실측해 반영했다(`prompts/playbook/`).
1. **셜록현준** (docs/research/셜록현준_편집스타일_리서치.md) — 화자 중심의 차분한 교양 토크, 칠판형 사이드 패널, 평면·단면도 같은 *설명 도구로서의* 그래픽, 장소/사물 중심 챕터.
2. **Musicbed × Filmsupply, Commercial Filmmaking Trend Report 2026** (첨부 PDF) — 에디토리얼 레이아웃(러닝 헤더, 초대형 콘덴스드 타이포, 괄호 캡션, ▣ 크레딧), 시그널 레드-오렌지, 필름 질감, 그리고 "Keep it stupid cinematic / Keep it human / Controlled chaos의 대비" 라는 편집 철학.

## 1. 원칙 (리포트에서 가져온 것)

| 리포트 트렌드 | 이 채널에서의 적용 |
|---|---|
| Keep It Stupid Cinematic — "보여줄 것만 보여주고 나머지는 자른다" | 그래픽은 설명 도구만. 장식·밈·과한 트랜지션 금지. 다만 말하는 내용은 화면에 보여야 한다 — 8~15초마다 도식·키워드·자료 사진·스톡(“그래픽이 너무 적다” 피드백) |
| Keep It Human — 다큐멘터리적 진정성 | 화자의 얼굴·호흡이 중심. 결론·웃음 순간은 그래픽으로 가리지 않음. 무음은 0.55초 넘는 것만 줄여 '생각하는 호흡'을 남김 |
| Controlled Chaos — 핵심은 *대비* | 그래픽 사이 3~6초는 얼굴로 숨 고르기(얼굴만 보이는 구간 최대 12초). 숏폼 첫 1초만 에너지 있게 |
| Cohesive Multi-Frame — 분할 화면, 세로 스택 | 롱폼 칠판 패널(화자 1/3 + 패널 2/3), 숏폼 상단 도식 + 하단 얼굴, 오프닝 표지의 작은 영상 프레임 |
| Analog Aesthetics — 기술적 한계를 감정으로 | 따뜻하고 진한 색(웜 리치 — 룩의 방향이지 화면 평균을 맞출 목표가 아님, 아래 2장 '색보정'), 약한 비네팅, 그레인은 기본 끔 |
| Solo Instrumentation / Timeless Scores — 침묵이 이야기를 숨 쉬게 | BGM 은 목소리 아래 -25dB, 인트로·챕터·엔드카드에서만 부풀림. 추천 무드: 솔로 피아노/어쿠스틱 |
| 리포트 표지·페이지 레이아웃 | 오프닝 타이틀 = 표지(레드 바탕 + 짙은 레드 초대형 제목 + 가장자리 '20'/'26' + 가운데 작은 영상 프레임), 풀스크린 그래픽 = 리포트 페이지(상단 러닝 헤더: 채널 · 에피소드 · 연도 · ch 02) |

### 색보정(자동, `studio/grade/auto.py`)

컬러리스트의 3단계(참고: Zac Watson "3 Step Premiere Pro Color Grading" · "Color Grading Full Walkthrough")를 그대로 따른다.
1. **교정** — 화이트밸런스는 **피부를 피부색 선(CIELAB 색상 약 50°)에 놓는 것**이 기준(무채색 픽셀은 출발점, 조명이 섞인 얼굴은 얼굴 전체 평균). 노출은 얼굴 55~70 IRE, 블랙·화이트 포인트 정리. 장면의 조명(따뜻한 방, 창가의 푸른빛)은 지우지 않는다 — 따뜻한 장면은 WB 를 절반만.
2. **룩 = 목표, 양은 영상마다** — 룩마다 목표(밝기 스프레드 · 중간톤 채도 · 피부 채도 · 무채색의 온기)가 있고, 교정된 영상을 재서(`measure`) 목표까지 필요한 만큼만 더한다(`plan_recipe`): 평평한 소스엔 S-커브를 많이(최대 0.32), 채도 낮은 영상엔 채도를 많이(최대 1.8배, 피부는 따로 최대 1.3배, 파랑·청록은 절반), 이미 따뜻한 방엔 온기를 안 주고 중성·차가운 방엔 밝은 곳에만(b\* 최대 +9, 흰 것은 흰 채로), 떠 있는 암부는 내린다. 같은 룩이라도 영상마다·카메라마다 양이 다르고 로그에 남는다(“명암 0.48→S커브 0.32 · 채도 17→×1.22 · 온기 −1→+9”). **화면 평균색을 어디로 옮기지 않는다.**
3. **피부 보호** — 마지막에 피부만: 색상 32~60°, 채도 30 이하.
두 가지 실패를 모두 막는다: 교정이 방의 온기를 지운 회색 결과(채도 5.9), 평균을 레퍼런스(b\* +14.5)에 맞추느라 파란 조명의 방을 통째로 주황으로 만든 결과(얼굴이 오렌지, 흰 모니터가 노랑).

## 3. 타이포

- **Pretendard** (OFL) — 한글 본문·자막·제목. 제목은 Black(900) + 자간 -4~-5% 로 포스터처럼.
- **Anton** (OFL) — 숫자·영문 디스플레이(챕터 번호, 연도, 퍼센트). 리포트의 콘덴스드 그로테스크 역할.
- **Noto Serif KR** (OFL) — 인용문 전용 명조.
- 1080p 기준 스케일: 러닝 헤더 18 · 라벨 22 · 본문 34~46 · 제목 64~150 · 표지 230.

## 3½. 롱폼 무대(Stage) — 기본 챕터의 롱폼 고유 디자인

숏폼은 세로로 쌓고(카드 ↑ 얼굴 ↓) 카드를 갈아 끼우지만, 롱폼은 가로 무대(화자 열 36% + 작업대 열 64%)에서 요소가 같은 자리에
머물고 쌓인다. 오리엔테이션 장치 셋(상단 컨텍스트 스트립 · 챕터 카드의 목차와 주장 · 챕터 끝 정리 보드), 위계 하나(칩 → 헤드라인
→ 본문 → 각주, 강조는 한 낱말 밑줄 스윕), 모션 시그니처 하나(바깥에서 안으로 쓸어 들어오기 + 괘선 + 줄 마스크 슬라이드), 재질은
잉크 위 두 장의 판(화자 판 · 보드 판)과 유리 플레이트. 자세한 수치와 부품은 **`docs/롱폼_무대_디자인.md`**.

## 5. 모션

교육 영상이라 **튀지 않게**(2026-09 운영자 피드백: “훅훅 튀어 정신없다”).
- 등장: ease-out 12~18프레임, 텍스트는 마스크 안에서 아래→위로 3~4프레임 간격 스태거. 퇴장은 진입의 75%.
- 카메라: 와이드 100% ↔ 미디엄 106%, 실수를 잘라낸 자리·챕터·그래픽 복귀에서만. 샷 안은 초당 0.4%(최대 5%)로 아주 느리게.
- 다시점(원본을 여러 각도로 찍었을 때): 줌 대신 **앵글**을 바꾼다 — 점프컷 자리에서, 바꾼 뒤 최소 2.5초 유지, 한 앵글 최대 9초(숏폼 7초·가까운 앵글 선호). 앵글이 바뀌는 컷은 소프트 컷 없이 하드 컷, 새 샷은 와이드(100%)부터. 초점이 나갔거나 얼굴이 빠진 앵글은 피한다.
- 모든 움직임은 30fps 프레임 수로 짠다. 출력은 24/25/30fps — 50·60fps 원본(휴대폰)은 절반으로 내보내 움직임 속도가 같게.
- 점프컷: 같은 프레이밍이면 앞 장면 마지막 프레임을 0.1초 섞는 소프트 컷(길이·싱크 불변).
- 강조: 0.7초에 걸쳐 당기고 0.9초에 걸쳐 풀리는 글라이드(+4~9%). 콜아웃 자리 만들기도 천천히 옮겨 간다.
- 전환: 블러·푸시·와이프(챕터)·빛샘(타이틀)만. 휩·플래시·줌 전환은 쓰지 않는다.
- 칠판 패널: 바깥쪽 가장자리에서 열리고, 화자는 같은 시간에 1/3 열로 이동(얼굴이 열 가운데 오도록 추적).
- 도식 선: 분필처럼 그려지는 stroke 애니메이션, 지금 말하는 단계는 강조색 면. 목록/연표는 말하는 속도에 맞춰 순서대로.

## 6. 자막

- 롱폼: 하단 중앙 **흰 종이 상자 + 검정 글씨, 핵심어 어간만 굵게**(운영자 템플릿). 한두 마디(13자·2.4초 이하)씩, 말소리 시작에 맞춤.
- 화면 그래픽(개념 카드·도식·콜아웃)이 같은 말을 이미 보여 주면 그 자막은 화면에서 숨긴다(SRT 에는 남김).
- 숏폼(릴스식): 위 카드와 아래 얼굴 사이 이음새에 1~2어절(6자 안팎)씩 아주 굵은 흰 글씨 + 검정 외곽선·그림자, 강조어는 강조색.
- **두 층 강조 자막**(Nick Saraev 실측을 한국어로): 윗줄은 기울인 명조 흰 글씨(앞말), 아랫줄은 아주 굵은 고딕 핵심어(크림 → 따뜻한 주황 그라데이션, 숫자는 Anton). 핵심어가 들리는 순간 4프레임에 흐림 12px → 0 · 10px 떠오르며 등장, 상자·외곽선 없이 번짐 그림자만. 핵심어가 있는 한 마디에만 — 롱폼 18초 · 숏폼 3.5초에 한 번 이하(자주 쓰면 강조가 사라진다), 화면 그래픽이 글을 보여 주는 동안은 쓰지 않는다.

## 7. 사용자 템플릿에서 가져온 요소(기본 구성에서도 늘 쓰는 것)

| 요소 | 모양 | 쓰는 곳 |
|---|---|---|
| 찢어진 흰 액자 | 흰 테두리 약 12px, 손으로 찢은 듯한 가장자리 + 그림자 | 얼굴 옆 자료 사진·스톡(pip), 칠판 패널 사진, 타이틀의 화자 |
| 개념 텍스트 | 검정 라벨 + 아주 굵은 흰 글씨(그림자), 한 낱말만 강조색 | 얼굴 옆 키워드·숫자, 콜아웃 |
| 개념 카드 글 위계 | 흰 라벨 태그 → 헤드라인(한 낱말만 강조색) → 본문 → 회색 괄호 주석 | 칠판 패널의 키워드·정의·인용·숫자, 타이틀 |
| 출처 | 우상단 작은 흰 글씨 “출처: …” | 자료 사진·스톡·인용 |
| 엔드카드 | 오늘의 정리(챕터 목록) + 다음 영상 자리 2칸(액자) | 롱폼 끝 |

## 8. 화면 구성: 자동 하이브리드(기본 × 종이 콜라주)

사용자가 스타일을 고르지 않는다. `studio/edit/style.py` 가 대본·전사·기획(그래픽 종류)을 보고 정한다.

- **종이 콜라주** — 운영자 템플릿 3장을 측정해 옮긴 것: 구겨진 짙은 종이(절차적 생성) · 회색 거친 테두리(두께 약 38px) · 개념 카드 + 오른쪽 화자 액자 · 화자 전체를 액자에 담은 세 번째 앵글 · 얼굴 옆 액자 사진 + 개념 텍스트.
- **기본(에디토리얼)** — 칠판 패널 · 잉크 · 시그널 표면, 분필 도식.
- 챕터마다: 개념·사례·이야기가 중심(키워드·정의·인용·숫자·자료 사진, "예를 들어·제가·경험…")이면 종이, 구조·과정이 중심(프로세스·순환·매트릭스·비교·연표, "단계·구조·비교·첫째…")이면 기본. 챕터가 둘 이상인데 한쪽으로만 쏠리면 차이가 가장 작은 챕터를 반대로 둬서 **반드시 섞는다**.
- 그래픽마다: 개념 카드(키워드·정의·인용·숫자)와 타이틀은 어느 챕터에서든 종이(글 왼쪽 + 화자 액자), 도식·사진·스톡·모션은 그 챕터의 구성을 따른다. 액자 샷은 종이 챕터에서만.
- 결과는 편집 리포트에 “화면 구성(자동 · 하이브리드): 챕터 1 종이(개념·사례 중심) · 챕터 2 기본(구조·도식 중심)”처럼 남는다.

## 9. 숏폼 구성

- **릴스식** — 참고 릴스 구성: 위 큰 둥근 카드가 말에 맞춰 바뀌고, 아래는 얼굴 전체 폭, 이음새에 굵은 자막. 사진이 있으면 첫 2.2초는 카드 여러 장이 부채꼴로 겹친 흰 화면 + 큰 제목.
- 카드: 사진·스톡이 가득 / 어두운 앱 창 같은 도식 카드 / 개념 카드 세 가지를 번갈아 — 굵은 고딕 + 형광펜, 기울인 명조(에디토리얼), 어두운 구겨진 종이 + 라벨 태그 + 강조 낱말(종이 콜라주).
- 숏폼은 롱폼을 잘라 붙인 화면이 아니라 따로 구성한다(그 구간의 롱폼 그래픽을 물려받고, AI 가 3~5초마다 바뀌는 개념 텍스트를 쓴다). 레터박스·얼굴 전체 구성은 개발·시험용으로만 남아 있다.
