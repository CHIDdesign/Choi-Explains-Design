# 대본 태그 가이드

대본에 `[태그: 내용]` 을 넣어두면 그 문장을 말하는 순간에 **반드시** 그 그래픽이 들어갑니다.
태그가 없는 부분은 Claude 가 스타일 가이드(셜록현준식 흐름 + 밀도 규칙)에 따라 알아서 채웁니다.
태그는 자막에 나오지 않고, 음성 인식 정렬에도 영향을 주지 않습니다.

- 태그는 **그 뒤에 오는 문장**(또는 태그가 들어 있는 문장)에 붙습니다.
- 인자는 `|` 로 나누고, 여러 항목은 `;` 로 나눕니다.
- 괄호 안이 태그 종류가 아니면(예: `[괄호]`) 그냥 본문으로 둡니다.

## 구조

| 태그 | 예시 | 화면 |
|---|---|---|
| 챕터 | `[챕터: 문제를 다시 정의하기]` 또는 줄 맨 앞 `# 문제를 다시 정의하기` | 잉크 표면 챕터 카드(거대한 번호 + 제목), 설명란 타임코드 |
| 숏폼 범위 | `[숏폼 시작] … [숏폼 끝]` | 이 범위를 숏폼 1순위 후보로 |
| 줌 | `[줌]` | 그 문장에서 카메라 펀치인(2캠 전환처럼) |
| 컷 | `[컷]` | 그 문장을 영상에서 뺌 |
| 메모 | `[메모: 여기는 천천히]` | Claude 에게 전하는 연출 메모(화면에 안 나옴) |

## 그래픽

| 태그 | 예시 |
|---|---|
| 도식(유명 모델) | `[도식: 더블다이아몬드 \| 정의]` — 두 번째 인자는 강조할 단계. 지원: 더블다이아몬드, 디자인씽킹, 매슬로, 사용성위계, 린 |
| 도식(직접 정의) | `[도식: 우리 팀 프로세스 \| 관찰 ; 질문 ; 스케치 ; 테스트 \| 질문]` |
| 단계 | `[단계: 디자인 씽킹 \| 공감 ; 정의 ; 아이디어 ; 프로토타입 ; 테스트 \| 2]` |
| 순환 | `[순환: 반복 디자인 \| 만들기 ; 보여주기 ; 배우기]` |
| 강조(키워드) | `[강조: 발산]` · `[강조: 여백은 숨 쉴 공간 \| 디터 람스의 원칙]` |
| 정의 | `[정의: 어포던스 \| Affordance \| 형태가 사용법을 알려주는 성질]` |
| 인용 | `[인용: 좋은 디자인은 가능한 한 적게 디자인하는 것이다 \| 디터 람스 \| 10 Principles]` |
| 목록 | `[목록: 좋은 질문의 조건 \| 구체적이다 ; 열려 있다 ; 사용자를 향한다]` |
| 비교 | `[비교: 발산 : 넓게 ; 많이 \| 수렴 : 좁게 ; 깊게 \| 두 가지 사고방식]` |
| 매트릭스 | `[매트릭스: 기능과 감성 \| 좌상 ; 우상 ; 좌하 ; 우하 \| x낮음 ; x높음 ; y낮음 ; y높음 \| 우상]` |
| 연표 | `[연표: 모던 디자인의 흐름 \| 1919 바우하우스 ; 1953 울름 조형대학 ; 1956 브라운 SK4]` |
| 숫자 | `[숫자: 85% \| 다섯 명이 찾아내는 사용성 문제 \| Nielsen 2000]` |
| 벤 | `[벤: 좋은 아이디어 \| 매력성 ; 실현성 ; 지속가능성 \| 혁신]` |
| 피라미드 | `[피라미드: 디자인 욕구 \| 기능성 ; 신뢰성 ; 사용성 ; 숙련성 ; 창의성 \| 사용성]` |
| 사진 | `[이미지: Braun SK 4]` — 이미지 폴더에 `Braun SK 4.jpg` 가 있으면 그것, 없으면 위키미디어 커먼즈에서 자유 라이선스 사진을 찾아 출처와 함께 넣음. 세 번째 인자로 `split`/`pip` 지정 가능 |

## 예시

```
# 들어가며
여러분, 문 손잡이만 보고 밀지 당길지 아시죠? [강조: 어포던스]
오늘은 그 이유를 이야기해 보려고 합니다.

# 좋은 디자인은 설명이 필요 없다
[정의: 어포던스 | Affordance | 형태가 사용 방법을 스스로 알려주는 성질]
도널드 노먼은 이걸 어포던스라고 불렀습니다.
[이미지: Braun SK 4] 1956년 디터 람스가 디자인한 이 라디오를 보면…

[숏폼 시작]
사실 디자인과 학생들 대부분은 이 단계를 건너뜁니다.
[도식: 더블다이아몬드 | 정의] 문제를 정의하기 전에 해결책부터 그리거든요.
결국 좋은 디자인은 좋은 질문에서 시작합니다.
[숏폼 끝]
```

## 팁

- 대본이 없어도 동작합니다(음성 인식 결과로 자막을 만들고, Claude 가 전체를 판단). 다만 대본이 있으면 자막 오타가 거의 사라지고 NG 테이크를 정확히 걸러냅니다.
- 촬영 중에 틀려서 다시 말했다면 그대로 두세요. 같은 대본 구간을 여러 번 말하면 **마지막 테이크만** 남깁니다. "아 다시 할게요" 같은 말도 자동으로 잘립니다.
- 대본과 다르게 애드리브를 해도 괜찮습니다. 대본에 없는 말은 음성 인식 결과(용어 사전 교정 포함)로 자막을 답니다.
- 자주 틀리는 용어는 **설정 → 용어 사전**에 `틀린말=맞는말` 로 추가하세요.
