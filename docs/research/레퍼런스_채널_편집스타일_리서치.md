## 0. 먼저 읽을 것: 조사 방법, 근거 등급, 한계

### 접근 환경 (중요)
- 이 세션의 네트워크 정책 때문에 **WebFetch/직접 접속이 거의 모든 관련 도메인에서 차단**됐다. 차단 확인: youtube.com, i.ytimg.com(썸네일), namu.wiki, openads.co.kr, videocon.io, filmmakers.co.kr, v.daum.net, news.tf.co.kr, socialerus.com, ugwanggi.com, 주요 언론사, playboard, socialblade, archive.org.
- 그래서 **영상을 직접 보거나 썸네일·자막·트랜스크립트를 확인하지 못했다.** 사용한 경로는 둘뿐이다.
  1. **WebSearch**: 검색엔진 결과 제목·URL과 검색 요약문. 원문을 직접 읽은 것이 아니라서 아래에서는 **[검색요약]**으로 표시한다. WebSearch는 세션 한도(200회)를 다 써서 중간에 멈췄다.
  2. **GitHub(공개 저장소 원시 파일)**: 제3자가 YouTube Data API로 수집한 데이터셋. 특히 `nanappooo135-coder/youtube-finder`의 `scripts/economy/dataset_raw.json`에는 레퍼런스 채널 영상 57편(2025-09-16~2026-07-08)과 비교 채널들의 제목·게시일·조회수·좋아요·댓글·**길이(초)**가 있다. 수집 코드(`fetch_youtube_api.py`)를 읽어 보니 API의 `contentDetails.duration`을 초로 바꾼 값이었다. 수집 시점은 2026년 7월 중순쯤으로 보인다(채널별 최신 영상 날짜 기준). 이 데이터로 계산한 값은 **[데이터]**로 표시한다.
- **편집 디테일(자막 모양, BGM, 컷 속도, 카메라, 썸네일)은 대부분 직접 검증하지 못했다.** 이 부분은 **[미확인]** 또는 **[추론]**으로 표시했다. 자동 편집기에 넣기 전에 대표 영상 3~5편을 사람이 직접 보고 코딩해 보기를 권한다. 체크리스트는 6장 끝에 있다.

## 1. 채널 개요

| 항목 | 내용 | 근거 |
|---|---|---|
| 제작 철학 | 작가를 두지 않는다. 전문가가 기획 단계부터 참여하고, 제작사는 전달 형식을 고민한다. "시청자는 작가가 써준 정제된 이야기보다 전문가의 솔직한 이야기를 원한다." 레퍼런스 채널은 **"한 이슈에 관해 편하게 대화하듯 촬영"**하고, 건축을 **스토리텔링 방식**으로 푼다. 김지윤 채널은 뉴스 분석형이며 본인이 스크립트를 쓴다 | [1차] 아주경제 |
| 형식 원칙 | "주제에 맞는 형식과 캐릭터 조합이 가장 중요하다. 급격한 변화보다 정체성을 유지하는 점진적 변화(일관성)" | [1차] 제작사 인터뷰 |
| 편집 툴·인력 | 채용공고 기준 **Premiere Pro와 After Effects** 필수. 별도로 **모션그래퍼** 채용 있음 | [검색요약] 사람인·필름메이커스·편집몬 공고(2022년경) |

**업로드 주기와 길이** [데이터] (2025-09-16~2026-07-08, 약 42주, 57편)
- 롱폼 36편, 쇼츠 21편(3분 이하). **롱폼은 주 0.8~0.9편, 사실상 주 1편**이고 쇼츠는 월 2편꼴. 2021-09~2023-09에는 2년간 161편이라 주 1.5편 정도로 지금보다 잦았다 [데이터 기반 추론].
- **롱폼 길이: 중앙값 23.6분, 평균 24.3분, IQR 15.0~27.9분, 범위 9.5~51.5분.** 구간별로 <15분 8편, 15~20분 7편, 20~30분 13편, 30~45분 6편, 45분 이상 2편(하버드·MIT 등 현장 답사).
- **쇼츠 길이: 31~82초**, 대부분 45~65초.
- 조회수 중앙값은 롱폼 18.6만, 쇼츠 19.4만. 최고 조회수는 쇼츠 (제목 비공개)(1:22, 310만), 롱폼 (제목 비공개)(24:30, 221만).
- 좋아요/조회수 중앙값은 약 2.0%, 댓글/조회수는 약 0.14%.
- YouTube 카테고리는 27(Education), 기본 오디오 언어 ko [데이터: gpsyrou/tube-virality 트렌딩 JSON].

**형식 분류** (제목·설명란 기준. 괄호 안은 실제 영상)
1. **스튜디오 해설(1인 토크, 대화형)**
2. **현장 답사·여행 시리즈** (설명란에 챕터 타임코드)
3. **게스트 대담**
4. **자기 작업 소개**
5. **주제 확장(시사·경제·기술)**: 조회수 상위에 자주 든다
6. **연재·특집**
7. **쇼츠는 롱폼에서 잘라 낸 클립**으로 보인다. 날짜가 겹친다.

**설명란 형식** [데이터: 여러 저장소의 API 스니펫]
- 첫 줄에 해시태그 2~4개(`#건축 #도시 #역사`), 이어서 제목을 되풀이하는 한 줄 요약.
- 답사·다구간 영상에는 **타임코드(챕터)**가 있다. 실제 예:
  - 스타디움 리뷰(2023-12): `00:00 인트로 / 00:41 레알마드리드 경기장 / 05:07 FC바르셀로나 경기장 / 08:47 … 바이에른 뮌헨 / 13:52 … 파리 생제르맹 / 15:40 … 토트넘`
  - 하버드: `🕰️하버드대학교 캠퍼스투어 타임코드🕰️ 00:00 인트로 00:37 하버드 스퀘어 05:24 하버드 야드 …`
  - 뉴욕 EP1: `… 00:00 건축가의 미국 여행 …`
  - 여기서 나오는 규칙: **인트로는 37~41초**, **챕터 간격은 약 3.7~5.1분**, 챕터 이름은 **장소나 대상 명사구**.
- 자막 트랙: (제목 비공개) 검색 결과에 CC(字幕) 배지가 붙어 있어 **제작자가 올린 자막 트랙이 있는 영상이 있다.** 일부 제목에는 `[EN]` 접두어가 있어 영어 자막 제공을 알린다 [데이터].

- 근거 조각:

  2. **질문**: 왜 그럴까, 다른 도시는 어떤가
  3. **사례·역사·원리**: 해외 사례, 건축사, 인간 행동 원리. 이 구간에서 도면·사진이 가장 많이 나온다
  4. **인사이트 명명**: 짧은 개념어나 비유로 압축 ("공간은 권력", "개미굴")

대표 영상 3편(스튜디오형·도면형·답사형)을 골라 각각 첫 5분을 코딩한다.
- 분당 컷 수, 샷 크기 분포, 화자 위치(좌/중/우)
- 오픈 자막 유무·글자 수·색·위치, 강조 방식
- 그래픽 유형별 빈도(사진 풀스크린 / 패널 / 도면 애니메이션 / 지도 / 텍스트 카드)와 평균 유지 시간
- BGM 유무 구간, 효과음 빈도
- 첫 30초 대사 받아 적기(오프닝 문장 패턴)
- 이 결과로 규칙 8, 12, 16, 18~20의 [I] 파라미터를 교정한다.
