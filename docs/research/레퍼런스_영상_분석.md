## 0. 방법과 한계 (먼저 읽기)

**수집 방식**
- 영상 본편은 받지 않았다. `yt-dlp` 로 **스토리보드(sb0)**, **info JSON**, **자동자막(json3)** 만 받았다.
- 플레이어 클라이언트 `web_safari` 는 봇 체크("Sign in to confirm you're not a bot")가 간헐적으로 떴다. 영상마다 `web_safari → android_vr → web_embedded` 순서로 재시도했고, **19편 모두 스토리보드를 확보**했다.
- 해상도는 클라이언트마다 달랐다.

  | 구분 | web_safari | android_vr · web_embedded |
  |---|---|---|
  | 롱폼 | 320×180 (5 s 간격) | 160×90 |
  | 쇼츠 | 101×180 (1 s 간격) | 45–50×90 |

- 쇼츠 레이아웃 치수는 `https://i.ytimg.com/vi/<id>/oar2.jpg`(1080×1920 원본 비율 썸네일)에서 픽셀 단위로 측정했다.
- 자막 목록
  - `web_safari` info 에는 `automatic_captions` 가 비어 있었다.
  - 그래서 `web_embedded` 로 info 만 다시 받았다(`--skip-download --ignore-no-formats-error --write-info-json`).
  - 그 안의 timedtext URL(`fmt=json3`)을 curl 로 받았다. 429 가 1회 났고, 20초 뒤 재시도해 성공했다.
  - **19편 모두 한국어 ASR 을 확보**했다.

**라벨링 방식**
- 프레임은 전부 직접 봤다. 5개씩 × 6줄 접촉 시트로 만든 뒤 한 장씩 라벨링했다.
- 라벨 정의

  | 라벨 | 뜻 |
  |---|---|
  | F | 얼굴·토킹헤드 단독(자막만 있음) |
  | O | 얼굴 + 오버레이(키워드 텍스트, 인셋 사진, 챕터 태그, 아이콘) |
  | S | 분할 화면(얼굴 + 그래픽 패널이 화면을 나눔) |
  | G | 전면 모션그래픽, 다이어그램, 지도, 텍스트 카드, 스크린샷 카드 |
  | B | 사진, 아카이브, 스톡, 현장 B-roll(액자 프레임 안에 든 사진 포함) |
  | T | 채널 인트로, 엔드카드, 전면 챕터 카드 |

**한계**
- 샘플 간격이 5 s(쇼츠는 1 s)이므로 그보다 빠른 컷은 보이지 않는다. 컷 빈도는 **하한값**이다.
- 사물궁이 롱폼은 시트 0·3·4만 직접 봤다. 전 구간이 2D 애니메이션인 채널이라 시트 1·2도 G 로 간주했다.
- 쇼츠 라벨은 주로 앞 28–48 s 창에서 셌다. 평균 샷 길이(ASL)는 시트에서 샷 경계를 손으로 센 값이다.
- ASR 원문에는 오탈자가 많다. 아래 인용은 뜻이 통하도록 최소한만 교정한 짧은 구절이다.

원자료(스크래치패드 `research/`):
- `labels.json`, `shorts_labels.json`: 프레임별 라벨
- `stats.json`, `shorts_stats.json`: 통계
- `sb/<id>_sheet*.jpg`: 접촉 시트
- `subs/<id>.txt`: 타임코드 자막
- `thumbs/`: oar2 썸네일

## 2. 롱폼 영상별 표

엔드카드(T 꼬리)는 비율에서 뺐다.

**용어**
- 얼굴 노출: F + O + S
- 그래픽 레이어: O + S + G + T. 화면 어딘가에 디자인된 그래픽이 떠 있는 비율이다.
- 레이아웃 변경/분: 라벨이 바뀐 횟수
- 얼굴↔비얼굴/분: 얼굴 화면과 컷어웨이가 서로 바뀐 횟수
- 큰 변화 %: 인접한 두 샘플의 32×18 그레이 평균 차가 25를 넘은 비율
- 변화 간격: 샘플 간격 ÷ 큰 변화 비율. 시각 변화 1회당 평균 초수의 상한 추정이다.

### 2-2. 영상별 스타일 메모

**L1 셜록현준 · 구룡성채**
- 얼굴
  - 서재(나무 책장) 앞 미디엄샷이다. 인물은 화면 왼쪽 1/3~중앙에 선다.
  - 2캠: 정면 미디엄, 측면 클로즈업(인물 오른쪽). 가끔 와이드샷이 섞인다.
- 오버레이
  - 우측 빈 공간에 인셋 사진을 폴라로이드나 찢어진 종이 프레임으로 띄운다.
  - 우측에 키워드 2줄 박스를 띄운다.
  - 우측 사이드 챕터 태그: 짙은 청록 종이 패널 + "!" 원 아이콘.
- 전면 그래픽
  - 크림색 모눈종이 배경에 채도 낮은 청록 플랫 지도를 올린다.
  - 아이소메트릭 선화 다이어그램에 연도나 인구 라벨을 붙인다.
  - 1:20 비율 도해가 있다.
- 사진·B-roll
  - 청록 배경 위 찢어진 종이 액자에 아카이브 흑백 사진을 넣는다.
  - 드론 스톡과 영화·애니 스틸을 쓰고, 출처를 작게 표기한다.

**L2 셜록현준 · 재건축**
- 얼굴 비중이 가장 높다(86%). 대신 O가 40%라서 얼굴 위에 그래픽이 계속 얹힌다.
- 오버레이 요소
  - 이모지, 손 아이콘, 건물 일러스트
  - "이유.1 주민들 간의 입장 차이" 같은 번호형 키워드
  - 뉴스 헤드라인 카드
- 와이드와 클로즈업을 10–20 s 단위로 교차한다.
- 도입부 좌상단에 "오늘의 추리 / 아파트 재건축이 / 어려운 이유" 토픽 태그가 뜬다(탐정 컨셉 브랜딩).
- "Point.1" 전면 카드는 왼쪽 흑백 사진 + 오른쪽 청록 패널 구성이다.

**L3 셜록현준 · 도쿄·서울**
- B-roll 42%로 현장 촬영 비중이 크다. 도쿄를 걷는 인물, 드론을 쓴다.
- 그래픽 배경은 밝은 세이지·아이보리 단색이다. 누끼 건물 사진과 인물 컷아웃으로 도해를 만든다.
- 챕터는 상단 중앙 흰 바 + 초록 "!" 사각 아이콘으로 표시한다.
- 키워드는 좌하단에 흰 굵은 글씨 + 검은 외곽선을 쓰고, 핵심어를 초록으로 칠한다. 위에 작은 초록 라벨이 붙는다.
- 인물 뒤에 거대한 단어("주차장법")를 깔아 깊이감을 낸다.

**L4 14F 돈슐랭**
- 화면 상시 로고: 좌상단 시리즈 로고 "돈슐랭", 우상단 "14F".
- B-roll 81%. 음식 클로즈업과 방송·아카이브 클립을 쓴다.
- 노랑·분홍·민트 패턴 테두리 프레임과 레트로 TV 프레임을 쓴다.
- 요리 이름은 네온 그린이나 골드 세리프 대형 타이틀로 띄운다.
- 진행자는 흰 주방 세트에 미디엄샷으로 서고, 인물은 중앙~우측에 둔다. 진행자 등장 비중은 10%에 그친다.

**L5 지식해적단**
- 100% 일러스트 애니메이션이다.
- 양피지·베이지 배경에 세피아 실루엣 일러스트를 쓴다.
- 마스코트(해골 해적, 펭귄)가 말풍선으로 개입한다.
- 막대그래프, 세계지도, C3/C4 도식을 쓴다.
- 자막은 크림색 박스 + 검은 글씨다.

**L6 사물궁이**
- 100% 2D 플랫 애니메이션이다. 짙은 녹색 칠판 배경에 흰 동그란 머리 캐릭터가 나온다.
- "오늘의 주제" 분필 느낌 타이틀 카드로 시작한다.
- 자막은 박스 없이 흰 글씨를 하단에 둔다.

**L7 블랙스완**
- 얼굴이 없다. 시네마틱 스톡(어두운 톤)과 검은 배경 미니멀 다이어그램(색상환·톤 격자)으로 구성한다.
- 영화 스틸 아래에 5색 팔레트 띠를 붙인다.
- 로마 숫자 챕터 카드("IV 좋은 색감")를 쓴다.
- 자막은 매우 작은 흰 글씨이고 박스가 없다.

**L8 Madia UI**
- 검은 배경 위 모바일 목업 2장을 나란히 놓고, 빨간 ✕ / 초록 ✓ 로 Do/Don't 를 비교한다.
- 챕터는 대형 숫자 "03 아이콘 스타일"로 표시한다.
- 인트로와 아웃트로에만 스톡을 쓴다.

**L9 디고디원찬**
- 토킹헤드 72%다. 인물은 중앙 좌측, 나무 루버 벽 + 조명·꽃 배경이다.
- 텍스트가 매우 공격적이다.
  - 얼굴 위에 반투명 대형 빨강 텍스트("절대 디자인하면 안된다!")를 얹는다.
  - 민트 형광 박스(#2EF0C8 계열)에 남색 글씨를 우측 정렬로 여러 줄 쌓는다.
- 챕터 카드는 보라 전면 "| 디자인하면 안되는 유형 01"이다.
- 좌상단에 로고 "DGOD WONCHAN"이 상시 떠 있다.

## 8. 우리가 재현할 스타일 프로필 (구체 스펙)

> 기준 모델은 **셜록현준**(본인 출연 전문가 해설 + 아카이브 편집)이다. 여기에 디자인 채널의 도해 비중(블랙스완 다이어그램, Madia Do/Don't)을 더한다.
> 렌더러 용어와 대응: `Layout = fullscreen | split | overlay | pip`, 쇼츠 `layout: full | framed`.

### 8-1. 롱폼 화면 비율 목표 (엔드카드 제외)

| 유형 | 목표 | 근거 |
|---|---|---|
| 얼굴 단독 (TalkingHead, 자막만) | **25–30 %** | 셜록 중앙값 30 % |
| 얼굴 + 오버레이 (`overlay`: 키워드 콜아웃, 인셋, 챕터 태그) | **20–25 %** | 셜록 21 % |
| 얼굴 + 사이드 패널 (`split`, 인물 좌측 2/3 + 우측 청록 패널) | **3–5 %** | L1 4.4 % |
| 전면 그래픽 (`fullscreen`: 다이어그램, 도해, 비교 카드) | **20–25 %** | 셜록 14 % 에 디자인 이론 도해 수요를 더함 |
| 사진·레퍼런스 B-roll (작품, 건축, 제품 사진) | **20–25 %** | 셜록 30 % |
| 전면 챕터 카드 | 1–2 % | – |

→ 얼굴 노출 약 50–55 %, 화면에 그래픽 레이어가 떠 있는 시간 약 45 %.

### 8-2. 롱폼 편집 속도

- 레이아웃 변경: **분당 7회 전후.** 5–6 s마다 무언가 바뀌어야 한다. 앵글 전환, 오버레이 등장, 컷어웨이 중 하나.
- 얼굴↔비얼굴 전환: **분당 4–6회**, 컷어웨이 한 번에 5–10 s.
- 얼굴 단독 연속은 **10 s 이하가 기본**이다. 15 s를 넘으면 앵글 전환(와이드↔클로즈, 펀치인 110–120 %)이나 오버레이를 넣는다. 25 s는 절대 상한이다.
- 챕터 태그는 **90–150 s마다** 넣는다. 번호형 "이유 1 / Point 1"을 권장한다.
- 시작 구성
  - 콜드 오픈 티저: 본편에서 가장 센 문장이 담긴 12–18 s 클립
  - 채널 아이덴트 2–3 s
  - "오늘의 주제" 토픽 태그: 좌상단, 5–6 s
- 끝 구성: 요약 1문장 → "다음 시간에 …" → 엔드카드 15–20 s

### 8-3. 롱폼 자막 (LongCaptions)

| 항목 | 값 |
|---|---|
| 위치 | 하단 중앙, 박스 하단이 **프레임 높이의 95 %**(1080p 기준 y ≈ 1026 px) |
| 줄 수 | 1줄, 20–24자 |
| 서체·크기 | Pretendard/Noto Sans KR SemiBold(600), **글자 높이 3.3–3.8 % H**(1080p 폰트 약 40–44 px) |
| 박스 | 검정 **75 %** 불투명, 패딩 0.25em × 0.5em, 모서리 2–4 px. 외곽선 없음 |
| 강조 | 기본 자막에서는 하지 않는다. 강조는 콜아웃 레이어로 분리 |

### 8-4. 키워드 콜아웃 (Emphasis)

- 화자 **반대편** 빈 공간에 둔다. 인물이 좌측이면 우측 55–95 % x, 30–55 % y.
- 2줄 ExtraBold, 글자 높이 **6–8 % H**(폰트 약 70–90 px).
- 흰 글씨 + 4–6 px 어두운 외곽선 또는 그림자.
- 핵심어 1–2개만 강조색으로 칠한다.
- 위에 작은 컨텍스트 라벨을 붙인다(강조색 박스, 2.5 % H).
- 등장: `SPRING` 팝, 약 12 f. 유지 3–5 s.

### 8-5. 챕터 태그

- 형태 A: 우상단 사이드 패널. 짙은 청록 종이 텍스처 + "!" 원형 아이콘 + 흰 굵은 2줄.
- 형태 B: 상단 중앙 흰 바 + 강조색 "!" 사각 아이콘 + 짙은 글씨.
- 유지 4–6 s.

### 8-6. 전면 그래픽 양식

- 배경: **크림·아이보리 종이**(#EFE9DC, 모눈 텍스처 5 % 불투명) 또는 세이지 단색.
  - 밝은 배경이 기본이다. 어두운 배경은 색채 이론 장면(블랙스완식 검정 + 색상환)에서만 쓴다.
- 주조색: 짙은 청록 #1F4B46, 갈색 #6B4A2B, 강조색 1개.
  - 셜록현준은 초록 #3CC08A 와 주황 #FF6B2C 를 쓴다. 우리는 브랜드 강조색 하나로 통일한다.
- 형식
  - 플랫 도형과 아이소메트릭 선화
  - 누끼 사진 + 치수·비율 라벨(예: "1 : 20")
  - 좌우 비교 카드(Before/After, Do ✕ / Don't ✓)
  - 5색 팔레트 띠를 붙인 이미지(색채 설명용)
  - 연도·수치 라벨
- 레퍼런스 사진: **찢어진 종이·폴라로이드 액자**에 넣어 청록 배경 위에 약간 기울여 올린다. 출처는 우하단 1.5 % H 로 표기한다.
- 이모지·아이콘은 얼굴 오버레이에만 소량 쓴다.

### 8-7. 전체 룩

- 따뜻한 중성 톤(인물 5000–5600 K 자연광, 책장·나무 배경), 중간 대비.
- 그래픽은 채도를 낮게 유지하고 강조색만 고채도로 둔다.

### 8-8. 쇼츠 (ShortCaptions / `framed` 레이아웃, 1080×1920)

**배치**

| 요소 | 세로 범위 (px) | 스펙 |
|---|---|---|
| 배경 | 전체 | 검정 #000(또는 브랜드 다크) |
| 상단 타이틀 | 180–395 | 2줄 고정, 중앙 정렬, 초굵은 고딕(Black 900), 폰트 약 88–96 px |

- 대안(풀프레임 얼굴형, 디고디원찬식)
  - 얼굴 9:16 풀프레임
  - 상단 타이틀은 반투명 짙은 회색 박스에 넣는다
  - 설명 구간은 "상단 50 % 그래픽 / 하단 50 % 얼굴" 분할(`split`)
  - 툴 시연은 화면 + 원형 얼굴 PIP(`pip`, 우하단 지름 약 30 % W)

**속도·구성**
- ASL **2–2.5 s**. 컷 없이 3 s를 넘기지 않는다. 같은 샷이라도 펀치인이나 오버레이로 변화를 준다.
- 얼굴 30–50 %, 나머지는 B-roll·도해.
- 첫 프레임: 타이틀 + 가장 강한 비주얼(작품·건물 클로즈업, 또는 말하는 도중인 얼굴)을 동시에 띄운다. 인사와 로고 인트로는 금지한다.
- 첫 문장은 0–3 s 안에 **역설 주장, 수치, 질문** 중 하나로 시작한다.
- 쇼츠 타이틀 문형
  - "~한 이유"
  - "~의 반전?"
  - "~, '이것' 없으면 탈락합니다"
  - "우리가 몰랐던 ~의 비밀"
  - 2줄로 끊고, 2번째 줄에 핵심어를 둔다.

### 8-9. 훅 대본 규칙 (프롬프트 반영용)

- 롱폼: 본편에서 가장 반직관적인 한 문장을 콜드 오픈으로 앞에 붙인다(12–18 s). 그 뒤에 인사와 "이번 시간에는 X를 Y 관점에서" 한 줄을 둔다.
- 쇼츠: 제목과 같은 뜻의 역설·수치·질문 한 문장으로 시작한다. 5 s 안에 "근데 / 의외로 / 사실은" 전환을 한 번 넣는다.
