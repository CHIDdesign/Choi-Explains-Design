## 1. 오프닝·구조 규칙

### R1.1 첫 30초는 3단계로 [V]
| 구간 | 할 일 | 파라미터 |
|---|---|---|
| 0–5초: 패턴 인터럽트 | 대담한 주장, 뜻밖의 장면, 화면 텍스트, 한 줄 질문 | **첫 발화 ≤0.5초**(무음 리드 금지). Ali Abdaal은 2.5초 안에 본론, "hey guys"·"in this video" 없음 [V writepanda] |
| 5–15초: 약속 | 이 영상을 끝까지 보면 얻는 구체적인 한 가지 | 15초 안에 걸린 것(stakes)을 말한다 [V air.io] |
| 15–30초: 커밋 훅 | 정보 공백, 증거, 이야기의 시작 | 30초 시점 잔존율이 이후 성적을 가장 잘 예측한다 [V prepublish] |

- 구현: 대본에서 `hook_segs`(질문·반전 문장)를 0초로 당긴다. 인사·자기소개 문장은 **삭제하거나 아이덴트 뒤로 보낸다** [I].
- 첫 5초 안에 **증거 비주얼 1개**(사진·자료)를 넣는다. 셜록현준은 0:04에 테이프 붙인 사진 카드, 0:09에 풀스크린 사진이 나온다 [O].

### R1.2 채널 아이덴트·타이틀 카드는 훅 **뒤**에 [V][O]
- 로고 범퍼로 시작하면 3~5초를 버리고 리텐션을 깎는 7대 패턴 중 하나다 [V prepublish]. 브랜딩 인트로는 넣더라도 5초 미만 [V pixflow].
- 셜록현준: 콜드오픈(화자 + 증거 사진) 14초 → **0:14~0:19 채널 아이덴트 약 4~5초**(종이 콜라주, 돋보기·파이프, 키워드 칩 "도시·공간·건축") → 0:24 사이드 토픽 카드 「오늘의 추리: 주차와 도시」 [O]. 14F 시리즈 아이덴트는 1:14 [O].
- **기본값 [I]**: 아이덴트는 훅이 끝나는 문장 경계에서 시작한다. 목표 12~20초, 허용 8~30초. 길이 **3초(90f)**, 범위 2~5초. 이어서 토픽 카드를 **3~4초** 동안 화자 옆에 띄운다.

### R1.3 인트로 길이와 첫 챕터 [데이터][I]
- 셜록현준 챕터 데이터: 인트로 37~41초, 챕터 간격 3.7~5.1분(`docs/research/셜록현준_편집스타일_리서치.md`, YouTube API 데이터셋).
- **기본값**: 인트로 ≤40초(허용 30~60초). 첫 챕터 카드는 40초 안팎.

### R1.4 오픈 루프와 리훅 [V][S]
- 첫 2분 안에 오픈 루프가 1개 이상 있는 영상은 완주율이 20% 높다는 주장이 있다 [S 검색요약, 원 통계 출처 불명].
- **리훅 주기**:
  - 2~3분마다 [V air.io Narrative Loop / pixflow "Rehook every 2–3 minutes"]
  - MrBeast 매뉴얼: 1분이 가장 중요하고, **3분과 6분**에 재참여(re-engagement) 장치를 둔다 [V jarvis 메모]
  - 첫 패턴 인터럽트는 **25~35초** [V air.io, pixflow]
- **기본값 [I]**: 리훅 후보를 `t = 30초, 이후 150초마다`(허용 120~180초)로 표시한다. 챕터 경계와 가까우면(±30초) 챕터 카드로 합친다. 리훅 수단은 셋 중 하나: ① 질문 문장 + 화자 클로즈업, ② 앞으로 나올 내용 예고 카드, ③ 음악 교체나 정지.

### R1.5 챕터 [V][데이터][I]
- YouTube 규칙: 타임스탬프 **3개 이상, 첫 번째는 0:00, 각 챕터 ≥10초**. 하나라도 어기면 챕터가 표시되지 않는다 [S support.google.com/youtube/answer/9884579].
- 학습 영상은 **6분 미만** 덩어리일 때 몰입이 가장 높다(edX 690만 세션, 중앙 몰입 시간 ≤6분) [V Guo 2014].
- **기본값 [I]**: 챕터 간격 4분(허용 3~6분, 6분 초과 금지). 챕터 제목은 대상·사례 명사구.
- 챕터 카드: **60f(2초)**, 범위 45~75f. 등장 12~18f(`EASE.outQuint`), 퇴장은 등장의 75%.
- Ali Abdaal 챕터 카드 [O]: 가운데 주황 둥근 카드(#F5805B 계열) + 아이콘 배지 + 세리프 제목 + 알약형 부제("Week #2"). 좌우에 다음·이전 카드 윤곽이 보이는 캐러셀 형태. 2:16, 7:37, 15:43에 등장(약 3~8분 간격).
- 셜록현준 소제목 카드 [O]: 화자 옆에 짙은 틸 박스 + 흰 굵은 글씨 + "!" 배지(「구룡성채의 탄생 배경」, 「슬럼화가 되는 이유」, 「현실적인 차고지 증명제 도입 방안」).

### R1.6 설명 구조: 통념 먼저 [S][I]
- Derek Muller(Veritasium) 박사 연구: 설명만 보여 주면 오개념이 오히려 강화된다. **흔한 오개념을 먼저 말하고, 틀린 이유를 보이고, 정답을 준다**. 오개념 기반 수업의 사후 점수 향상은 9.1점, 전통 방식은 6.8점 [S].
- 디자인 이론에 적용 [I]: "좋은 디자인은 예뻐야 한다"(통념) → 반례 → 원리 → 개념 이름 붙이기 → 일상 적용. `prompts/style_guide.md`의 셜록현준 흐름과 같은 방향이다.

### R1.7 본문 페이싱 곡선 (Progressive Rhythm) [V]
- Veritasium·Ali Abdaal 패턴: **처음 3분은 10~20초마다 시각 리셋**, 몰입이 생기면 25~40초 간격으로 넓히고, 8분 이후에는 차분한 설명 사이에 짧은 에너지 버스트를 섞는다 [V air.io].
- Contrast 패턴: 대부분 차분하게(컷당 15~25초) 가다가 **2~3분마다 5~10컷 버스트** [V air.io].
- 연령별: 25세 이상 시청자에게는 20~40초마다, 주제나 톤이 바뀔 때만 시각 변화를 주고 전환은 단순 페이드나 가벼운 줌으로 [V air.io].

### R1.8 엔딩 [V][O]
- MrBeast: 엔딩은 리텐션을 지키려면 **갑작스러워야** 한다 [V jarvis].
- 작별 인사와 구독 요청은 이미 이탈이 많은 구간이라 **빼거나 한 줄로 줄인다**. 연 루프를 닫은 뒤 **다음 질문 하나**를 남기고, 추천 영상 **하나**를 말로 가리킨다 [V air.io].
- 셜록현준 [O]: 마지막 문장 "다음 시간에 또 찾아오도록 하겠습니다" → 엔드카드(채널 아이덴트 + SUBSCRIBE 버튼 + 좌하단 "자료출처: Gettyimages korea") **15~20초**.
- 상세는 R12.

## 2. 페이싱 규칙

### R2.1 평균 샷 길이 목표 (샷 = 시각 상태 하나: 카메라 앵글, B-roll 클립, 그래픽 한 장)
| 구간 | 기본 ASL | 범위 | 근거 |
|---|---|---|---|
| 콜드오픈 0–30초 | **4초** | 3~6초 | 셜록 첫 30초는 5초 샘플마다 화면이 바뀜(≤5초) [O]. 최소 5~7초마다 시각 변화 [V pixflow]. 시작부는 10~15초마다 앵글·화면 녹화·클로즈업·컷어웨이를 바꾼다 [V air.io]. 쇼츠 Ali는 3~8초 [V writepanda] |
| 30초–3분 | **5초** | 4~7초 | 셜록 ASL 추정 4~7초 [O] |
| 본문 3분 이후 | **6초** | 5~9초 | [O]+[I]. 교육용 클립은 8~15초 [V vidpros]. 두 값의 절충 |
| 결론·아웃트로 | **8초** | 6~12초 | 결론 문장은 얼굴로 길게 [I] |

- **같은 프레이밍 최대 20초**, 화자만 나오는 정지 화면 최대 **40초** ("40초 넘게 정지한 토킹헤드는 리텐션 그래프를 평평하게 만든다" [V air.io]). 셜록 경험담 영상에는 화자 구간이 144초까지 이어지지만 그 안에서 앵글이 계속 바뀐다 [O].
- **2초 넘게 아무것도 움직이지 않고 소리도 없는 구간 금지**. 영상이 끝난 것처럼 읽힌다 [V air.io].

| 잘라낼 최소 무음 길이 | **0.35초** | 0.30~0.60 | 자연스러운 리듬 [S] |
| 발화 앞 패딩 | **0.10초** | 0.08~0.15 | |
| 발화 뒤 패딩 | **0.15초** | 0.10~0.30 | [S] |
| 문장 끝 호흡 보존 | **0.30초** | 0.25~0.45 | 대화형 톤. 문장 **안**은 자르지 않음 [V writepanda: "hard trims between segments, never inside sentences"] |
| 앞 문장 끝으로 당기기 | 0.2초 | 0.1~0.25 | "마지막 음절을 기다리다 생기는 빈틈 제거" [V jupitrr] |
- 컷은 숨 쉬는 지점에서 한다. 단어나 제스처 중간에서 자르면 편집이 눈에 띈다 [V air.io].
- 싱크 규칙(프로젝트): 영상 컷은 CFR 프록시 프레임 단위, 음성은 FFmpeg 샘플 단위. 위 패딩값을 프레임 경계에 맞춰 반올림한다(가까운 프레임, 30fps = 33.3ms).

### R2.3 J/L 컷 [V][I]
- J컷 오프셋은 보통 **1~10프레임** [V firecut].
- **기본값 [I]**:
  - 화자 → B-roll: 그림이 **키워드 첫 음절 −2f**에 들어온다(예비 동작).
  - B-roll → 화자: B-roll이 절 끝 **+6f**(범위 4~12f)까지 남는다(L컷).
  - 챕터 전환: 다음 챕터 음악·앰비언스가 **8~15f** 먼저 들어온다(J컷).

### R2.4 에너지 버스트 [V][I]
- 2~3분마다 10~15초짜리 버스트(5~10컷)를 넣을 수 있다 [V air.io Contrast].
- 디자인 채널 적용 [I]: 버스트는 밈이 아니라 **사례 몽타주**로 만든다. 레퍼런스 작품 4~6장을 **0.8~1.2초(24~36f) 간격**으로 넘기고 비트에 맞춘다. 챕터당 최대 1회.

## 3. 토킹헤드 카메라 처리

### R3.1 가상 앵글(점프컷 교차 프레이밍) [S][V][O]
셜록현준은 실제로 2~3대 카메라(또는 크롭)로 **와이드(책상과 소품이 보이고 화자는 우측 1/3) / 미디엄 / 클로즈**를 교차한다 [O]. 1캠 원본이면 크롭으로 흉내 낸다.

| 앵글 | 기본 스케일 (4K 원본 → 1080 출력) | 1080 원본일 때 | 구도 |
|---|---|---|---|
| A 와이드 | 100% | 100% | 눈높이 y≈0.33~0.38H, 화자 x≈0.55~0.66W(한쪽에 여백) |
| B 미디엄 | **118%** (115~125) | **112%** (110~115) | 눈 y≈0.33H, 가운데~약간 옆 |
| C 클로즈(강조) | **140%** (130~150) | ≤120% | 가슴 위, 눈 y≈0.30H |

- 근거:
  - 1080 소스 확대는 110%까지 안전, 소스가 아주 깨끗하면 120% [S creativecow]
  - 4K 소스를 1080으로 내보내면 1920×1080 크롭까지 손실이 없다 [S videoguys]
  - 1080 출력·4K 소스에서 ~130%를 넘으면 흐려지기 시작한다 [V echowave]
  - 펀치인은 흔히 115~135% [S wisecut/echowave]
  - 하드컷용 두 번째 카피는 20~30% 확대 [V echowave]
- **점프컷마다 A↔B를 번갈아** 쓴다. 같은 스케일로 이어 붙이지 않는다. 크기 차이는 **≥12%**. 비슷한 크기끼리 붙이면 실수한 점프컷처럼 보인다 [V air.io "skip a shot size"].
- 컷을 넘어 **눈 위치 변화 ≤ 화면의 10%**(매치 컷의 원칙) [V air.io]. 스케일 기준점은 얼굴 중심.
- 스케일 상한: `maxScale = min(1.5, 원본높이/1080 × 1.15)` [I].

### R3.2 느린 푸시인 [S][V][I]
- Premiere 관행: 클립 시작 100% → 끝 **105~110%**. 천천히, 믿을 만하게 [S trentogilvie]. 시네마틱 푸시는 100%→115%를 10초 이상에 걸쳐 [V echowave]. Ken Burns 기본 확대 1.10 [S pypi burns].
- 사고가 끝날 때까지 천천히 밀고, 다음 섹션에서 와이드로 **하드컷 복귀**. 압력을 쌓았다가 풀어 준다 [V jupitrr].
- **기본값 [I]**:
  - 화자 롱홀드(≥6초): 초당 +0.5%(범위 0.3~1.0%/s), 누적 최대 +6%, `EASE.linear` 또는 inOutSine. 되돌아가는 줌아웃은 금지하고 다음 컷에서 리셋한다.
  - 사진·B-roll 스틸: 100→106%를 클립 길이 전체에(3~6초), 약한 팬 ±2%W.
  - 셜록현준식 첫 등장 자료 사진: 끝까지 105% 이하(`style_guide.md`와 같음).

### R3.3 강조 펀치인 [S][V][I]
- 펀치인은 강조다. **나머지 대부분에 없어야** 효과가 있다. 훅, 감정적인 한 줄, 펀치라인, 섹션 전환, 곱씹어야 할 요점에만 쓴다 [V jupitrr]. Ali 쇼츠는 영상당 최대 1회, 75% 지점, 약 1.5배 [V writepanda].
- 30fps에서 **12프레임(0.4초)**이면 빠른 펀치인, **24~45프레임**이면 의도적인 느낌 [S echowave/morphic].
- **기본값 [I]**:

| 파라미터 | 값 |
|---|---|
| 방식 | ① **하드컷 펀치**(기본): 강조어 첫 음절 −1f에 현재 앵글에서 +15~20% 크기로 컷 ② **스냅 줌**: 8f `EASE.outCubic`(범위 6~12f) |
| 홀드 | 강조 문장 끝까지. 최소 1.0초, 최대 4초 |
| 해제 | 줌아웃 대신 **다른 앵글로 하드컷** |
| 밀도 | 기본 **분당 0.75회**(45~80초에 1회). 상한 분당 1.5회, 롱폼 전체 최대 12회. `style_guide`의 punch(분당 1~2회)는 상한으로 본다 |
| 사운드 | 스냅 줌이면 whoosh·snap의 가장 센 지점을 줌이 **도착하는 프레임**에 [S morphic zoom sfx] |

### R3.4 마이크로 셰이크 [S][I]
- 정적인 샷에 "살아 있는" 느낌을 주는 값: wiggle(주파수 2~3, 진폭 5~8px). 회전은 wiggle(0.5, 0.3°) [S schoolofmotion 계열]. Mrwhosetheboss 인트로처럼 정적인 샷에 흔들림을 흉내 내는 기법 [V air.io].
- **기본값 [I]**: **기본은 끔**(셜록·Ali 톤은 삼각대 고정 [O]).
  - 켤 때: 위치 노이즈 0.8Hz / 3px(범위 0.5~1.5Hz, 2~6px @1080), 회전 ±0.15°, 오버스케일 101.5%(가장자리가 드러나지 않게).
  - 쓰는 곳: 펀치인 홀드, Johnny Harris식 사진 콜라주(2프레임 홀드 스텝 애니메이션과 함께)만.
  - 구현: 1D value-noise(시드 고정)를 `interpolate`로 매핑. 매 프레임 결정적이어야 한다.

### R3.5 그래픽 자리를 위한 리프레이밍 [V][S][O]
- 셜록현준: 화자의 몸·얼굴이 **향하는 방향**에 인포그래픽을 둔다. 좌우 한쪽 일정 공간을 칠판처럼 쓴다 [V openads]. 2025~26년 영상에서는 와이드 앵글 자체가 화자를 우측 1/3에 두고 왼쪽 책상 공간을 비워 두며, 카드는 빈 쪽 x=0.05~0.40W 또는 0.58~0.95W에 붙는다 [O]. 사이드 패널(짙은 틸 #2A4745)은 화면의 약 **1/3**을 차지한다 [O].
- 인터뷰 구도: 화자가 오른쪽을 보면 왼쪽 1/3선, 반대도 마찬가지. **음의 공간은 시선 방향 쪽** [S wave.video 계열].
- **기본값 [I]**:
  1. 얼굴 방향(yaw)과 얼굴 중심 x를 검출한다.
  2. 여백 쪽 폭이 ≥0.38W면 리프레이밍 없이 **카드 폭 0.30~0.36W**를 여백 중앙에 둔다.
  3. 여백이 부족하면 **다음 점프컷에서** 오프셋 앵글로 바꾼다(움직임이 보이지 않게). 오프셋 dx=0.12~0.15W, 필요 스케일 ≥1+2·dx(=1.24~1.30)이라 4K 원본에서만. 1080 원본이면 패널 모드(화자 위에 불투명 패널 1/3)로 간다.
  4. 컷 없이 꼭 움직여야 하면 18f `EASE.inOutCubic`.

## 4. 얼굴 vs 보이스오버 그래픽·B-roll·분할 화면

### R4.1 근거
- 강의 영상에서 **토킹헤드를 슬라이드 사이에 끼운 영상**이 슬라이드만 있는 영상보다 몰입이 높다. 권장: "좋은 타이밍에 강사 얼굴을 삽입하라" [V Guo 2014]. 편집자들이 반복 전환을 거슬려 할 때는 PiP가 대안이다 [V Guo 2014].
- 시선 추적: 얼굴이 있으면 시선의 **약 41%**가 얼굴에 가고, **3.7초마다** 얼굴과 슬라이드를 오간다. 학습자는 얼굴 있는 쪽을 강하게 선호한다(회상 점수 차이는 없음) [S Kizilcec 2014].
- Mayer 원리: 무관한 자료를 빼면 학습이 깊어진다(coherence, d≈0.70~0.86). 구조를 드러내는 신호를 넣으면 좋다(signaling, d≈0.46). **그래픽 + 내레이션 + 같은 문장 텍스트**는 그래픽 + 내레이션보다 못하다(redundancy, d≈0.87) [S].
- 실무 기준: 그 주장을 이해하거나 믿는 데 무엇을 봐야 하는가. 자신감·감정·진심·경험은 얼굴로, "어떻게 생겼나·어떻게 되나"는 B-roll로, 숫자·목록·비교·과정·인용은 그래픽으로 [V pireel]. A롤 60 : B롤 40이 흔한 출발점 [S captions.ai].

### R4.2 목표 비율 [O][I]
| 프리셋 | 화자 풀프레임 (F+O) | 사이드 패널·PiP (S) | B-roll·사진 | 풀 그래픽 | 근거 |
|---|---|---|---|---|---|
| **셜록형 (기본)** | **50%** (40~65) | 5% (0~10) | **30%** (20~40) | **13%** (8~18) | [O] 셜록 3편 평균: 화자 59%, B 27%, G 11% |
| 경험담·에세이형 | 75% (65~86) | 0~5% | 10% | 5% | [O] 재건축 영상 86% |
| Ali형 (PiP) | 40% | **45~50%** | ≤5% | 5~10% | [O] |
| 다큐형 (JH/Vox) | 15~30% | – | 40~50% | 25~45% | [O] |

- 풀스크린 **그래픽** 합계는 35% 이하(`style_guide.md`). 풀스크린 (B-roll + 그래픽) 합계는 **≤55%**(셜록 최대 58%) [I].

### R4.3 문장 유형 → 화면 결정표 [I] (근거: pireel·Guo·Mayer·셜록 관찰)
| 문장 특징 (대본·ASR 태깅) | 화면 | 길이·규칙 |
|---|---|---|
| 훅 질문, 반전, 결론, 의견, 감정, 경험담("제가…") | **화자 풀프레임**(C 또는 B 앵글) | 그래픽으로 가리지 않음 (`style_guide`의 Keep it human) |
| 고유명사 첫 등장(작품·건물·디자이너·브랜드) | **사진**: 풀스크린 또는 화자 옆 사진 카드 | 1초 안에. 풀스크린 3~6초, 카드 2.5~4초 [O: 셜록은 테이프 붙인 사진 카드를 화자 옆에] |
| 장소·국가·도시 | **지도**(풀스크린) | 2~4초. 빨강 해칭이나 라벨 박스로 표시 [O] |
| 숫자·통계 | 화자 옆 또는 B-roll 위 **숫자 카드** | 2~4초. 카운터는 R6.3 |
| 비교 "A와 B" | 좌우 분할 비교 그래픽(크림 배경) 또는 화자 양옆 라벨 "서울 ↔ 도쿄" | 3~6초 [O] |
| 목록·단계 | 사이드 패널 목록(S) 또는 풀 그래픽 | 항목이 말에 맞춰 누적 |
| 정의·용어 | 정의 카드(종이 메모 + 테이프) | 3~5초 [O: 셜록 「해금」 카드, 14F 「차고지 증명제」 카드] |
| 인용·책 | 책 표지 + 저자 컷아웃 + 이름 라벨(화자 옆) 또는 인용 카드(풀스크린) | 3~6초 [O] |
| 역사적 사건 | 아카이브 사진·회화 풀스크린 + 작은 라벨 메모 | 3~6초, 아주 느린 푸시 |
| "이렇게 생겼다·이렇게 된다" | B-roll(스톡·드론·거리) | 클립당 3~6초. 한 문장에 1~2클립 |
| 추상 원리(디자인 이론 본체) | 모션 다이어그램(MotionScene) | 설명이 끝날 때까지 유지. 단계는 highlight로 |

- **연속 제한 [I]**:
  - 비화자 구간 최대 30초(셜록 최대 35~40초 [O]). 넘으면 화자를 1회 이상(≥2초) 끼운다.
  - 화자 구간 최대 45초. 넘으면 R3.1 앵글 교체와 오버레이 카드로 쪼갠다.
  - 전체에서 얼굴이 사라지는 최장 시간은 45초.

### R4.4 분할 화면·PiP 모드 [O][I]
- **셜록 사이드 패널**: 화자는 원래 구도 그대로, 반대쪽 약 1/3에 짙은 틸(#2A4745) 패널을 깔고 아이콘·국기·짧은 라벨을 얹는다 [O].
- **Ali PiP**: 크림 캔버스(#FBF8F1) 위에 UI 화면·목록·차트를 놓고, 화자를 **둥근 모서리 사각형 PiP**(폭 약 0.20~0.22W, 모서리 반경 ≈ 폭의 8%, 옅은 그림자)로 좌우 가장자리 중앙에 둔다 [O].
- **기본값 [I]**:
  - PiP 폭 0.21W, 여백 0.04W, 반경 24px(@1080)
  - PiP 진입 12f `EASE.outQuint`(스케일 0.92→1, 불투명도). 화면 녹화나 긴 목록 설명(≥8초)에서만 쓴다.

## 5. 트랜지션

### R5.1 원칙 [V][O]
- 큰 트랜지션(시네마틱 줌·whoosh·스팅어)은 **장면 전환, 핵심 폭로, 감정 정점**에만. 그 사이는 단순 점프컷 [V air.io, MrBeast 사례]. "이야기의 진행을 표시하지 않는 트랜지션은 소음이다."
- Johnny Harris·Vox 룩: **하드컷 위주, 디졸브 최소**, 홀드 보간의 공격적인 펀치인 [V fcpxfullaccess]. Vox는 3D 카메라를 뒤로 트래킹하고 블러를 살짝 줘서 **거의 안 보이게** 잇는다 [S premiumbeat].
- 셜록현준 스토리보드에서는 트랜지션 효과가 관찰되지 않았다(5초 샘플 한계). 하드컷 위주로 추정 [O/I].
- **기본 분포 [I]**: 하드컷(J·L 포함) ≥90%, 디졸브류 ≤7%, 스타일 트랜지션(휩·줌스루·와이프) ≤3%(롱폼 20분에 3~6회, 챕터 경계에만).

### R5.2 트랜지션 사양표 (30fps)
| 유형 | 언제 | 길이 (프레임) | 이징·파라미터 | SFX | 근거 |
|---|---|---|---|---|---|
| **하드컷** | 기본 | 0 | – | 없음 | [V] |

### R6.3 숫자 카운터 [S][O][I]
- 카운트는 **ease-out**으로 마지막에 감속해 착지를 강조한다. 숏폼은 2~4초, 기본 2초 [S].
- 셜록 [O]: B-roll(도쿄 인파) 위 좌하단에 「도쿄 인구 **1,400만** / 서울의 1.5배」. 라벨은 작고 숫자는 크며 녹색 강조.
- **기본값 [I]**: 카운트 **24f**(범위 18~36), `EASE.outExpo`, `tabular-nums`, 착지 후 1.00→1.04→1.00(6f), 착지 뒤 홀드 ≥1.5초. 숫자 높이 0.09~0.11H(≈100~120px), 단위·라벨은 고정 텍스트.

### R6.4 인용 카드 [V][O][I]
- 화면 텍스트는 느린 독자(200wpm)가 **두 번 읽을 수 있을 만큼** 둔다 [V SSW]. 공식: 3초 + 단어당 0.5~0.7초 [S].
- 한국어 환산 [I]: `hold_s = clamp(0.8 + 글자수/6, 2.0, 8.0)`. 12CPS로 두 번 읽는 시간 + 시선 착지 0.8초. 예: 24자 → 4.8초.
- 셜록 [O]: 어두운 바다 B-roll 위 가운데 흰 2줄 인용 + 아래 작은 "출처 – …".
- 구현 규칙: 인용 카드가 말과 **같은 문장**이면 그동안 하단 자막을 숨긴다(Mayer redundancy) [I].

### R6.5 목록의 항목별 등장 [O][I]
- Ali [O]: 왼쪽 정렬 목록, 주황 원형 번호 배지(1~5), 말할 때마다 한 줄씩 추가된다. 최대 5줄. 흐름도(박스 + 점선 화살표)도 같은 방식으로 누적.
- Veritasium [O]: 오른쪽 위에 세리프 수식이 줄 단위로 쌓인다(3×2×1=6 → 26³=17,576 → …).
- **기본값 [I]**:
  - 항목은 해당 단어 첫 음절 **−2f**에 등장. 등장 12f(`DUR.normal`), y +16px→0, 불투명도.
  - 최소 간격 5f(`STAGGER.item`). 이전 항목은 불투명도 0.55로.
  - 한 화면 최대 5항목. 넘으면 페이지를 넘긴다(슬라이드 12f).

### R7.6 그래픽이 화면에 있을 때 자막 [O][S][I]
1. **위치·모양 고정**. 셜록은 풀 그래픽·지도·사이드 패널에서도 하단 중앙 박스를 유지한다 [O]. 자막이 움직이면 시선이 흔들린다.
2. 그래픽 요소는 자막 박스 상단 +24px 위(y ≤ 1080 − 64 − 68 − 24 ≈ **924px**)에서 끝나게 레이아웃한다. 겹칠 때는 **그래픽을 올린다**(자막은 그대로).
3. 키워드 카드·숫자 카드가 떠 있으면 자막 강조색을 끈다.
4. 풀스크린 인용·정의 카드가 **말과 같은 문장**을 보여 주면 그 구간 자막을 숨긴다(Mayer redundancy, d≈0.87 [S]).
5. 풀스크린 그래픽 안에 이미 문장형 텍스트가 2줄 넘게 있으면 자막 불투명도를 0.72→0.55로 낮춘다 [I].

## 9. BGM

### R9.1 장르 [V][S][I]
- 다큐 BGM은 피아노·하프·현·펄스·앰비언트, 가볍고 몽환적이다. 미니멀 다큐 언더스코어는 잔잔한 피아노 + 앰비언트 텍스처로 내성적이다. 주목받지 않는 것이 목적 [S depositphotos/envato 요약]. 다큐 권장은 현·피아노 중심의 절제된 곡 [V premiumbeat doc]. 탐사형은 낮은 럼블, 올라가는 현, 반복 피아노 음 [V legismusic].
- 한국 지식·교양 유튜브: 가사 없는 로파이, 잔잔한 피아노 [S].
- **기본값 [I]**:
  - 솔로 피아노·어쿠스틱 기타 + 가벼운 재즈 브러시(`style_guide.md`), 미니멀 앰비언트 일렉트로닉, 차분한 로파이. 가사 없음.
  - 템포: 설명 구간 **60~80 BPM**, 인트로·버스트 90~110 BPM. air.io도 차분한 구간 60~80 BPM, 에너지 구간 100~120 BPM을 제시한다 [V].

### R9.2 레벨 [V][S][I]
| 조건 | 대사 대비 음악 레벨 | 근거 |
|---|---|---|
| 차분한 설명 구간 (대사 위) | **−20 ~ −25 dB** | [V air.io] |
| 에너지·빌드 구간 | −8 ~ −12 dB | [V air.io] |
| 일반 권고 | 대사보다 18~25 dB 아래 | [S] |
| 대사 −14~−12 LUFS-S일 때 음악 | −24~−20 LUFS-S (6~10 LU 차이) | [S audioforgepro] |
| 대사와 함께 | −30~−35 dB (대사 −18~−9 dB) | [V epidemic] |
| 한국 편집 사례 | 대사 −8~−18 dB, BGM −30 dB, 효과음 −20~−30 dB | [S 한국어 검색요약, 원 출처 불명확] |
- **기본값 [I]**:
  - 대사 위: 음악 단기 라우드니스 = **대사 단기 라우드니스 −20 LU**(범위 −14~−25). 대사 −14 LUFS-S면 음악 ≈ **−34 LUFS-S**.
  - 대사가 없는 구간(아이덴트, 무내레이션 몽타주, 엔드카드): 음악 **−18 LUFS-S**(범위 −16~−22).
  - 콜드오픈 대사 위는 조금 더 앞으로: −16 LU.

### R9.4 인트로 스웰·아웃트로 [V][I]
- 음악 베드 페이드인·아웃 1초 [V openscreen].
- **기본값 [I]**:
  - 콜드오픈: 음악이 0초부터 대사 −16 LU.
  - 아이덴트: 음악 **+6 dB 스웰**(음악 전용 −18 LUFS-S) + sub drop. 아이덴트가 끝나면 12f 동안 대사 위 레벨로 내린다.
  - 아웃트로: 마지막 문장이 끝나면 음악이 −18 LUFS-S로 올라가고, 엔드카드 끝에서 **2.5초 페이드아웃**. 해결되는 화음 위치에서 끝나도록 곡을 자르면 더 좋다.

### R9.5 챕터별 트랙 교체와 침묵 [V][I]
- 새 챕터·장면·감정 전환에는 새 트랙이나 변주를 쓴다. 한 곡을 영상 내내 반복하지 않는다 [V air.io].
- 큰 폭로 직전에 음악을 잠깐 빼거나 완전히 끊으면 어떤 효과음보다 강하다 [V air.io]. 핵심 순간에 음악을 빼면 말에 집중하게 된다 [V legismusic].
- 킥·스네어에 하드컷을 맞추면 부드럽게 느껴진다 [V air.io].
- **기본값 [I]**:
  - 챕터마다 새 곡이나 변주(한 곡 연속 최대 6분). 챕터 카드에서 이전 곡 **1.0초 페이드아웃** → 카드 → 새 곡 0.5초 페이드인(또는 카드 위 riser → 새 곡 다운비트).
  - **침묵**: 핵심 명제·반전 문장 **0.8초 전**(범위 0.5~1.5)에 음악을 0으로 내리고(6f 페이드), 그 문장이 끝난 뒤 **1초 이상 지나서** 다시 올린다(1초 페이드인). 영상당 3~6회.
  - 결론 구간 마지막 20~40초: 음악을 빼거나 더 낮게(−26 LU) 한다.
  - 몽타주 버스트: 컷을 다운비트 **±1f**에 스냅한다.

- 위 체인과 R10.2 비디오 체인은 로컬 FFmpeg(libavfilter, Lavc60)에서 파싱·실행을 확인했다(`loudnorm`은 1패스 측정 모드로 시험).
- `loudnorm`은 **2패스**(1패스 측정 → 2패스 linear)로 돌린다. 음성만 먼저 −14로 맞추고, BGM·SFX를 섞은 뒤 최종 믹스를 다시 측정해 ±0.5 LU 안인지 확인한다.
- 긴 필터는 프로젝트 규칙대로 `FFmpeg.filter_script_args`로 넘긴다.

## 17. 남은 검증 과제
1. **실제 컷 타이밍**: 스토리보드는 5~10초 해상도다. 셜록 영상 1편을 쿠키 인증으로 받아 `ffmpeg -vf "select='gt(scene,0.3)',showinfo"`로 ASL과 앵글 전환 간격을 정밀 측정한다.
2. **BGM·SFX 실측**: 오디오를 받아 대사·음악 분리(Demucs) 후 LUFS-S 차이와 덕 깊이를 측정한다. 이 문서의 R8·R9 값은 대부분 일반 가이드 기반이다.
3. **자막 픽셀 크기**: 1080p 원본 프레임에서 셜록 자막 글자 높이·박스 불투명도를 다시 잰다. 지금 값은 320×180 썸네일 추정치다.
4. **A/B**: 펀치 밀도(분당 0.5·0.75·1.5), 음악 −16·−20·−24 LU, 박스 vs 그림자 자막을 AVD·APV로 비교한다.
