# 디자인 v5.1 — 1인 시사교양 토크쇼, 건축 저널의 재질로

채널 주인 2026-11-09: "시사교양인데 혼자 토크를 하는 쇼 느낌. 지금은 너무 AI slop 이다."
채널 주인 2026-11-09 저녁: "너무 플레인하다. 종이질감·메모지·노이즈·페이드·블러·그림자 등 다양한 효과, 각 요소를 디자인해서 템플릿으로, 그리고 이미지 위에 그래픽을 올리는 느낌."
이 문서가 v4 모던 모션을 대체한다. 근거 수치는 레퍼런스 채널 영상 시청 로그(2026-11-09, 프레임 측정이 아닌 추정)와 `docs/research/레퍼런스_영상_분석.md` 실측이다.

## 한 문장
한 사람이 자기 공간에서 근거를 들어 논증하고, 말이 가리키는 **실물 자료를 전면으로 끊어 넣고 그 위에 그래픽을 올린다.** 글자와 그래픽은 **미리 디자인한 템플릿**으로만 나오며, 재질은 건축 저널을 오려 붙인 책상이다.

## 왜 슬롭처럼 보였나 — 무엇을 피하나
v4: 복숭아빛 번짐, 흰 둥근 카드 + 부드러운 그림자, 알약 칩, 코너 라벨, 한글을 기울인 강조, 오렌지 면, 선 아이콘, 둥둥 떠다니기, 글자를 뭉개는 모니터 질감.
v5 초판: 그것을 다 빼서 플레인해졌다. **효과를 빼는 것이 답이 아니었다.** 슬롭의 원인은 효과가 아니라 ① 진짜 재질 없이 CSS 그라디언트로 흉내 낸 면 ② 내용과 상관없는 장식 ③ 영상마다 새로 짓는 일회용 레이아웃이다.
그래서: 재질은 실제 종이처럼 보여야 하고(섬유·구김·고르지 않은 톤·찢긴 단면), 종이 조각에는 늘 진짜 내용이 있으며, 요소는 한 번 잘 디자인한 템플릿을 쓴다. 가짜 UI(말풍선·칩·기기 목업)는 계속 금지.

## 화면 배분
| 종류 | 비율 |
|---|---|
| 얼굴 단독 | 25~30% |
| 얼굴 + 얹힌 글자·소형 자료 | 20~25% |
| 분할 | ≤3%(비교할 때만) |
| 전면 도식 | 10~15% |
| 전면 실물 자료(사진·영상·지도·문서) | 25~35%(이 중 절반 이상은 위에 그래픽이 얹힌다) |
| 전면 글자 카드 | ≤2% |

얼굴 노출 합계 50~60%(허용 40~85). **곡선이 있다:** 앞 6분은 자료 밀도 높게(얼굴 약 40%), 중반은 토크로 풀어 얼굴을 30~50초씩 맡긴다(약 80%). 자료 컷은 대개 2~5초, 도식 8~14초, 얼굴 없는 구간 최대 45초.

## 재질 키트
- **종이 다섯:** 양피지 캔버스(도식·챕터 바탕 — 그 위 흰 메모가 도드라지는 톤) · 흰 메모 · 크라프트 · 모눈/트레이싱 · 신문지 조각. 조명을 받은 높이맵으로 만든 실제 같은 텍스처(섬유·구김·톤 얼룩). 찢긴 가장자리에는 흰 섬유 단면이 보인다.
- **노이즈:** 디자인된 면과 사진에 깐다. 글자 **아래** 층이다(글자를 뭉개지 않는다). 화자 영상 위에는 깔지 않는다.
- **그림자:** 광원 하나(위 왼쪽). 종이는 접촉 그림자 + 넓은 부드러운 그림자 두 겹으로 들떠 보인다. 글자는 부드러운 낙하 그림자.
- **블러:** 깊이를 만드는 데 쓴다 — 인용·핵심어 뒤 사진을 흐리고 어둡게, 초점 창 밖을 흐리게, 요소 등장 시 흐림 → 선명.
- **페이드:** 요소 등장·퇴장에 쓴다(올라오며 페이드 + 블러, 8~10프레임). **글자 요소 둘이 동시에 겹쳐 페이드되지 않는다.**
- **테이프·핀·클립, 형광펜, 연필 선, 도장**은 실제 내용을 붙이거나 강조할 때만. 도장은 영상당 3개 이하.

## 토큰
- 색: 짙은 숲색 `#1F4D3E` · 민트 머리표 `#8FC7A8` · 에그셸 `#F4F3EE` · 양피지 `#EFE9DC` · 메모 `#FBF9F3` · 크라프트 `#B89B72` · 차콜 `#1E2124` · 잉크 `#22211E` · 채널 오렌지 `#FC5400`(테이프·표식·형광 밑줄·충격파, 넓은 면 채움 금지).
- 서체: Pretendard(라벨 600 · 본문 500 · 핵심어 800). 명조는 인용과 타이틀의 저널 제호에. 손글씨(나눔손글씨)는 메모지 위 짧은 글에만. **기울임 금지**(영문 원어 표기만 예외).
- 자막: 하단 중앙 1줄, 최대 24자, 4초 이내, 흰 Pretendard 500 40px, 검정 75% 상자, 반경 3px, 색 강조 없음. 강조는 콜아웃 몫(800, 최대 86px).

|---|---|---|---|
| 챕터 배지 | 좌상단 | 접힌 종이 탭, 숲색 + 12~18자 | 3초 |
| 오늘의 주제 | 우상단 | 흰 메모 + 주황 테이프, 살짝 기울임 | 3~4초 |

| 한 줄 정리 | 우상단 | 흰 메모 + 테이프(오늘의 주제와 같은 재질) | 3초 |
| 인용 | 중앙 | 흐리고 어두워진 자료/화자 위 명조 + 큰 따옴표, 원전 표기 | 4초 |

| 오림 스택 | 오른쪽 위에서 아래로 | 흰 테두리 + 그림자 오림 그림이 말에 맞춰 하나씩 | 대사 |

## 이미지 위 그래픽 층(`data.overlays`)
전면 사진·지도·문서·영상 위에 올린다. 종류: **outline**(대상의 벡터 윤곽 — 꼭짓점 8개 미만이면 circle 로, 나머지는 채도를 뺌) · **circle**(손으로 그린 원) · **arrow** · **label**(지시선 달린 종이 라벨 — 가리킬 곳을 모르면 메모로) · **memo**(사진에 테이프로 붙은 메모) · **cutout**(흰 테두리 오림 그림) · **impact**(주황 충격파) · **stamp** · **focus**(초점 창 밖을 흐리고 어둡게).
바탕 처리: `desaturate` · `darken` · `blur`. 좌표는 **그림을 본 비전 선택이 정한 정규화 좌표**만 쓴다(추측 금지) — 좌표가 없으면 memo·label 을 빈 쪽(`safe.side`)에 놓는다. 각 오버레이는 `at_word` 로 말에 착지한다. 한 화면 3개까지.

## 움직임
- 화자 ↔ 전면 자료는 **하드 컷이 기본.** 아이리스·다이브·흩어지기·와이프 금지. 예외: 타이틀 들고나는 **종이 찢기 전환**(영상당 1~2회), 사진끼리 드문 디졸브.
- 화자에게 슬로우 줌·글라이드 없음. 점프컷은 크롭을 바꾼 하드 컷(100 ↔ 112%). 사진·문서에는 약한 3% 푸시.
- 얹히는 요소는 옆으로 살짝 밀려오거나 올라오며 페이드 + 블러로 등장, 종이는 놓이듯(되튐 없음). 정착하면 멈춘다. 떠다니기 없음.
- 표시는 **말한 낱말에 착지**한다(`at_word`/`data-at-word`).

## 구조
콜드 오픈 20~30초(한두 생각) → 콜라주 아이덴트 2~4초 → 인사 한 줄 + 오늘의 주제 → 본론. 전면 챕터 카드는 큰 전환 2~4회, 그 사이 논증 배지(90~150초마다). 챕터 끝 자동 정리 보드 없음.

## 자료
일반 스톡보다 구체적 실물·아카이브·지도·문서가 먼저(일반 스톡은 증거 시간의 25% 이하). 자유 카드는 **실물이 보여 줄 수 없는 메커니즘**에만, 15분에 3~6곳, 시그니처 1~3곳.

## 소리
효과음은 그래픽 착지에 맞춘다. 자동은 템플릿 등장만, 분당 4개 이하. 종이 템플릿은 종이 소리. 게인은 실제로 들리게.

## 하지 않는 것
글자 위 입자·글로우 · 카라오케 자막 · 두 줄 큰 자막 · 전면 타이포를 개념마다 짓기 · 가짜 UI · 출처 없는 그림 · 내용 없는 장식 조각 · 되튐.
