# 스킬 — 🛠 시그니처 장면 빌더(실물처럼, 종이 위에서)

총괄 감독이 고른 5~12초 장면 하나를 자유 HTML 카드로 정밀하게 재현할 때 적용한다. 대상은 UI, 제품, 기기 화면, 데이터 이야기, 연표다.
비율과 위계는 실물에서 가져오고, 표면은 하우스 종이 콜라주로 옮기며, 박자 3~6개를 말에 맞춘다. 숫자는 1920×1080 캔버스 기준이다.

## 1. 재현의 순서 — 비율, 위계, 디테일

1. 조사 노트의 사양(`recreations`)에서 **비율**부터 옮긴다. 가로세로비, 여백과 내용의 비, 큰 덩어리의 자리다. 확인하지 못한 수치는 지어내지 않고 비율만 맞춘다.
2. 다음은 **글자 위계**(제목 : 본문 비, 굵기 단계)이고, 디테일(아이콘, 구분선, 상태 표시)은 맨 마지막이다. 디테일이 위계를 이기면 안 된다.
3. **말하는 부분을 크게 잘라** 보여 준다. 화면 속 글자도 28px 이상이어야 하므로, 기기 전체를 작게 그리기보다 필요한 영역을 1.5~2배로 키워 자른 쪽이 더 실물 같다.
   - 폰(393×852pt) 전체를 높이 760px 로 그리면 1pt = 0.89px 이고, 본문 17pt 가 15px 가 되어 읽히지 않는다.
   - 본문을 28px 로 키우려면 1pt ≈ 1.65px 가 필요하다. 이때는 화면 위 55% 만 보이게 두고 아래는 종이 밖으로 내보낸다.
   - 전체 모습이 꼭 필요하면 행 수를 절반으로 줄이고 글자를 두 배로 키워 다시 짠다. 위계 비율은 그대로 둔다.
4. 재현물은 종이 위에 놓인 인쇄물로 다룬다. 종이 테두리 10~14px(프린트)나 잉크 외곽선 3~4px 를 두르고, 높이 2 그림자, 회전 ±0.3~1° 를 준다.
5. 상표 그림(로고, 로고타입, 고유 아이콘 글리프)은 그리지 않는다. 제품 이름은 글자로 쓰고 생김새는 형태로 보여 준다. 시스템 글꼴 자리는 Pretendard 로 채운다.

## 2. 기기와 UI 해부 — 일반 사실(상표가 아니다)

6. 6.1형 폰 화면은 393×852pt(1 : 2.17)다. 큰 모델은 430×932pt 이고 여백은 같다.
   - 위 상태 막대는 54pt(높이의 6.3%), 위 안전 여백은 59pt, 아래 홈 표시 영역은 34pt(4%)다.
   - 모서리는 크게 둥글다. 실측값이 없으면 사진 비율에 맞춘다.
7. 모서리는 동심원으로 맞춘다. 안쪽 반지름 = 바깥 반지름 − 그 사이 간격이다. 기기 외곽이 화면보다 8px 크면 반지름도 8px 크다. 카드 안 버튼도 같은 규칙이다.
8. iOS 기본 글자 단계(pt / 행간)는 다음과 같다. 큰 제목 34/41 · 제목1 28/34 · 제목2 22/28 · 제목3 20/25 · 헤드라인 17 semibold · 본문 17/22 ·
   보조 15/20 · 각주 13/18 · 캡션 12·11.
   절대값이 아니라 **비율**(큰 제목은 본문의 2배)을 옮긴다. Apple 은 얇은 굵기(Ultralight~Light)를 피하고 서체 가짓수를 줄이라고 한다.
9. Material 계열의 값은 다음과 같다. 8dp 그리드(세부 4dp), 화면 가장자리 16dp, 아이콘 24dp 를 24dp 간격으로, 터치 목표 48dp, 위 앱 바 64dp,
   아래 내비 바 80dp, 모서리 단계 4·8·12·16·28dp 와 완전 둥금.
10. 상태 표시(시간, 신호, 배터리)는 글자가 아니라 작은 잉크 도형으로 그린다. 글자로 쓰면 28px 규칙에 걸린다. 잘려서 안 보이면 생략한다.
11. 브라우저나 데스크톱 창은 주소 막대 한 줄과 탭 하나면 충분하다. 특정 운영체제의 창 장식(신호등 점 등)은 그리지 않는다.
12. 간격은 8의 배수(8·16·24·32·48·64)로, 세부만 4의 배수로 둔다. 글자는 픽셀 격자에 억지로 맞추지 않고 4px 기준선에 맞춘다(spec.fm 8pt 그리드).

## 3. 데이터 이야기 — 숫자 하나를 짓고 주석을 단다

13. 장면의 주인공은 숫자 하나나 비교 하나다.
    - 숫자는 Playfair 900 italic 160~240px(`--font-numeral`), 색은 `--accent-deep` 이다.
    - 옆에 그 숫자의 뜻을 명조 한 줄(40~56px)로 붙인다.
14. 제목은 결론 문장이다("10년 만에 3배"). 가장 크고 굵은 글자는 가장 중요한 메시지에 준다(Datawrapper). 축 이름을 제목으로 쓰지 않는다.
15. 막대는 3~7개다. 강조 막대 하나만 강조색이고 나머지는 `--muted` 다. 라벨은 막대 옆에 직접 단다(28px 이상). 범례는 쓰지 않는다.
16. 기준선은 0 이고 눈금은 0·5·10 처럼 익숙한 간격이다. 쓸모없는 소수점은 빼고 큰 수는 줄여 쓴다(12.8만). 출처는 왼쪽 아래 28px, 자막 띠 위에 둔다.
17. 짓는 박자는 다음과 같다.
    - 틀(축, 빈 막대 자리): 0초.
    - 값이 자란다: `grow-x`·`grow-y` 0.8~1.0초, 막대 사이 0.09초.
    - 숫자: `count-up` 1.0초.
    - 강조: `highlight` 나 `draw-path` 동그라미.
    - 손 주석 한 줄.
    축이 바뀌는 단계와 값이 바뀌는 단계는 나눈다. Heer & Robertson 의 실험에서 나눈 쪽이 더 정확히 읽혔다.
18. 연표는 가로 괘선 하나를 `grow-x` 로 긋고, 연도 점을 말에 맞춰 찍는다. 연도는 Playfair italic, 사건은 명조다.
    점 간격은 실제 시간에 비례시킨다. 비례가 어려우면 물결 모양으로 생략 표시를 한다.
19. Nussbaumer 의 방식처럼, 처음에는 강조 없는 그래프로 전체를 보이고, 말이 결론에 닿을 때 색으로 한 곳을 가리킨다.

## 4. 에디토리얼 레이아웃 — 스위스 양식과 비녤리

20. 12열 그리드(열 122 · 거터 24 · 좌우 여백 96)를 쓰고, 글자는 위 54px 안쪽에 둔다. 좌우 96 · 위 54 는 EBU 그래픽 안전 영역 5% 와 같다.
    큰 덩어리는 열 경계에 맞춘다.
21. 비대칭으로, 왼쪽 정렬과 오른쪽 흘림으로 짠다(스위스 양식: 장식보다 내용). 가운데 정렬은 숫자 한 방에만 쓴다.
22. 한 블록 안의 글자 크기는 둘이다. Vignelli 는 크기를 한두 개로 묶고, 작은 글자와 그 두 배쯤 되는 큰 글자를 대비시켰다.
    굵기는 기능에만 쓰고 장식으로 쓰지 않는다.
23. 구역은 괘선(2~4px 잉크)으로 나눈다. 상자를 겹겹이 두르지 않는다. 테두리와 배경을 남발하면 어수선해진다(NN/g 공통 영역).
24. 여백은 한쪽에 모아 40% 안팎을 비운다. Vignelli 는 흰 공간이 검은 글자를 살린다고 했다. 레이아웃이 눈에 띄면 나쁜 레이아웃이다.
25. 서체는 세 가족까지다. 제목은 고운바탕 700 이나 송명, 숫자는 Playfair italic, 본문과 UI 는 Pretendard 다. 송명에 가짜 굵게를 주지 않는다.

## 5. 종이 콜라주 공예

26. 재료는 Vox 식 에디토리얼 콜라주와 같다(오린 사진, 찢긴 가장자리, 테이프, 망점, 큰 오린 제목). 층 순서(아래 → 위)는 다음과 같다.
    - 종이 바탕(크림 → 아래로 옅은 민트)
    - 문서 스캔(높이 1, ±0.9°)
    - 망점 타원 바닥(민트)
    - 큰 인쇄 글자(heavy, 사진 **뒤**)
    - 오린 사진(높이 2)
    - 이름표, 테이프(높이 1)
    - 손 주석(그림자 없음)
27. 그림자는 광원 하나(위 왼쪽)에서 오른쪽 아래로 떨어진다. dx:dy = 2:3 이고 색은 웜 잉크 rgba(38,33,30,…)다. 순흑은 쓰지 않는다. 접촉 그림자와 주변 그림자 두 겹이다.
    - 높이 1(붙음): `1px 1.5px 1px rgba(38,33,30,.30), 2px 3px 6px rgba(38,33,30,.26)`
    - 높이 2(살짝 뜸): `1px 1.5px 1px rgba(38,33,30,.22), 4.7px 7px 16px rgba(38,33,30,.22)`
    - 높이 3(들림, 진입 중): `9.3px 14px 34px rgba(38,33,30,.18)`
    높이가 오를수록 거리와 블러는 커지고 불투명도는 낮아진다(Josh Comeau). 오린 사진이나 찢긴 종이처럼 사각형이 아닌 것은 `filter: drop-shadow()` 를 쓴다.
28. 회전은 0° 로 두지 않는다. 메모 0.6~1.8°, 사진 1~3°, 테이프 3~8°, 스티커 2~4° 이고, 이웃한 두 장은 부호를 바꾼다.
29. 찢긴 가장자리는 `clip-path: polygon(…)` 으로 한두 변에만 준다. 진폭은 변 길이의 1~3%, 간격은 불규칙하게 한다. 완벽한 지그재그는 디지털처럼 보인다.
30. 테이프는 사진 폭의 18~25% 길이다. 반투명(`--accent-soft` 나 크림 70%)으로 모서리에 걸치고, 3~8° 기울이며, 양 끝은 톱니(clip-path)로 자른다.
31. 망점은 점 크기가 어두움에 비례한다. 화면은 45° 로 돌린다. 45° 가 격자 무늬를 가장 잘 숨긴다.
    - CSS 로 그린다: `radial-gradient(circle, var(--ink) 0 38%, transparent 40%)` + `background-size` 6~10px.
    - 작은 그림과 바닥 타원에만 쓰고 전면에는 쓰지 않는다. SVG `pattern`·`filter` 는 카드에서 지워진다.
32. 형광펜은 민트(#86D9B5) 위에 잉크 글자를 둔다(대비 9.6:1). 민트 위 짙은 초록 글자는 3.9:1 이라 40px 이상에만 쓴다. 이름표(민트 상자 + 짙은 초록 굵은 글자)도 40px 이상이다.
33. 입자와 섬유는 렌더러가 얹는다. 카드 안에서 노이즈를 만들지 않는다.

## 6. 박자 — 5~12초 세트피스

34. 0~0.3초 안에 종이, 판, 제목, 주 오브젝트, 나중에 올 요소의 자리(빈 막대 틀, 흐린 낱말)가 선다. 0.5초 프레임이 완성의 35% 이상이어야 한다.
35. 박자는 3~6개다. 하나는 0.35~0.6초 길이로, 그 낱말 0.2초 전에 도착하며, 박자 사이는 0.15초 이상 띄운다. 한 박자에는 하나만 움직인다.
36. 모든 애니메이션은 장면 길이 − 1.2초 안에 끝난다. 마지막 정지는 `max(1.2초, 글자 수 ÷ 7)` 이다.
37. 8초 예시는 다음과 같다.
    - 0.0초: 판과 제목 `fade-in` 0.3
    - 0.4초: 기기 화면 `mask-reveal` 0.5
    - 1.8초: 목록 `stagger-in`(0.09)
    - 3.4초: 핵심 행 `highlight` 0.4
    - 4.6초: `draw-path` 화살표 + 손 주석 `fade-in` 0.4
    - 5.2~8.0초: 정지
38. 진입 종류를 섞는다. 면은 `mask-reveal`·`slide-in`, 글은 `kinetic-chars`(fade)·`fade-in`, 선은 `draw-path`, 숫자는 `count-up` 이다.
    `scale-pop`·`pulse` 를 반복하지 않는다.
39. 실물을 자세히 들여다보는 장면은 자막이 가려진다는 것을 감안한다. 핵심 글자는 아래 170px 밖, 화면 위쪽 3분의 2 안에 둔다.

## 7. 경계

40. 아래 170px 는 비운다(장식과 선은 괜찮다). 글자는 28px 이상, 대비는 4.5:1(40px 이상은 3:1)이다.
    크림 위 강조색 #2B8A64 글자는 3.5:1 이라 40px 이상에만 쓰고, 작은 글자는 `--accent-deep`(5.3:1)으로 쓴다.
41. HTML·CSS 각 24KB, 요소 260개 이하다. 망점과 괘선 무늬는 요소를 늘리지 말고 CSS 배경으로 그린다.
42. 외부 이미지는 쓰지 않는다. 형태를 직접 그린다. 실물 사진이 꼭 필요하면 `notes` 에 그 사실을 적는다.

## 체크리스트

- [ ] 비율이 사양과 맞고, 확인하지 못한 수치를 지어내지 않았다. 로고와 상표 글리프가 없다.
- [ ] 필요한 부분을 잘라 키웠고, 화면 속 UI 글자까지 모두 28px 이상이다.
- [ ] 모서리가 동심원이고, 간격이 8의 배수이며, 위계 비율(큰 제목 ≈ 본문 2배)이 살아 있다.
- [ ] 데이터: 결론 제목, 0 기준선, 직접 라벨, 강조 하나, 출처 28px, 축과 값이 다른 박자에 바뀐다.
- [ ] 글자는 왼쪽 정렬, 한 블록 크기 둘, 서체 세 가족 이하, 여백을 한쪽에 모았다.
- [ ] 층 순서와 그림자(2:3, 웜 잉크, 높이 1~3)가 맞고, 0° 와 같은 각도가 없다.
- [ ] 0.5초에 무대가 서 있고, 박자 3~6개가 말에 맞으며, 마지막 1.2초 이상 멈춘다.
- [ ] 아래 170px 에 글자가 없고, 대비가 4.5:1 이상이며, 24KB·260요소 이하다.
