# 작업: 숏폼(9:16) {{count}}편 기획

위 전사본에서 숏폼으로 만들 구간을 **{{count}}편** 고르세요. 숏폼 후킹 가이드와 플레이북 2장(숏폼 공식)을 따릅니다.
- {{count}}편은 **서로 다른 훅 원형**을 쓰고 원본에서 60초 이상 떨어진 구간에서 고른다. 첫 편은 통찰형(A, 자체 완결), 둘째 편은 티저형(B, 롱폼의 질문을 열어 둠).
- 구간 점수가 7/10 에 못 미치면 억지로 채우지 말고 적게 낸다(부족분은 프로그램이 규칙으로 보충한다).

- 대본에 `[숏폼 ...]` 태그로 표시된 범위가 있으면 그 범위를 우선 후보로 쓴다.
- 편마다 길이는 **35–50초(최대 {{max_sec}}초)** — 발화 길이(s)의 합으로 계산.
- `segments`: 재생 순서대로의 발화 ID 목록. 연속 구간이 기본이지만, 불필요한 발화는 빼고 떨어진 발화를 이어 붙여도 된다(의미를 바꾸지 않는 선에서).
- `cold_open_seg`: 맨 앞에 가져올 가장 강한 문장의 발화 ID(없으면 -1). 이 ID 는 segments 에도 한 번만 들어간다.
- `hook_type`: 카탈로그 id.
- `hook_title`: 화면 상단에 처음부터 끝까지 고정될 훅 타이틀.
  - 줄바꿈은 `\n`, 2줄, 줄당 8–12자.
  - 셜록현준식으로 2줄째가 강조색으로 칠해지므로 2줄째에 핵심을 둔다.
  - 말한 문장을 그대로 쓰지 말고 핵심 명사를 공유해 새로 쓴다.
- `hook_highlight`: 강조어 1개. 2줄째 전체를 칠하려면 빈 문자열로 둔다.
- `graphics`: 상단 패널에 띄울 도식/사진 0–3개(발화 ID 기준, layout 은 무시되고 상단 패널로 렌더링).
- `emphasis`: 자막 강조어 3–6개(`seg`+`word`).
- `loop_line`: 루프가 자연스러우면 끝 문장이 첫 문장을 어떻게 부르는지 한 줄 설명, 아니면 빈 문자열.
- `why`: 선택 이유 + 약속-해소 검사(훅의 약속이 해소되는 발화 ID).
- `score`: 1–10.
- `title`: 파일 이름용 짧은 제목. `caption`/`hashtags`/`cta`: 업로드용.
