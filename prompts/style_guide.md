# 채널 스타일 가이드 — 디자인 이론 교육 채널의 롱폼·숏폼

## 1. 톤: 설명 구조 (docs/research/레퍼런스_채널_편집스타일_리서치.md)

- 논증 흐름: **일상 관찰·통념 → 질문 → 사례·역사·원리 → 개념 명명(비유) → 일상·한국으로 복귀.** 편집은 이 흐름의 전환점을 드러낸다.
  - 사례·원리 구간 = 그래픽(도식·사진·스톡 영상)이 가장 많이 나오는 구간
  - 개념 명명 순간 = `keyword` 한 장(영상 전체의 앵커)
  - 일상 복귀 구간 = 그래픽을 거두고 화자의 얼굴에 집중
- 대화하듯 말하는 1인 토크. 과장 효과음, 밈, 이모지, 초고속 컷은 쓰지 않는다.
- 인트로는 40초 이내: 첫 문장부터 오늘의 질문. 인사·자기소개로 시작하지 않는다(화자가 그렇게 말했다면 그 뒤의 질문 문장을 `hook_segs` 로 지정).
- 챕터는 **3.5~5분 간격**, 챕터 제목은 대상·사례 명사구("바우하우스 교실", "뮐러-브로크만의 그리드"). 첫 챕터(인트로)는 0초.

## 2. 디자인 v4 — 모던 모션 언어 (채널 주인 2026-10-02 레퍼런스: 테크 설명 영상의 모션 디자인)

**무대 둘**: 밝은 무대(흰 #F7F8F6 + 아래쪽에 옅은 디자인 색 번짐)가 기본, 어두운 무대(차콜 #121214)는 한 방·반전·숫자에만(챕터당 1회 안팎).
**색 하나**: 디자인 색은 채널 오렌지 `#FC5400`(흰 바탕 글자용 짙은 톤 `#D94600`, 칩·행·형광용 옅은 톤 `#FFD7C4`). 한 화면에 강조색 자리는 한 곳.
**글자**: 거의 모두 Pretendard — 헤드라인 800(자간 −0.035em, 행간 1.06), 본문 500, 라벨 600 대문자 자간 0.14em. **한 어절만** 이탤릭 세리프 강조(`*어절*` 표기 — 영문은 Instrument Serif, 한글은 명조 기울임). 명조 본문·손글씨·블랙한산스는 쓰지 않는다.
**부품**(모션 디자이너·시그니처 빌더가 쓰는 말):
- 키네틱 헤드라인 — 어절마다 아래에서 올라오며 등장, 짧은 문장은 둘레에 흐린 메아리, 제목 둘레 네모 넷(코너 마크)
- UI 패널 — 흰 둥근 카드(반경 28·부드러운 그림자) + 제목 줄 + 둥근 행(아이콘 · 라벨 · 값), 살짝 기울인 3D 틸트 가능
- 칩 — '✓ 라벨' 알약(흰/옅은 색/디자인 색 채움) · 말풍선 — 값 + 작은 설명 + 꼬리
- 기기 목업 — 모니터·노트북·폰 틀 안에 화면(UI 재현·지도·그래프)
- 아이소메트릭 블록 — 흰 블록 도시 + 옅은 색 길(지도·장소·흐름의 배경)
- 큰 숫자 — Pretendard 900, 구두점만 디자인 색('02:47'), 단위는 작게 옆에
- 영상 위 글자 — 가는 머리말 + 굵은 본문(왼쪽 아래 어둠), 또는 가운데 어둡게 누른 영상 위 한 문장
- 오린 사진 장면 — 밝은 무대 가운데 오린 사물(바닥 그림자) + 칩 + 왼쪽 헤드라인
- 모서리 작은 라벨 — 챕터 이름·브랜드(16px, 대문자 자간) — 내부 이름·검색어는 절대 금지
**움직임**: 등장은 아래→위 마스크(14f), 칩·말풍선은 정착 곡선(살짝 넘쳤다 자리 잡음), 패널은 큰 면 곡선(16f), 둘째 샷부터는 컷. 0.5초 안에 판과 제목이 보인다.

## 3. 화면 구성 원칙 — 얼굴보다 시청각 자료가 먼저

- **얼굴은 늘 나올 필요가 없다**(채널 주인). 어떤 장면은 스톡 영상·사진이 화면을 꽉 채우고, 어떤 장면은 모션 그래픽만 가득해도 된다.
  얼굴은 훅·반전·의견·결론·감정·경험담에서 보인다(그때는 얼굴을 가리지 않는다 — 홀드).
- **개념 설명의 기본 화면은 모션 그래픽만의 장면**(모션 장면·자유 카드 `fullscreen`): 얼굴 없이 화면 전체가 모션의 무대. 같은 개념의
  장면 2~3개를 이어도 된다. 얼굴 없는 구간은 최대 90초.
- **말한 것은 보여 준다**: 대상·사례·장소·과정·수치·출처가 나오면 스톡 영상(과정·현장은 영상이 사진보다 먼저)·사진·문서·UI 재현을
  **전면**으로. 지나가는 언급은 `pip`(얼굴 옆 흰 카드), 챕터마다 한 번은 증거를 전면(풀블리드 또는 55% 이상)으로.
- `split`: 화자의 표정이 설명과 함께 필요한 짧은 순간 — 화자는 둥근 카드 1/3, 반대쪽은 흰 UI 패널(도식·목록·정의).
- `overlay`: 화자 위에 얹는 짧은 키워드/숫자(2~4초). `pip`: 화자 그대로 + 반대편 위 흰 카드(사진·개념).
- **고유명사**(제품·건축·디자이너·브랜드·작품)가 처음 나오면 1초 안에 실제 사진. 두 번째부터는 생략. 인물 사진은 얼굴이 잘리지 않게(앱이 얼굴 위치로 구도를 잡는다).
- 비교 대사는 `compare`, 단계 설명은 `process`/`double_diamond`, 반복 과정은 `cycle`, 위계는 `pyramid`, 두 축 분류는 `matrix`, 역사 흐름은 `timeline`, 처음 나오는 용어는 `definition`.
- 도식은 설명이 진행되는 동안 유지하고 `highlight` 로 지금 말하는 단계를 가리킨다(같은 도식 위의 변화처럼).

## 4. 밀도와 리듬

- 채널 운영자 피드백(2026-09-30 · 10-02): "그래픽이 너무 없다 — 모션 그래픽과 스톡 이미지·영상을 최대한 많이, 엄청 풍부하게."
  교육 영상은 **말하는 내용이 화면에 보여야** 이해가 된다.
- 배분표(본편 시간 기준): 얼굴만 **≤20%**(10–30) · 실물 자료(스톡 영상·사진·오린 장면·문서·UI 재현) **≥45%** · 모션 장면·카드·도식 **≥30%**.
  풀스크린 합계 90% 까지. 맨얼굴(아무 그래픽 없이 얼굴만)은 한 번에 25초 이하. 스톡은 영상당 12~20개.
- 그래픽은 문장이 대상·사례·출처·과정·수치를 말할 때 넣는다. 간격을 고르게 맞추지 않는다 — 사례가 몰리는 곳은 시퀀스로 촘촘하게(장당 1.2~2.5초), 고백·결론은 얼굴로 길게(6~25초).
- 같은 템플릿을 연속으로 세 번 쓰지 않는다(도식 highlight 이어 붙이기는 예외). 첫 1.5초와 마지막 5초에는 그래픽을 두지 않는다.
- 강조(`emphasis`): `punch` 는 논점이 바뀌는 문장, 결론 문장, 반전 문장에만(1분에 1~2회). `highlight` 는 자막 속 핵심 용어 한 단어(한 문장에 하나).
- **Keep it human**: 화자의 표정과 호흡이 좋은 순간(웃음, 확신에 찬 결론)은 그래픽으로 가리지 않는다.

## 5. 사운드 방향

- BGM 은 인트로와 챕터 전환에서만 또렷하게, 본문은 목소리 아래 -20dB 이하 언더스코어. 가사 없는 곡. 곡은 내 음악 폴더에서 🎼 음악 감독이 고른다.
- 솔로 악기(피아노·첼로·기타 한 대)의 미니멀한 스코어가 "손으로 만든 듯한, 인간적인" 인상을 준다. 디자인 이론 채널에는 **솔로 피아노/어쿠스틱 기타 + 가벼운 재즈 브러시** 톤을 기본 추천.
- 효과음은 모션 그래픽에서 흔한 것만(whoosh_soft · swoosh_short · swipe · pop · click · typing · camera_shutter · paper · ding · bell_soft · notification), 총괄 감독이 고른 자리에만.
- `music.mood` 에 이 영상에 맞는 무드와 템포(BPM)를, `music.notes` 에 챕터별 음악 운용(어디서 음악을 빼고 어디서 다시 올릴지)을 적는다.

## 6. 유튜브 메타데이터 (레퍼런스 채널 제목 데이터 기반)

- 제목: **18~30자 한 문장, 구분자(`|`, `/`) 없이, 고유명사 1개 이상.** 우선 패턴: ①`~인 (진짜) 이유` ②`A와 B의 결정적인 차이` ③`~할 수 있을까? / ~한다면?` ④`디자이너의 눈으로 본 X` ⑤`~라고 생각했던 X의 반전?` ⑥`X보다 '이것'`. **"왜 ~할까"는 기본값으로 쓰지 않는다.** 5개 제안.
- 설명란: 첫 줄 해시태그 2~4개, 둘째 줄 한 줄 요약, 빈 줄, 그다음 `{{CHAPTERS}}` 라는 자리표시자 한 줄(프로그램이 실제 타임코드로 바꾼다), 마지막에 참고 도서/출처(화자가 언급한 것만).
- 썸네일 문구: 6~12자, 3개 제안. 제목과 겹치지 않게 호기심을 여는 짧은 말.
- 고정 댓글: 시청자에게 던지는 질문 하나(자기 경험을 묻는 형태).
