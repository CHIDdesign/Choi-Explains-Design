# 영상 형식 — 1인 시사교양 토크, 건축 저널의 재질로

**이 문서가 형식 수치의 유일한 원본이다. 다른 프롬프트·플레이북·스킬 노트와 부딪히면 이 문서가 이긴다.**
한 사람이 자기 공간에서 근거를 들어 논증하고, 말이 가리키는 실물 자료를 전면으로 끊어 넣고 **그 위에 그래픽을 올린다.** 글자와 그래픽은 미리 디자인한 템플릿으로만 나오고, 재질은 건축 저널을 오려 붙인 책상이다. 슬롭의 원인은 효과가 아니라 진짜 재질 없는 면, 내용과 상관없는 장식, 영상마다 새로 짓는 일회용 레이아웃이다.

## 화면 배분(본편 시간)
| 종류 | 비율 |
|---|---|
| 얼굴 단독 | 25~30% |
| 얼굴 + 얹힌 글자·소형 자료 | 20~25% |
| 분할(비교할 때만) | ≤3% |
| 전면 도식 | 10~15% |
| 전면 실물 자료(사진·영상·지도·문서) | 25~35%(이 중 절반 이상은 위에 그래픽이 얹힌다) |
| 전면 글자 카드 | ≤2% |

얼굴 노출 합계 50~60%(허용 40~85). 이 표와 아래 길이는 레퍼런스 시청 추정이다 — 문장이 요구하면 어겨도 된다(앱은 경고만 한다).
**곡선**: 앞 6분은 자료 밀도 높게(얼굴 약 40%), 중반은 토크로 풀어 얼굴에 30~50초씩 맡긴다(약 80%). 영상 끝까지 같은 밀도를 쓰지 않는다.
**길이**: 자료 컷 대개 2~5초 · 도식 8~14초 · 얼굴 없는 구간 최대 45초.

## 구조
콜드 오픈 20~30초(한두 생각) → 콜라주 아이덴트 2~4초 → 인사 한 줄 + 오늘의 주제 → 본론.
전면 챕터 카드는 큰 전환에만 영상당 2~4회, 2.2~3초, 목차 없음. 그 사이는 논증 배지(90~150초마다). 챕터 끝 정리 보드는 없다.

## 재질 키트
- **종이 다섯**: 양피지 캔버스(도식·챕터 바탕 — 그 위 흰 메모가 도드라지는 톤) · 흰 메모 · 크라프트 · 모눈/트레이싱 · 신문지. 책상은 어두운 바탕. 섬유·구김·톤 얼룩이 있는 실제 텍스처이고, 찢긴 가장자리에는 흰 섬유 단면이 보인다.
- **노이즈**: 디자인된 면과 사진에 깐다. 언제나 글자 아래 층. 화자 영상 위에는 깔지 않는다.
- **그림자**: 광원 하나(위 왼쪽). 종이는 접촉 + 넓은 부드러운 그림자 두 겹으로 들뜬다.
- **블러**: 깊이를 만든다 — 인용·핵심어 뒤 사진을 흐리고 어둡게, 초점 창 밖을 흐리게, 요소 등장 때 흐림 → 선명. 정착한 글자는 언제나 선명하다.
- **페이드**: 요소 등장·퇴장에 쓴다(올라오며 페이드 + 블러, 8~10프레임). 글자 요소 둘이 동시에 겹쳐 페이드되지 않는다.
- **테이프·핀·형광펜·연필 선·도장**은 진짜 내용을 붙이거나 강조할 때만. 도장은 영상당 3개 이하. 내용 없는 장식 조각은 만들지 않는다.
- **글자**: Pretendard(라벨 600 · 본문 500 · 핵심어 800). 명조는 인용과 타이틀 제호에. 손글씨는 메모지 위 짧은 글에만. 기울임은 영문 원어 표기만.

## 요소 템플릿 — 고정 위치, 얼굴·자막을 피한다, 영상마다 새로 짓지 않는다
| 템플릿 | 자리 | 모양 | 유지 |
|---|---|---|---|
| 챕터 배지 | 좌상단 | 접힌 종이 탭, 숲색 + 12~18자 | 3초 |
| 오늘의 주제 | 우상단 | 흰 메모 + 주황 테이프, 살짝 기울임 | 3~4초 |
| 용어 정의 | 좌하단 | 숲색 머리표 + 불투명 차콜 본문 상자 | 3초 |
| 핵심어 | 중앙 | 흰 고딕 800, 프레임 높이 약 8%, 부드러운 그림자 | 2~3초 |
| 한 줄 정리 | 우상단 | 흰 메모 + 테이프(오늘의 주제와 같은 재질) | 3초 |
| 인용 | 중앙 | 흐리고 어두워진 자료/화자 위 명조 + 큰 따옴표, 원전 표기 | 4초 |
| 숫자 태그 | 말과 동기 | 인덱스 카드, 비교 대상과 함께 | 대사 동안 |
| 인물·기관 슈퍼 | 좌하단 | 왼쪽 세로선 + 이름 + 소속 | 4초 |
| 오림 스택 | 오른쪽 위에서 아래로 | 흰 테두리 + 그림자 오림 그림이 말에 맞춰 하나씩 | 대사 동안 |
| 도장 | 자료 위 대각선 | 잉크 번진 도장 | 2초 |
| 출처 | 우하단 작게 | 자료 위에 항상 `출처: 기관` | 자료 내내 |
| 타이틀·아이덴트 | 전면 | 신문·도면 조각의 스톱모션 콜라주 2~4초 | |
| 챕터 카드 | 전면 | 종이 위 콜라주 + 큰 제목, 2.2~3초 | |
| 콜라주 | 전면 | 흑백 망점으로 오린 실제 사람·건물 덩어리 + 평면색 원(민트·오렌지) + 신문·모눈 조각 + 찢긴 종이 이름표. 역사 속 인물·건물을 호명할 때, 영상당 3~5곳(타이틀 별도) | 3~6초 |
| 핵심어 몽타주 | 전면 | 가운데 고정된 큰 흰 고딕 낱말 뒤로 사진 3~5장이 0.7~1.5초마다 하드 컷, 그 사례를 말한 낱말에 착지 | 3~6초 |
| 도식 보드 | 전면 | 양피지 위 연필 선·해치 | 8~14초 |
| 문서 | 전면 | 구김 있는 인쇄물이 책상 위에, 형광펜이 말에 맞춰 | |

## 이미지 위 그래픽 층
전면 사진·지도·문서·영상 위에 올린다. 종류: outline(대상의 윤곽, 나머지는 채도를 뺌) · circle(손으로 그린 원) · arrow · label(지시선 달린 종이 라벨) · memo(테이프로 붙은 메모) · cutout(흰 테두리 오림 그림) · impact(주황 충격파) · stamp · focus(초점 창 밖을 흐리고 어둡게). 바탕 처리: desaturate · darken · blur.
치수선(dimension): 대상의 두 끝을 잇는 가는 선 + 끝 틱 + 세어 올라가는 수치 — 화자가 말한 실제 숫자에만.
조각 전환(expand): 전면 자료·도식이 다른 전면과 맞붙을 때 드물게, 조각이 펼쳐져 다음 화면이 된다. 영상당 2회까지, 화자 ↔ 자료는 언제나 하드 컷.
좌표는 그림을 본 쪽이 정한 정규화 좌표만 쓴다(추측 금지) — 없으면 memo·label 을 그림의 빈 쪽에 놓는다. 표시마다 말에 착지하고, 한 화면 3개까지(글이 달린 circle·arrow·outline 은 표찰까지 둘로 센다).

## 자유 카드(HTML)
실물이 보여 줄 수 없는 메커니즘(단면·자금 흐름·변화 과정 등)에만 쓴다. 15분에 3~6곳, 그중 시그니처 장면 1~3곳. 실물 자료가 있는 문장은 그 자료를 쓰고, 카드를 지을 때는 그 이유를 `why_not_evidence` 에 적는다.

## 자료
구체적 실물·아카이브·지도·문서가 먼저다. 일반 스톡은 증거 시간의 25% 이하. 각진 풀블리드로 끊어 넣고, 화질·비율이 제각각인 것을 숨기지 않는다.

## 움직임
화자 ↔ 전면 자료는 하드 컷이 기본이다(목소리는 이어져 L컷이 된다). 아이리스·다이브·흩어지기·와이프 금지. 예외는 타이틀 들고나는 종이 찢기 전환(영상당 1~2회)과 사진끼리의 드문 디졸브.
화자에게 슬로우 줌·글라이드를 쓰지 않는다. 점프컷은 크롭을 바꾼 하드 컷(100 ↔ 112%). 사진·문서에는 약한 3% 푸시만.
얹히는 요소는 올라오거나 옆으로 살짝 밀려오며 페이드 + 블러로 등장하고, 종이는 놓이듯(되튐 없음). 정착하면 멈춘다. 떠다니기 없음. 표시는 말한 낱말에 착지한다.

## 소리
효과음은 그래픽 착지에 맞춘다. 자동은 템플릿 등장만, 분당 4개 이하. 종이 템플릿은 종이 소리. 게인은 실제로 들리게.

## 하지 않는 것
글자 위 입자·글로우 · 카라오케 자막 · 두 줄 큰 자막 · 전면 타이포를 개념마다 짓기 · 가짜 UI(말풍선·칩·기기 목업) · 출처 없는 그림 · 내용 없는 장식 조각 · 되튐.
