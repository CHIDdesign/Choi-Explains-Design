# 🛠 시그니처 장면 — 이 영상을 기억하게 할 한 장면을 정밀하게 만든다

위 공유 컨텍스트의 **🔎 주제 조사 노트**(`recreations` 사양·대상의 생김새)가 정확도의 근거다. 사양이 모자라면 웹 검색·가져오기로 확인한다. 확인하지 못한 수치는 지어내지 말고 비율·배치만 맞춘다.

## 만드는 법
1. **실물이 있으면 실물 위에 짓는다.** 확보 자료(`images/…`)의 도면·사진·지도·문서를 바탕으로 깔고 그 위에 지금 말하는 부분만 표시한다. 없을 때만 단면·흐름을 종이 위에 연필 선으로 그린다.
2. **구도 원형** 하나에서 출발한다(`archetype`). 말에 맞춰 3~6박자, 표시가 말한 낱말에 착지하고 정착하면 멈춘다.
3. **읽히게.** 글자는 이름표(이름·연도·수치·짧은 라벨), 설명은 말이 한다. 자료를 쓰면 `출처: 기관`을 적는다.
4. **상표를 흉내 내 그리지 않는다.** 제품 이름은 글자로, 생김새는 형태로.
5. 화면 UI 를 재현할 때는 조사 노트의 사양이나 자료 폴더 캡처에 있는 것만 그대로 옮긴다. 있는 그대로의 화면 비율·문구를 쓰고, 화면 속 가짜 글자는 `aria-hidden`.
6. 바탕과 이름표는 재질로 짓는다(`data-surface`·`data-torn`·`data-tape`). 재현한 화면이 가짜 UI 가 되면 짓지 않는다.
7. 레이아웃은 보통 `fullscreen`, 비교할 때만 `split`.

## 내는 것
- `layout`·`style`·`archetype`·`title`(장면 이름 — 화면에 나가지 않는다)
- `html`: 카드 계약 그대로의 조각 전체
- `timeline`: 직접 쓴 GSAP 타임라인. `data-anim` 만으로 되면 ""
- `start_word`: 장면 정보의 `start_word` 를 그대로
- `why_not_evidence`: 왜 실물 자료만으로 안 되고 이 장면이 필요한가 한 문장
- `notes`: 무엇을 어떻게 재현했는지와 근거(조사 노트의 어느 사양) 한두 줄
