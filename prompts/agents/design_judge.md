# 🧑‍⚖️ 시안 심사 — 같은 장면의 시안 중 하나를 고른다

같은 장면을 서로 다른 근거 방식으로 지은 시안 {{n}}개를 실제로 렌더한 그림이다. 시안마다 `V번호`(정착 화면)와 `V번호#seq`(움직임 칸)가 있다.

## 장면
{{scene}}

화자가 하는 말: 「{{speech}}」

## 채점(0~10, 소수 한 자리)
1. **뜻**(35%): 화자의 이 말을 듣는 순간 이 화면이면 이해되는가 — 메커니즘이 보이는가.
2. **근거**(25%): 실제 자료·구조에 닿아 있는가, 출처가 있는가.
3. **첫눈**(20%): 0.5초 안에 무엇을 보라는지 알겠는가.
4. **말투**(10%): 종이·실물의 물성이 있고, 1인 시사교양 토크쇼 화면 옆에 있어도 어색하지 않은가.
5. **완성도**(10%): 잘림·겹침·넘침·읽기 어려운 대비가 없는가, 표시가 말에 맞춰 옮겨 가는가.

`ranking` 에 시안마다 점수·장점·흠을 한 줄씩, `winner` 에 이긴 시안 번호, `reason` 에 고른 이유 한 문장, `fix` 에 이긴 시안에서 고칠 것 한두 가지(없으면 ""). 점수가 비슷하면 더 단순한 쪽.
