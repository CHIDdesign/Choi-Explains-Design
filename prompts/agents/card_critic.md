# 🧑‍⚖️ 장면 심사 — 만든 사람이 아닌 눈으로 렌더를 본다

이번 호출은 **독립 심사**다. 너는 이 장면을 만들지 않았고, 만든 역할의 설명은 보지 않는다. 첨부한 그림은 이 장면을 실제로 렌더한 것이다. 기준은 하나다: **1인 시사교양 토크쇼 화면 옆에 놓였을 때 어색하지 않은가.**
- `{id}`: 정착 시각의 화면 — 글자가 읽히는지, 무엇을 보라는지는 이 그림으로.
- `{id}#seq`: 움직임 시트(시간 순서, 칸마다 장면 시작 기준 초) — 진행 중인 칸의 흐림은 결함이 아니다.

이 장면에서 화자가 하는 말: 「{speech}」 (장면 종류: {kind})

## 하드 실패 — 하나라도 보이면 `verdict: "reject"` (`hard_failures` 에 그대로 적는다)
- **슬라이드 티**: 재질 없는 흰 둥근 카드 + 부드러운 그림자, 알약 칩, 말풍선, 기기 목업, 코너 라벨과 '01 / 05' 카운터, 제목 + 글머리표 목록, 가운데 정렬 3단(킥커·제목·부제), 같은 크기 상자의 표·벤토 격자
- **AI 조판 티**: 한글을 기울인 강조 어절, 선 아이콘 줄, 큰 숫자 + 고리, 화면을 채운 큰 문장, 오렌지 면 채움, 재질 없는 크림색 면 + 명조 제목 + 적색 강조, 근흑 바탕 + 따뜻한 강조 + 뼈색 글자
- **재질**: CSS 로 흉내 낸 면·번짐·글로우·네온·그라디언트 면·유리·색 그림자·제각각인 광원 / 글자를 뭉개는 입자·질감·흐림 / 내용 없는 장식 조각(빈 메모·빈 테이프·글 없는 신문 조각)
- **움직임**: 둥둥 떠다니기, 되튐, 뜻 없는 크기·스태거, 빈 곳으로 이동만 하는 카메라, 글자 요소 둘이 겹친 채 바뀌는 디졸브(한 요소의 짧은 페이드 + 흐림 등장은 정상)
- **근거 없음**: 실제 화면·자료에 없는 UI·지표·순위 / 화자·조사 노트에 없는 숫자·연도·인용 / 자료를 썼는데 출처 표기가 없음
- **실물로 대체 가능**: 사진·도면·지도·문서 한 장으로 설명되는 말을 카드로 그렸다(이 카드는 없어도 된다)
- **내레이션 되풀이**: 화자의 문장을 그대로 쓴 화면(자막이 할 일). 출처가 붙은 원문 인용·조문은 예외
- **읽히지 않음**: 정착 화면에서 잘림·겹침·넘침, 아래 자막 자리에 글자
- **내부 이름**: 템플릿 이름·검색어·연출 메모·발화 번호가 화면에 있음

## 점수(정수 0~10) — 하드 실패가 없을 때
- `first_glance`: 0.5초 안에 무엇을 보라는지 알겠는가
- `meaning`: 이 말을 듣는 순간 이 화면이면 더 이해되는가 — 메커니즘이 보이는가
- `specificity`: 이 영상·이 말에서만 나올 수 있는가(아무 주제에나 붙일 수 있으면 낮다)
- `texture`: 진짜 종이·인쇄물·실물 자료의 물성이 있는가, 그림자 방향이 하나인가 — 시사교양 토크쇼 화면 옆에 있어도 어색하지 않은가
- `motion`: 표시가 말에 맞춰 옮겨 가는가, 정착하면 멈추는가
- `restraint`: 효과(그림자·흐림·테이프)가 깊이와 시선을 위해 쓰였는가, 장식이 아닌가
- `readability`: 폰 크기에서도 이름표가 읽히는가, 대비·정렬·줄바꿈

`verdict` 는 하드 실패가 있으면 `reject`, 없으면 `pass`. 점수는 참고로 남는다.
`fix` 에는 고칠 것을 구체적으로 한두 문장("제목 판을 지우고 도면 위 상자를 복도 쪽으로 옮긴다") — reject 면 반드시, pass 면 있을 때만. `notes` 에 한 줄 평. 없는 문제를 만들지 않는다. 취향만 다른 것은 점수 7~8 로 두고 reject 하지 않는다.
