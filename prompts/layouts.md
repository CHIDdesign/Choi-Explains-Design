# 구도 원형 12 — 빈 좌표에서 시작하지 않는다

채널 주인 2026-10-04: "지금 스타일은 너무 기본적인 PPT 같다." 실제 10/04 장면을 렌더해 보니 화면 대부분이 비고, 작은 글자와
점·선이 좌표에 떠 있고, 주인공이 없었다. 원인은 **구도 체계 없이 백지 좌표에 요소를 하나씩 놓는 것**이었다.
모든 카드·모션 장면은 아래 원형 하나에서 출발한다(`layout_name` 에 원형 id). 원형은 뼈대일 뿐 — 내용·크기·방향은 장면마다 바꾼다.
아래 '카드 예시'는 이 원형들을 실제로 렌더해 확인한 것이다(같은 이름).

## 공통 문법 (1920×1080, 모든 원형)

- **그리드**: 바깥 여백 120~150px, 12열(열 너비 ≈ 115px, 거터 24px). 큰 덩어리는 열 경계에 맞춘다. 아래 170px 는 자막 자리 — 글자 금지.
- **주인공 하나**: 화면의 35~60% 를 차지하는 덩어리(큰 글자 · 실물/사물 · 숫자 · 기기 화면) 하나. 나머지는 그보다 확실히 작다(1/3 이하).
- **글자 크기 단계**: 주인공 제목 150~200px · 장면 제목 92~110px · 본문 38~44px · 라벨 28~32px(자간 0.14em). 단계 사이를 비우지 않는다
  (예: 110 다음이 32 — 중간 크기를 만들지 않는다). Jitter 공개 템플릿 131개 글자 실측: 가로 1920 기준 중앙값 57px · 상위 25% 114px ·
  상위 10% 240px — 큰 글자를 겁내지 않는다.
- **재질**: 밝은 무대(`--paper`) 위 흰 둥근 판(`--white`, 반경 28~40px, 위에서 오는 부드러운 그림자 하나) · 잉크에 가까운 검정 ·
  채널 오렌지는 한 곳(면·선·한 낱말). 어두운 무대(`--ink` 바탕)는 챕터당 한 번, 한 방에만. Jitter 실측 모서리 반경 중앙값 58px(1920 기준).
- **강조 한 어절**: 제목의 한 어절만 `<em>`(Instrument Serif 이탤릭, `--accent-deep`). 한글 이탤릭은 기울인 고딕이 된다 — 짧은 한 어절에만.
  `--accent-deep` 글자는 40px 이상에만(작은 글자에서는 대비가 4.5:1 아래). 작은 강조는 잉크 글자 + 오렌지 밑줄.
- **장식 글자**(뒤에 크게 깔린 연도·워터마크)는 `aria-hidden="true"` — 검사가 대비를 재지 않는다. 읽어야 하는 글자에는 쓰지 않는다.
- **줄바꿈**: 카드는 어절 단위(keep-all)로 줄이 바뀐다 — 줄을 직접 나누려면 `<br>` 이나 `.line` 블록으로.

## 움직임 문법 (Jitter 공개 템플릿 77개 애니메이션 실측 → 우리 GSAP)

| 무엇 | 실측(중앙값·범위) | 우리 쓰는 법 |
|---|---|---|
| 글자 등장 | 어절 21 · 줄 16 · 글자 14회, 위로(40/51), '마스크 + 올라옴'이 최다 | `gsap.splitText(sel, {type:'words', mask:'words'})` → `yPercent: 110 → 0` |
| 글자 간격 | 낱개 사이 50ms(20~150), 낱개 길이 0.5초(0.2~1.0) | 어절 `stagger 0.05~0.08` · 줄 `0.1` · 글자 `0.03`, `duration 0.6~0.8` |
| 페이드 | 0.2~0.4초 — 짧다 | 투명도만 바꾸는 등장은 0.3~0.5초. 1초짜리 페이드는 흐릿해 보인다 |
| 크기 등장 | 0.8초(0.3~1.6), 가끔 되튐(back) | 판·칩 `scale 0.9 → 1` 0.6~0.9초, 칩만 `back.out(1.4)` |
| 마스크 열기 | 들어올 때 1.0초 · 나갈 때 0.5초 | `clipPath: inset(…) → inset(0)` 0.8~1.2초, `power3.inOut` |
| 들어옴 : 나감 | 나가는 쪽이 절반(마스크 1.0 → 0.5, 회전 1.5 → 0.4) | 퇴장은 렌더러가 한다 — 카드 안에서 따로 나가게 하지 않는다 |
| 이징 | natural(부드러운 in-out) 최다 · linear(배경의 긴 회전·이동) · slowDown(감속) · accelerate(나감) | 채널 기본 곡선 `gsap.customEase('M0,0 C0.12,0.9 0.2,1 1,1')`(빠르게 출발해 길게 안착), 이동 `power3.inOut`, 배경 흐름 `none`/`sine.inOut` |
| 시작 몰림 | 동작의 25%가 첫 3% 안에서 시작, 절반이 처음 20% 안 | 0~0.3초에 판·제목 · 0.3~1.5초에 나머지 · 그 뒤는 말에 맞춘 강조 한두 개 |
| 머무는 동안 | 긴 linear 회전(2.6초)·이동(1.5~6초)이 배경에 깔린다 | 정지 구간에 아주 느린 흐름 하나: 무대 `scale 1 → 1.025`(4~5초, none) 또는 장식 `y ±8`(sine) — 화면이 얼지 않게, 글자는 움직이지 않게 |

## 원형

### 1. `statement` — 선언(한 문장이 화면을 채운다)
- **언제**: 결론·주장·챕터의 한 문장. 실물이 없거나 말 자체가 주인공일 때.
- **구도**: 왼쪽 7~8열에 두 줄 제목 170~200px(강조 한 어절), 그 아래 손으로 그은 밑줄, 본문 한 줄 40px. 오른쪽 4열에 그 문장을
  가리키는 작은 사물·기호(같은 사물 셋이 겹친 실루엣 등)와 큰 원 하나.
- **움직임**: 0.1초 어절 마스크 상승(0.07 간격) → 1.0초 밑줄 그리기 → 1.5초 본문 → 정지 동안 무대 줌 1.025.
- **실패**: 가운데 정렬 3단(킥커·제목·부제) · 제목 100px 이하 · 오른쪽 반이 빈 채.

### 2. `object_callouts` — 사물 주석(실물 하나 + 지시선)
- **언제**: 생김새·구조·부분을 말할 때("빨대·뚜껑·띠가 닮았다").
- **구도**: 왼쪽 흰 판(820×760) 안에 실물(사진이면 오린 PNG, 없으면 선 그림), 오른쪽에 제목 + 번호 붙은 라벨 3개. 라벨에서 실물의 그
  부분까지 곡선 지시선과 오렌지 점.
- **움직임**: 판이 올라오며 실물이 그려진다(DrawSVG 0.12 간격) → 라벨마다: 점 등장 → 지시선 그리기 → 라벨 밀려옴(말에 맞춰 0.75초 간격).
- **실패**: 지시선 없이 라벨 목록만 · 실물이 판의 절반 이하.

### 3. `data_bars` — 데이터(결론 숫자 + 막대)
- **언제**: 숫자·비율·비교 결과.
- **구도**: 왼쪽에 결론 숫자 260~320px(단위만 오렌지) + 출처 라벨 + 해석 한 줄, 오른쪽에 막대 4개 이하(하나만 오렌지), 축선, 막대 위 값.
- **움직임**: 축 먼저 그려짐(0.7초) → 막대 `scaleY 0 → 1` `expo.out` 0.14 간격 → 값 → 결론 숫자 `count-up`.
- **실패**: 막대 6개 이상 · 모든 막대가 같은 색 · 숫자가 막대보다 작다.

### 4. `bento` — 근거판(크기가 다른 칸 4~6개)
- **언제**: 한 주장의 근거가 여러 종류(숫자·인용·연도·태그·그림)일 때.
- **구도**: 큰 칸(제목 + 그림) 하나가 40%, 나머지는 숫자 칸(어두운 면) · 강조 칸(오렌지 면) · 인용 칸 · 태그 칸. 칸 사이 30px.
- **움직임**: 칸마다 `clipPath` 안쪽 12% → 0 + `scale 0.94 → 1`(0.09 간격) → 큰 칸 제목 어절 상승 → 그림 그리기 → 칩 등장(back).
- **실패**: 같은 크기 칸의 격자(표처럼 보인다) · 칸마다 글자만.

### 5. `before_after` — 전후 비교(와이프)
- **언제**: 고치기 전과 후, 처음 안과 바뀐 안, 틀린 예와 맞는 예.
- **구도**: 위에 제목, 아래 넓은 흰 판(1640×620) 하나. 왼쪽 반 = 전(거친 선), 오른쪽 = 후(깨끗한 선 + 오렌지 한 곳), 가운데 손잡이.
- **움직임**: 전이 그려진다 → 1.4초에 후 레이어 `clipPath: inset(0 0 0 100%) → inset(0 0 0 50%)` 와 손잡이가 함께 이동(1.4초 power3.inOut)
  → 후의 선이 그려진다.
- **실패**: 두 판을 나란히 따로(비교의 순간이 없다).

### 6. `process_path` — 과정(길을 따라)
- **언제**: 순서·단계·흐름·여정(특히 순서가 뒤집힌 과정).
- **구도**: 화면을 가로지르는 곡선 길(점선 밑그림 + 실선), 마디 4개(마지막만 오렌지), 마디 위 번호(이탤릭) + 단계 이름.
- **움직임**: 실선이 3초에 걸쳐 그려지며 점이 길을 따라 달린다(MotionPath, 같은 길이) → 점이 지날 때 마디가 `back.out` 으로 켜지고 이름이 올라온다.
- **실패**: 상자 + 화살표 일렬(순서도처럼 보인다) · 단계 5개 이상.

### 7. `ui_screen` — 화면 재현(기기·브라우저 안)
- **언제**: 앱·웹사이트·도구 화면을 말할 때, 화면 속 행동(찾기·저장·고르기)을 말할 때.
- **구도**: 오른쪽 7열에 브라우저 창/기기(반경 30, 큰 그림자), 안에 실제 구조(격자·목록·패널), 왼쪽 4열에 제목 + 한 줄. 커서·칩으로 행동을 보여 준다.
- **움직임**: 창이 살짝 기울어 올라옴(rotation 2 → 0) → 안의 칸이 격자 순서로(stagger grid) → 커서가 경로를 따라 이동 → 누름(scale 0.86 왕복)
  → 고른 칸 확대 + 오렌지 테두리, 나머지 흐려짐 → 결과 칩.
- **실패**: 빈 기기 틀 · 로고 흉내 · 화면 글자 28px 미만.

### 8. `timeline` — 연표(축 위 연도)
- **언제**: 연도·시대·연구의 흐름.
- **구도**: 위에 제목, 가운데 가로 축(굵기 5), 사건 3~5개(연도 이탤릭 88~110px 위 · 설명 36px 아래), 핵심 연도만 오렌지, 뒤에 그 연도를 아주 크게
  (`aria-hidden`, 6% 잉크).
- **움직임**: 축이 1.4초에 그어진다 → 사건마다 눈금 → 연도 상승 → 설명(0.42초 간격) → 뒤 큰 연도가 천천히 흐른다.
- **실패**: 연도만 나열 · 모든 연도 같은 색.

### 9. `fan_stack` — 펼침(쌓인 것들이 펼쳐지고 하나가 나온다)
- **언제**: 많은 예시·시안·자료 중 하나를 짚을 때("스무 장 모두 같은 컵").
- **구도**: 어두운 무대(챕터당 한 번), 왼쪽 제목, 오른쪽 카드 더미 4~6장(흰 판, 같은 그림).
- **움직임**: 더미가 올라옴 → 부채꼴로 펼침(rotation (i−2)×9°, x (i−2)×70) → 한 장이 앞으로(y −70, scale 1.06, back) + 오렌지 테두리, 나머지 흐려짐.
- **실패**: 카드가 서로 다른 그림(펼침의 뜻이 사라짐).

### 10. `stat_ring` — 결론 숫자 + 고리
- **언제**: 비율 하나가 결론일 때.
- **구도**: 왼쪽 원(지름 660) 안에 숫자 240px, 고리가 그 비율만큼 오렌지, 오른쪽에 제목 + 비교 두 줄(굵은 괘선).
- **움직임**: 고리 DrawSVG `0% → 71%` 와 숫자 `count-up` 이 같은 1.6초 → 제목 어절 → 비교 줄.
- **실패**: 고리 없이 숫자만(3번 data_bars 와 구분이 안 된다).

### 11. `term_split` — 용어(화자 옆 판, split 1080×792)
- **언제**: 개념 이름을 처음 붙이는 순간(화자의 얼굴이 함께 필요할 때).
- **구도**: 흰 판에 점 + 라벨 '용어', 용어 150px, 원어 이탤릭, 한 줄 정의(핵심 구절에 손으로 그린 원), 괘선 + 출처.
- **움직임**: 글자 단위 마스크 상승(0.04) → 원어 → 정의 → 괘선 → 원 그리기(그 구절을 말할 때).
- **실패**: 정의가 세 줄 이상 · 원어 없이 한국어만.

### 12. `lower_third` — 얼굴 위 이름표(overlay 1728×810)
- **언제**: 얼굴이 주인공인 문장에 한 줄을 얹을 때(이름·연도·핵심 구절).
- **구도**: 아래 ⅓ 왼쪽, 흰 상자 한 줄(72px) + 어두운 알약 한 줄(34px). 위는 비운다(얼굴).
- **움직임**: 흰 상자가 왼쪽에서 밀려옴 → 알약 → 핵심어에 형광 띠가 지나감.
- **실패**: 상자 세 줄 이상 · 얼굴을 가림.

## 원형을 고르는 법
말의 종류 → 원형: 주장 1 · 생김새 2 · 숫자 3/10 · 근거 여럿 4 · 전후 5 · 순서 6 · 화면 7 · 연도 8 · 많은 것 중 하나 9 · 용어 11 · 얼굴 위 한 줄 12.
같은 원형은 한 영상에 세 번까지, 연달아 두 번 쓰지 않는다. 한 챕터 안에서 정렬 축(왼쪽·오른쪽·가로 띠·가운데 원)을 바꾼다.
