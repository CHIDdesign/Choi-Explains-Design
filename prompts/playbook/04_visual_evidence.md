## 🎓 4. 시각 증거 — 말한 것은 보여 준다

디자인 채널에서 디자인물이 안 보이면 설명이 아니라 낭독이다. 모든 에이전트는 아래 규칙을 같이 쓴다.

### 4-1. 주장 → 증거
- 화자가 **대상·사례·출처·생김새·화면**을 말하면, 그 문장이 들리는 동안 그것이 화면에 있다.
- 글자 카드와 도식은 주장을 **정리**하고, 자료는 주장을 **증명**한다. 정리만 있고 증명이 없는 챕터를 만들지 않는다.
- 꾸밈용 자료는 넣지 않는다. 이유를 한 문장으로 말하지 못하면 뺀다.
- 고백·의견·결론은 얼굴이다. 자료를 얹지 않는다.

### 4-2. 무엇을 봐야 하는가 (need)
| 말의 종류 | 보여 줄 것 | 스톡으로 대신해도 되나 |
|---|---|---|
| 화자 자신의 작업·경험 | 화자의 실제 과제물·스케치·화면(자료 폴더) | 안 된다 → 없으면 선으로 재현 |
| 이름 있는 인물·작품·제품·브랜드·장소 | 그 실물 사진(여러 장) | 안 된다 → 없으면 글자 자료 카드 |
| 논문·책·실험·통계 | 출처 카드 + 문서 첫 화면에 밑줄 | 안 된다 |
| 웹사이트·앱 | 그 화면 캡처(가짜 틀 없이) — 대표 인물 사진이 아니다 | 안 된다 → 없으면 이름표·글자 카드, 또는 얼굴(화면을 지어 그리지 않는다) |
| 원리·구조·과정 | 코드로 그린 도식·모션 | 안 된다(사진을 찾지 않는다) |
| 만드는 과정·쓰이는 맥락·분위기 | 스톡 영상·사진 | 된다 |

### 4-3. 밀도와 크기
- 실물 자료가 보이는 시간은 '영상 형식' 문서를 따른다.
- **근거는 전면으로**(풀블리드). 얼굴 옆 작은 액자(pip)만으로 끝내지 않는다.
- pip 는 지나가는 언급에만 쓴다. 한 문장 자리에 한 장이 기본이고, 여러 장은 선언한 시퀀스로만(`05_sequences`).
- 앞 6분은 사례·근거를 말하는 문장마다 증거를 붙이고, 중반 토크 구간은 얼굴에 30~50초씩 맡긴다('영상 형식' 문서의 곡선).
- 한 장 유지: 단순한 사물 2.5~3.5초, 읽을 것이 있는 이미지(포스터·화면·문서) 4~6초, 표시 하나마다 +0.8초.
- 같은 처리(느린 푸시인)를 세 번 잇지 않는다. 사진 → 문서, 전체 → 부분, 공개가 목적이면 세부 → 전체로 바꿔 간다.
- 일반 스톡의 비중은 '영상 형식' 문서를 따른다. 과정·현장·도시·시대는 **스톡 영상**을 먼저. 특정 대상을 스톡으로 대신하지 않는다.
- **사진은 각지게 풀블리드로 끊어 넣는다.** 화질·비율이 달라도 숨기지 않고, 출처를 항상 단다. 절반 이상은 위에 그래픽(윤곽·원·종이 라벨·메모)을 말에 맞춰 올린다.
  이름은 민트 상자 이름표, 출처는 우하단 작게.

### 4-4. 화면 글자
- **라벨 = 주장의 한 조각**(14자 이내): "서류가 된 이론". 화자의 말에서 가져온다.
- **캡션 = 사실**(24자 이내): 이름 · 연도 · 작가 · 출처.
- 화면에 나가면 안 되는 것: 검색어, 연출 메모("…을 보여준다", "장면", "전환점"), 내부 이름(`brand`·`motion`·`card`·`broll`·발화 번호).
- 사진과 다른 말을 쓰지 않는다. 사진을 확인하기 전에는 시간·장소·사람을 단정하는 라벨을 쓰지 않는다.
- 쓸 말이 없으면 라벨을 비운다. 빈 라벨이 틀린 라벨보다 낫다.

### 4-5. 출처 표기
- 자료에는 항상 작은 출처 줄이 붙는다: `사진: 작가 · 라이선스 · 출처`, 논문은 `저자 (연도), 저널`, 화면은 `화면: 도메인 (연월)`.
- 저작권이 있는 작품·문서·화면은 **그것을 설명하는 문장에서만**, 6초 이내, 밑줄·표시·비교와 함께 쓴다.
- 비영리 전용(NC)·변경 금지(ND)·출처 불명 이미지는 쓰지 않는다.
- 실존 인물·실존 작품·역사적 장면을 AI 로 만들어 내지 않는다.

### 4-6. 실물이 없을 때
틀린 자료보다 없는 게 낫다. 그렇다고 그냥 빼지 않는다. 아래 순서로 내려가고, 어디서 끝났는지 남긴다.
1. 다른 소스에서 같은 대상을 찾는다(화자 자료 → 공개 소장 자료 → 자유 라이선스 사진).
2. **만든다**: 서지 정보로 만든 출처 카드, 선으로 재현한 화면·구조, 원리 도식, 서체 견본.
3. 이름·연도·한 줄 설명의 **글자 자료 카드**(실물 사진처럼 보이지 않게).
4. 스톡은 과정·맥락일 때만. 그 밖에는 얼굴로 둔다.
화자 자료가 필요한데 없으면, 어떤 파일이 있으면 좋은지를 메모로 남긴다(다음 촬영 때 받는다).

### 4-7. 하지 않는 것
- 서비스·제품 이야기에 창업자·대표 사진.
- 화면 위의 컬러 클립아트.
- 은유 스톡(악수·전구·톱니바퀴·자판 위 손·형광 3D 배경).
- 해설 없이 사진만 길게 넘기는 구간(한 묶음 12초 이내, 목소리가 계속 설명한다).
- 대본에 없는 사실을 자료 캡션으로 덧붙이는 것(연도·이름은 확인된 것만).
